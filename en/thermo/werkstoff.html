Materials database – property curves, Larson-Miller, density from expansion

What the database computes with the numbers from the manufacturers' data sheets: shape-preserving piecewise cubic Hermite interpolation (PCHIP) between at most five data points without extrapolation, creep rupture strength after Larson-Miller with its three inversions and the data range of the fit, density versus temperature from the mean thermal expansion. Plus the file format with its validation rules, an example with hand calculation, the verification and the limits.

What it is about

Designing a blade needs metal properties versus temperature – thermal conductivity for the wall temperature, density for the centrifugal load, Young's modulus for natural frequencies – and a statement on creep rupture strength: which metal temperature can the blade tolerate at its stress for the required life? The manufacturers' data sheets provide tables at a few temperatures, often in °F, with different reference temperatures for thermal expansion and creep rupture values as individual points.

Werkstoffdatenbank keeps these values in SI with source and location for every number and computes three things with them:

  • Property curve (Kennlinie) – a property between the data points, shape-preserving and without overshoot, only inside the data range;
  • Larson-Miller – creep rupture strength, life or allowable temperature from three fitted constants, with the range in which the fit is reliable;
  • Density versus T – from the density at room temperature and the mean linear thermal expansion.

The shipped data contain 26 entries: 21 nickel-base alloys with property curves (Special Metals, Haynes, Nickel Institute), IN-738C with creep data only, the three named placeholders NIMS-24B/29B/30B without numbers (the NIMS Creep Data Sheets are licensed) and the default set of the cooling-demand model of the turbine library. The data sheets give typical values, not minimum values.

Properties and units

Each property has a fixed SI unit that must appear exactly so in the file – a forgotten conversion (MPa instead of Pa, µm/(m K) instead of 1/K) is caught when reading. Each also has a plausibility range and a statement on monotonicity in temperature:

"Required" means the verification fails if the data violate it (elastic moduli fall as long as the microstructure does not change; creep rupture strength falls with temperature and time). "Expected" means usual for the alloys included; deviations are recorded in the verification as known findings in the data sheets.

Property curve: PCHIP without extrapolation

Between the data points (Tk,wk)(T_k, w_k), k=0…n−1k = 0 \dots n-1, the shape-preserving piecewise cubic Hermite interpolation of Fritsch and Carlson is used, with slopes after Fritsch and Butland – the method behind pchip in MATLAB. On the interval [Tk,Tk+1][T_k, T_{k+1}] with hk=Tk+1−Tkh_k = T_{k+1} - T_k and s=(T−Tk)/hks = (T - T_k)/h_k:

w(T)=wk(2s3−3s2+1)+hkdk(s3−2s2+s)+wk+1(3s2−2s3)+hkdk+1(s3−s2)w(T) = w_k\,(2s^3 - 3s^2 + 1) + h_k d_k\,(s^3 - 2s^2 + s) + w_{k+1}\,(3s^2 - 2s^3) + h_k d_{k+1}\,(s^3 - s^2)

The slopes dkd_k come from the secants δk=(wk+1−wk)/hk\delta_k = (w_{k+1} - w_k)/h_k. Interior: a weighted harmonic mean, zero at a sign change or a horizontal secant:

dk=w1+w2w1/δk−1+w2/δk,w1=2hk+hk−1,w2=hk+2hk−1;dk=0ifδk−1δk≤0d_k = \frac{w_1 + w_2}{w_1/\delta_{k-1} + w_2/\delta_k}, \qquad w_1 = 2h_k + h_{k-1}, \quad w_2 = h_k + 2h_{k-1}; \qquad d_k = 0 \ \text{if}\ \delta_{k-1}\delta_k \le 0

At the ends the one-sided three-point formula, limited as in MATLAB (pchipend):

d0=(2h0+h1)δ0−h0δ1h0+h1;d0=0ifsgn⁡d0≠sgn⁡δ0;d0=3δ0ifsgn⁡δ0≠sgn⁡δ1and|d0|>3|δ0|d_0 = \frac{(2h_0 + h_1)\,\delta_0 - h_0\,\delta_1}{h_0 + h_1}; \qquad d_0 = 0\ \text{if}\ \operatorname{sgn} d_0 \ne \operatorname{sgn}\delta_0; \qquad d_0 = 3\delta_0\ \text{if}\ \operatorname{sgn}\delta_0 \ne \operatorname{sgn}\delta_1\ \text{and}\ |d_0| > 3|\delta_0|

With two data points the curve is the straight line. The result passes through all data points, is continuously differentiable, and monotone data give a monotone curve: local extrema occur only at data points. For property tables with five points this matters more than the higher smoothness of a cubic spline, which can overshoot between widely spaced points – a Young's modulus that rises between two table values would be physically wrong.

Data range. A property curve is valid only for T0≤T≤Tn−1T_0 \le T \le T_{n-1}; outside, wert throws an exception instead of continuing the end polynomial (which the class Pchip itself would do). A single data point is valid only at exactly its temperature. ableitung(T) returns dw/dT\mathrm dw/\mathrm dT from the same polynomial.

// Kennlinie.wert(T)
if not T₀ ≤ T ≤ T_(n−1): throw "outside the data range"
if n = 1: return w₀
k ← interval with T_k ≤ T < T_(k+1)          binary search, last interval at the end
s ← (T − T_k)/h_k
return Hermite(w_k, d_k, w_(k+1), d_(k+1), h_k, s)

// slopes, once on construction
for k ← 1 to n−2:
    if δ_(k−1) = 0 or δ_k = 0 or sgn δ_(k−1) ≠ sgn δ_k: d_k ← 0
    else: d_k ← (w₁ + w₂)/(w₁/δ_(k−1) + w₂/δ_k)
d₀, d_(n−1) ← three-point formula, limited

Creep rupture after Larson-Miller

Larson and Miller collapse creep rupture tests at different temperatures and lives onto a master curve via a time-temperature parameter. The database uses the form of the cooling-demand model of the turbine library, with TT in K, tht_h in hours and σ\sigma in MPa:

P=T(C+log10⁡th)1000=A−Blog10⁡σ1MPa⁡P = \frac{T\,(C + \log_{10} t_h)}{1000} = A - B\,\log_{10}\frac{\sigma}{1\ \mathrm{MPa}}

with AA = LMA, BB = LMB, CC = LMC. The master curve here is a straight line in log10⁡σ\log_{10}\sigma. Solved for each of the three quantities:

σ=106⋅10(A−P)/BPa⁡,th=101000(A−Blog10⁡(σ/MPa⁡))/T−C,T=1000(A−Blog10⁡(σ/MPa⁡))C+log10⁡th\sigma = 10^{6}\cdot 10^{(A - P)/B}\ \mathrm{Pa}, \qquad t_h = 10^{\,1000\,(A - B\log_{10}(\sigma/\mathrm{MPa}))/T \;-\; C}, \qquad T = \frac{1000\,\bigl(A - B\log_{10}(\sigma/\mathrm{MPa})\bigr)}{C + \log_{10} t_h}

The methods are spannung(T, t_h), lebensdauer(T, σ) and temperatur(σ, t_h); σ is passed in Pa. All three are closed-form, there is no iteration.

Fit and data range. For the shipped alloys C=20C = 20 is fixed; AA and BB were fitted outside the library (generator script werkstofftafel.py; it is currently not in the workspace, so the table cannot be regenerated, but every data point names its source) to the tabulated creep rupture values of the data sheets and rounded to two decimals. Each fit stores smallest and largest stress σmin⁡\sigma_{\min}, σmax⁡\sigma_{\max}, longest life tmax⁡t_{\max} and the largest residual in PP. imDatenbereich(σ, t_h) is true if σmin⁡≤σ≤σmax⁡\sigma_{\min} \le \sigma \le \sigma_{\max} and th≤tmax⁡t_h \le t_{\max}; an unknown limit counts as not satisfied. Temperature is not part of the check – it is tied to σ via PP.

A residual of 0.42 in PP means, at T≈1000T \approx 1000 K, an uncertainty of life by a factor 100.42⋅1000/T≈2.610^{0.42\cdot 1000/T} \approx 2.6 or of allowable temperature by 0.42⋅1000/(C+log10⁡th)≈17.50.42\cdot 1000/(C + \log_{10}t_h) \approx 17.5 K at 10⁴ h. This is the scatter of the fit to typical values, not that of a material heat.

Density from thermal expansion

The data sheets give the density at room temperature (20 °C) and the mean linear expansion α(T)\bar\alpha(T) from a reference temperature TbT_b (usually 20, 21 or 25 °C) to TT. The strain relative to TbT_b is

ε(T)=α(T)(T−Tb)\varepsilon(T) = \bar\alpha(T)\,(T - T_b)

inside the range of the expansion curve. If the first data point T0T_0 lies above TbT_b, the straight line through zero, ε(T)=α(T0)(T−Tb)\varepsilon(T) = \bar\alpha(T_0)\,(T - T_b), applies between the two; it is extended to 10 K below TbT_b so that a density at 20 °C matches an expansion from 25 °C. With isotropic expansion the volume grows with (1+ε)3(1 + \varepsilon)^3, hence

ρ(T)=ρ(T0)[1+ε(T0)1+ε(T)]3,dln⁡ρdT=−31+εdεdT\rho(T) = \rho(T_0)\left[\frac{1 + \varepsilon(T_0)}{1 + \varepsilon(T)}\right]^3, \qquad \frac{\mathrm d\ln\rho}{\mathrm dT} = -\frac{3}{1 + \varepsilon}\,\frac{\mathrm d\varepsilon}{\mathrm dT}

with T0T_0 the (lowest) temperature of the density curve. If RHO itself is given as a curve over several temperatures and TT lies inside, that curve applies. Without a reference temperature in the data sheet (field bezug_K empty) the density is refused rather than guessed.

// Werkstoff.dichte(T)
r ← curve(RHO)
if r valid at T: return r.wert(T)
T₀ ← r.tMin
return r.wert(T₀) · ((1 + ε(T₀))/(1 + ε(T)))³

// Werkstoff.dehnung(T)
a ← curve(ALPHA);  T_b ← reference temperature of a     missing: throw
if a valid at T: return a.wert(T)·(T − T_b)
if T₀ ≠ T_b and min(T_b, T₀) − 10 ≤ T ≤ max(T_b, T₀): return a.wert(T₀)·(T − T_b)
throw "outside the expansion curve"

File format and validation on reading

Shipped data and user file share one format: UTF-8, one line per value, separator ;, comment lines with #. The first data line is the header

werkstoff;kennwert;zustand;T_K;t_h;bezug_K;wert;einheit;quelle;stelle

Reading rejects, with file name and line number: wrong header, not exactly 10 fields, unknown property, a unit other than the property's, missing source, a number with decimal comma, a value outside the plausibility range, T or t missing or present where they do not belong (t_h only for creep rupture, bezug_K only for ALPHA), duplicate data point, two microstructural conditions or two reference temperatures in one curve, LMA/LMB/LMC incomplete, a data range without constants, a placeholder that also has values. An empty wert (with empty T, t and reference fields) makes the property a named placeholder: the material exists, a query reports "to be entered by the user".

User values. anwender() additionally reads the file named by the system property envisionz.werkstoffe or ~/.envisionz/werkstoffe.csv. A material from this file replaces the database material of the same name entirely, not property by property – this fills a NIMS placeholder without mixing values from two sources in one curve. Replaced materials that had values (not filled placeholders) are listed by ersetzt().

Framework convention: everything in SI (K, Pa, h for lives, kg/m³). Per alloy and property at most five data points from one source and one microstructural condition (rule F6 – the generator script selects them, the verification checks it); a curve never mixes sources. No extrapolation, neither for curves nor for expansion (except 10 K below Tb). Larson-Miller with C = 20 for all shipped alloys. The classes are immutable and thread-safe.

Worked example with hand calculation

Allowable metal temperature for HAYNES 282 at 250 MPa and 10,000 h, then the thermal conductivity there:

Werkstoff w = Werkstoffdatenbank.standard().werkstoff("HAYNES 282");
LarsonMiller lm = w.larsonMiller();          // A = 38.47, B = 6.14, C = 20
double tZul = lm.temperatur(250e6, 1e4);     // 989.4437 K
boolean ok  = lm.imDatenbereich(250e6, 1e4); // true: 83 … 586 MPa, t ≤ 10,000 h
double lam  = w.wert(Kennwert.LAMBDA, tZul); // 24.6810 W/(m K)

Larson-Miller by hand: Blog10⁡250=6.14⋅2.39794=14.7234B\log_{10}250 = 6.14\cdot 2.39794 = 14.7234, P=38.47−14.7234=23.7466P = 38.47 - 14.7234 = 23.7466, T=1000⋅23.7466/(20+4)=989.44T = 1000\cdot 23.7466/(20 + 4) = 989.44 K. Cross-check: at 1000 K and 250 MPa lebensdauer returns 5580 h, at 1050 K only 413 h – 50 K cost more than an order of magnitude of life.

PCHIP by hand: data points λ = 10.3 / 14.1 / 20.5 / 26.1 / 28.9 W/(m K) at 293.15 / 473.15 / 773.15 / 1073.15 / 1273.15 K. Secants δ=0.021111;0.021333;0.018667;0.014000\delta = 0.021111;\ 0.021333;\ 0.018667;\ 0.014000 W/(m K²). Slope at 773.15 K (hk−1=hk=300h_{k-1} = h_k = 300, equal weights): d=2/(1/0.021333+1/0.018667)=0.019911d = 2/(1/0.021333 + 1/0.018667) = 0.019911. Slope at 1073.15 K (hk−1=300h_{k-1} = 300, hk=200h_k = 200, w1=700w_1 = 700, w2=800w_2 = 800): d=1500/(700/0.018667+800/0.014)=0.015849d = 1500/(700/0.018667 + 800/0.014) = 0.015849. With s=(989.44−773.15)/300=0.72098s = (989.44 - 773.15)/300 = 0.72098 the Hermite polynomial gives 24.6810 W/(m K) – to all digits as the class. Linear interpolation would give 24.537, i.e. 0.6 % less.

Density by hand (Alloy 718, ρ = 8230 kg/m³ at 293.15 K, α\bar\alpha from TbT_b = 298.15 K): at 293.15 K one is 5 K below TbT_b, so ε0=1.28⋅10−5⋅(−5)=−6.4⋅10−5\varepsilon_0 = 1.28\cdot 10^{-5}\cdot(-5) = -6.4\cdot 10^{-5}. At 1073.15 K, α=1.62821⋅10−5\bar\alpha = 1.62821\cdot 10^{-5}/K (PCHIP), ε=1.62821⋅10−5⋅775=0.0126186\varepsilon = 1.62821\cdot 10^{-5}\cdot 775 = 0.0126186 and

ρ=8230(0.9999361.0126186)3=7924.62kg/m3\rho = 8230\left(\frac{0.999936}{1.0126186}\right)^3 = 7924.62\ \mathrm{kg/m^3}

3.7 % less than at room temperature – not negligible for the centrifugal stress of a rotor blade.

How it is verified

test/envisionz/thermo/werkstoff/Werkstoffprobe.java, 53 checks in six groups:

  • Database: 26 materials, 22 with property curves; every value with source and location, plausible in its SI unit; at most five data points and one condition per curve (F6); NIMS placeholders without numbers; default set of the cooling-demand model 8200 kg/m³ and 37 / 5 / 20, marked as "no certified data".
  • Physics: E and G fall with T, creep rupture strength falls with T and t; ν\nu is consistent with E/(2G)−1E/(2G) - 1 (isotropic); density exact at its measurement temperature, at 800 °C from expansion to 10⁻¹⁴, dln⁡ρ/dT\mathrm d\ln\rho/\mathrm dT against the formula above; density without reference temperature refused.
  • Property curves: pass through all data points, no overshoot between two data points over all curves, no extrapolation, a single point valid only at its temperature, falling data nowhere rising.
  • Larson-Miller: all 99 shipped creep rupture values lie within the residual of their fit (plus 0.03 for rounding A and B) and inside the data range; stress, life and temperature invert to 10⁻¹²; the cooling-demand model in turbinen_reihen.nfml uses the same densities and constants.
  • User file: fills a placeholder, replaces a material entirely and reports it, is found via the system property.
  • Error cases: 18 format errors are rejected with line number.

Data sheet findings that the verification records as known: HASTELLOY X cp falls at 473 K, Udimet 700 cp at 700 and 922 K; for HAYNES 230, ν above 700 K does not match E/(2G)−1E/(2G) - 1 (deviation up to 0.09).

Limits

  • Typical values from the data sheets, not minimum or design values; scatter between heats and product forms is not represented.
  • At most five data points: between widely spaced points PCHIP gives a smooth, shape-true curve, but no information that is not in the points; a microstructural change between two points stays invisible.
  • No extrapolation: computations beyond the data range (for instance metal temperatures above the last table temperature) stop with an exception. This is intended; the caller must decide.
  • Larson-Miller with fixed constant C = 20 and a master curve linear in lg σ; over a wide stress range the true master curve is curved. Outside σmin … σmax and beyond tmax the result is an extrapolation – imDatenbereich warns but prevents nothing. No creep strain model, no damage accumulation (Robinson, Miner) under varying load.
  • Density only isotropic and only as far as the expansion curve reaches; for some alloys (INCONEL 718, Udimet 720CR/LI) the expansion curve ends below 1073 K.
  • Nickel-base only in the shipped data; cobalt-base (NIMS-30B) only as a placeholder.
