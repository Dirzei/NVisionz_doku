Rocket, shock and detonation – background

The computation behind Rakete, Stoss and Detonation: nozzle flow with an infinite-area combustor in equilibrium or frozen, normal shock after Rankine-Hugoniot with reacting gas, Chapman-Jouguet detonation. Conservation laws, iteration methods and stopping criteria following the source, examples, check against CEA, limits.

What this is about

Three classical problems of high-temperature gas dynamics need the same tool: a state calculation that determines the gas composition anew at every temperature and pressure and delivers enthalpy, entropy, density and speed of sound with it. That is the Gordon-McBride equilibrium (equilibrium – background). Three conservation calculations build on it:

  • Rocket: combustion in the chamber, then isentropic expansion through the nozzle; wanted are throat, characteristic velocity c*c^*, specific impulse and thrust coefficient.
  • Shock: a gas flows supersonically into a normal shock; behind it it is hot, compressed and – at high Mach number – dissociated.
  • Detonation: a shock that carries its own combustion; the Chapman-Jouguet condition fixes velocity and end state.

Every calculation knows two limiting cases: equilibrium (chemistry infinitely fast) and frozen (the composition stays as it was before the change in the flow). The real flow lies in between.

Rocket with an infinite-area combustor

As in the CEA problem "rocket, iac" the combustor is so large that the gas is at rest there: the chamber is an (h, p) equilibrium at the enthalpy of the reactants h0h_0 and the chamber pressure pcp_c. From there the gas expands isentropically, s=scs = s_c, and the velocity follows from energy:

u(p)=2[hc−h(p,sc)]u(p) = \sqrt{2\,\bigl[h_c - h(p, s_c)\bigr]}

In the equilibrium case h(p,sc)h(p, s_c) is an (s, p) equilibrium, in the frozen case an isentrope with the chamber composition. The running variable is x=ln⁡(pc/p)x = \ln(p_c/p).

Throat. The mass flow per area ρu\rho u has a maximum where uu reaches the speed of sound – in equilibrium the equilibrium speed aeq⁡a_{\mathrm{eq}}, frozen afr⁡a_{\mathrm{fr}}. The root of

f(x)=u2−a2u2+a2f(x) = \frac{u^2 - a^2}{u^2 + a^2}

is sought (equal to −1 at x=0x = 0). From it m˙/At=ρtut\dot m/A_t = \rho_t u_t and the figures of merit:

c*=pcρtut,AAt=ρtutρu,Isp=u,Isp,vac⁡=u+pρu,CF=uc*c^* = \frac{p_c}{\rho_t u_t}, \qquad \frac{A}{A_t} = \frac{\rho_t u_t}{\rho u}, \qquad I_{sp} = u, \qquad I_{sp,\mathrm{vac}} = u + \frac{p}{\rho u}, \qquad C_F = \frac{u}{c^*}

IspI_{sp} holds for an adapted nozzle (exit pressure equal to ambient), Isp,vac⁡I_{sp,\mathrm{vac}} follows from F=m˙u+peAeF = \dot m u + p_e A_e per mass flow with Ae/m˙=1/(ρu)A_e/\dot m = 1/(\rho u). Both in m/s (divided by g0g_0 they give seconds).

Pseudocode – Rakete.rechne(g, b0, h0, pc, pv[], ae[], frozen)

chamber ← Gleichgewicht.hp(g, b0, h0, pc, start 3000 K);  hc, sc ← h, s of the chamber
point(x):  p ← pc·e^−x
    return frozen ? gefrorenSP(n_chamber, sc, p) : Gleichgewicht.sp(chamber as start, sc, p)
f(x) ← (u² − a²)/(u² + a²)  with u² = 2(hc − h(x)),  a = a_eq or a_fr
xa ← 10⁻⁶;  xb ← 0.5
while f(xb) < 0: xa ← xb;  xb ← 1.5·xb;  if xb > 20: throw "no throat found"
xt ← Brent(f, xa, xb, 10⁻¹⁴)
G ← ρ(xt)·u(xt);  c* ← pc/G
for each pressure ratio v > 1:  point at x = ln v
for each area ratio ε > 1:                             supersonic branch
    fe(x) ← ln( G/(ρ(x)·u(x)) / ε )
    a ← xt;  b ← xt + 1;  while fe(b) < 0: a ← b;  b ← b + 1   up to 60, else exception
    point at x = Brent(fe, a, b, 10⁻¹⁴)
point: u, Mach = u/a, A/At = G/(ρu), Isp = u, Isp_vac = u + p/(ρu), CF = u/c*

Normal shock after Rankine-Hugoniot

In the frame moving with the shock the gas enters with u1u_1 and leaves with u2u_2. Mass, momentum and energy are conserved:

ρ1u1=ρ2u2=m˙,p1+ρ1u12=p2+ρ2u22,h1+12u12=h2+12u22\rho_1 u_1 = \rho_2 u_2 = \dot m, \qquad p_1 + \rho_1 u_1^2 = p_2 + \rho_2 u_2^2, \qquad h_1 + \tfrac12 u_1^2 = h_2 + \tfrac12 u_2^2

With v=1/ρv = 1/\rho and u2=m˙v2u_2 = \dot m v_2 these are two equations for p2p_2 and T2T_2 (state 2 with its composition is a function of p2,T2p_2, T_2):

F1=p2+m˙2v2−(p1+m˙u1)p1=0,F2=h2+12m˙2v22−(h1+12u12)p1/ρ1=0F_1 = \frac{p_2 + \dot m^2 v_2 - (p_1 + \dot m u_1)}{p_1} = 0, \qquad F_2 = \frac{h_2 + \tfrac12\dot m^2 v_2^2 - (h_1 + \tfrac12 u_1^2)}{p_1/\rho_1} = 0

They are solved by Newton in (ln⁡p2,ln⁡T2)(\ln p_2, \ln T_2) with an analytic Jacobian. It needs only the derivatives every state carries anyway:

∂v∂ln⁡p=v(∂ln⁡V∂ln⁡p)T,∂v∂ln⁡T=v(∂ln⁡V∂ln⁡T)p,(∂h∂ln⁡p)T=pρ[1−(∂ln⁡V∂ln⁡T)p],(∂h∂ln⁡T)p=cpT\frac{\partial v}{\partial\ln p} = v\left(\frac{\partial\ln V}{\partial\ln p}\right)_T, \quad \frac{\partial v}{\partial\ln T} = v\left(\frac{\partial\ln V}{\partial\ln T}\right)_p, \quad \left(\frac{\partial h}{\partial\ln p}\right)_T = \frac{p}{\rho}\left[1 - \left(\frac{\partial\ln V}{\partial\ln T}\right)_p\right], \quad \left(\frac{\partial h}{\partial\ln T}\right)_p = c_p T

(in equilibrium with the equilibrium derivatives and cp,eq⁡c_{p,\mathrm{eq}}, frozen with 1, −1 and cp,fr⁡c_{p,\mathrm{fr}}). The start value comes from the ideal-gas shock relations with γ1\gamma_1 of state 1:

p2p1=2γ1M12−(γ1−1)γ1+1,ρ2ρ1=(γ1+1)M12(γ1−1)M12+2,T2T1=p2/p1ρ2/ρ1\frac{p_2}{p_1} = \frac{2\gamma_1 M_1^2 - (\gamma_1 - 1)}{\gamma_1 + 1}, \qquad \frac{\rho_2}{\rho_1} = \frac{(\gamma_1 + 1)M_1^2}{(\gamma_1 - 1)M_1^2 + 2}, \qquad \frac{T_2}{T_1} = \frac{p_2/p_1}{\rho_2/\rho_1}

// Stoss.rechne(g, n1, T1, p1, u1, frozen)
z1 ← gefroren(g, n1 per kg, T1, p1);  M1 ← u1/a1,fr;  if M1 ≤ 1: throw
x ← (ln(p1·p2/p1), ln(T1·T2/T1))                      ideal gas with γ1
z2 ← newton(frozen, x)                                always frozen first
if not frozen: z2 ← newton(equilibrium, x)           start: the frozen solution
return (z1, z2, u1, u2 = ρ1·u1/ρ2, M1)

// newton: at most 100 steps
z ← state(p, T)                                        Gleichgewicht.tp with the last one as start
(F1, F2), J from the derivatives;  d ← −J⁻¹F          Cramer, 2×2
λ ← max|d| > 0.4 ? 0.4/max|d| : 1;  x ← x + λ·d
if max|d| < 10⁻¹³: return state at x

Chapman-Jouguet detonation

The detonation front runs with velocity D=u1D = u_1 into the quiescent mixture. Behind it there is equilibrium, and the Chapman-Jouguet condition requires the gas to leave the front at the equilibrium speed of sound:

u2=a2=γsp2/ρ2u_2 = a_2 = \sqrt{\gamma_s\,p_2/\rho_2}

With r=ρ2/ρ1r = \rho_2/\rho_1, mass and momentum (ρ1u12=ρ2u22r=γsp2r\rho_1 u_1^2 = \rho_2 u_2^2 r = \gamma_s p_2 r) and energy (h2−h1=12(u12−u22)=12u22(r2−1)h_2 - h_1 = \tfrac12(u_1^2 - u_2^2) = \tfrac12 u_2^2(r^2 - 1)) give the two equations

p1p2−1+γs(r−1)=0,h2−h1RT2/M2−γs2(r2−1)=0,r=p2p1⋅M2M1⋅T1T2\frac{p_1}{p_2} - 1 + \gamma_s(r - 1) = 0, \qquad \frac{h_2 - h_1}{R T_2/M_2} - \frac{\gamma_s}{2}(r^2 - 1) = 0, \qquad r = \frac{p_2}{p_1}\cdot\frac{M_2}{M_1}\cdot\frac{T_1}{T_2}

Newton in ln⁡(p2/p1)\ln(p_2/p_1) and ln⁡(T2/T1)\ln(T_2/T_1) with the Jacobian of RP-1311; γs\gamma_s is held constant in it, so the method converges only linearly. The step is limited to ln⁡1.5\ln 1.5; stop at |Δ|<10−11|\Delta| < 10^{-11} (CEA stops at 5⋅10−55\cdot10^{-5}).

// Detonation.rechne(g, n1, T1, p1)
z1 ← gefroren(g, n1 per kg, T1, p1);  M1 ← molar mass(z1)
// start value after RP-1311, eqs. 8.8 to 8.10
π ← 15;  z ← hp(g, b0, h1 + 0.75·R·T1·π/M1, p1·π, start 3000 K)
γ ← γs(z);  cp ← cp,eq(z)/R;  τ ← T(z)/T1;  temp ← τ − 0.75·π/(cp·M1);  μ ← M(z)/M1
repeat 3 times:
    α ← μ/τ
    π ← (1 + γ)·(1 + √(1 − 4γα/(1 + γ)²)) / (2γα)
    τ ← temp + ½·π·γ·((πα)² − 1)/(M1·cp·πα)
// Newton
for it ← 1 to 200:
    z ← tp(z as start, b0, T1·τ, p1·π);  γ ← γs(z);  r ← π·M(z)/(M1·τ)
    f1 ← 1/π − 1 + γ(r − 1);   f2 ← (h(z) − h1)/(R T2/M2) − ½γ(r² − 1)
    J from (∂ln V/∂ln p)T, (∂ln V/∂ln T)p, cp,eq at fixed γ
    d ← −J⁻¹F;  λ ← max|d| > ln 1.5 ? ln 1.5/max|d| : 1
    π ← π·e^(λ·d1);  τ ← τ·e^(λ·d2)
    if max|d| < 10⁻¹¹:
        z ← tp(…);  a2 ← a_eq(z);  D ← a2·ρ2/ρ1
        return (z1, z, D, D/a1,fr, a2)
throw "no convergence"

Source: envisionz-framework-thermo/src/envisionz/thermo/gleichgewicht/Detonation.java (like the CEA problem "det").

The wide CEA tolerances are those of CEA: for rocket, shock and detonation it stops at about 10⁻⁵ to 10⁻⁷ (its own momentum residuals in the shock are around 4·10⁻⁶). The conservation laws establish the module's own accuracy. The CJ check independently searches for the smallest velocity at which the Rayleigh line still meets the equilibrium Hugoniot curve and compares it with DD.

Limits

  • One-dimensional and loss-free; rocket without nozzle losses, divergence and boundary layer, with an infinite-area chamber (no finite contraction).
  • Only equilibrium or frozen; no kinetics in the nozzle flow (no "freezing" at a point in the nozzle) and no relaxation zone behind the shock.
  • Gas phase only and the species set of the partition functions (see equilibrium); no ionisation – no longer applicable to shock speeds far above 5000 m/s in air.
  • Search ranges: throat up to ln⁡(pc/p)=20\ln(p_c/p) = 20, exit up to ln⁡(pc/p)=60\ln(p_c/p) = 60; shock only with M1>1M_1 > 1 relative to the frozen speed of sound.
  • Detonation: ideal CJ detonation, no cellular structure, no detonation limits.
