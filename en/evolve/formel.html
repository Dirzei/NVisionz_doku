Symbolic regression – searching for formulas instead of coefficients

The methods behind Ausdruck and SymbolischeRegression: formulas as trees, genetic programming with tournament, subtree crossover and mutation, a size penalty against bloat and an unprotected evaluation, plus formulas as genes for MAP-Elites – with pseudocode following the source, two recovered laws, the checks and the limits.

What it is about

An ordinary regression fixes the form – line, polynomial, power law – and searches only the coefficients. Symbolic regression searches the form as well: from measurements (xj,yj)(x_j, y_j) a formula ff of variables, constants and operators with f(xj)≈yjf(x_j) \approx y_j. If the law behind the data is simple, it often finds it exactly, and the formula then extrapolates – which no neural network and no polynomial does. The method is genetic programming after Koza (1992): a population of formula trees that are selected by their quality and changed.

Formulas as trees: Ausdruck

Leaves are variables xix_i and constants from a pool (default 1 and 2), inner nodes +,−,×,/+, -, \times, / and \sqrt{\ }. A tree is immutable; size (number of nodes) and depth are fixed. Nodes are numbered in preorder – root 0, then the whole left subtree, then the right one –; crossover and mutation address nodes by these numbers.

The evaluation is unprotected: 1/01/0 gives infinity, −1\sqrt{-1} gives NaN. Many implementations protect division (a/0:=1a/0 := 1); the formula found then has a meaning that holds in no computation outside the search. Here a formula that is not finite at a single data point gets the score +∞+\infty and dies out.

At the end the best tree is simplified by fixed rules: fold constants, a+0a + 0, a⋅1a \cdot 1, a⋅0a \cdot 0, a−aa - a, a/aa / a (only for equal subtrees) and a/1a / 1. A fold that would not be finite (1/01/0) is not done. The simplified formula is checked against the data once more and only taken if it is as good – a/a→1a/a \to 1 does not hold where a=0a = 0.

The search: SymbolischeRegression

The score is the normalised error plus a size penalty,

s(f)=RMSE⁡(f)sd⁡(y)+γ|f|,RMSE⁡(f)=1n∑j(f(xj)−yj)2,s(f) = \frac{\mathrm{RMSE}(f)}{\mathrm{sd}(y)} + \gamma\,|f|, \qquad \mathrm{RMSE}(f) = \sqrt{\frac1n \sum_j (f(x_j) - y_j)^2},

with γ=10−3\gamma = 10^{-3} per node. The normalisation makes the score independent of the unit of yy; the penalty keeps the trees small, which otherwise grow with every crossover without getting better ("bloat"). Smaller is better.

Pseudocode – SymbolischeRegression.suche(x, y, e)

pop ← N trees, depth 2 … starttiefe in turn, alternately full and grown   ramped half-and-half
for g ← 1 to generationen:
    s[i] ← error(pop[i]) + γ·|pop[i]|           not finite → +∞
    remember the smallest tree with error < ziel
    if one has been known for nachlauf generations: stop
    new ← [best tree]                           elitism
    while |new| < N:
        p ← tournament(k)                       smallest s among k drawn
        with probability kreuzung:
            q ← tournament(k); child ← p with a random node replaced by a random subtree of q
        else:
            child ← p with a random node replaced by a new tree of depth 1 … 3
        new ← new + (child, if depth(child) ≤ hoechstTiefe, else p)
    pop ← new
return the smallest exact tree simplified, otherwise the one with the smallest error

Because the best tree passes on unchanged, the best score never rises from generation to generation. After the first exact hit the search runs on for nachlauf generations (default 20), because the first hit is rarely the shortest formula.

Both formulas hold far outside the range the data came from: that is the difference to a surrogate that only interpolates. The power 3/23/2 is not in the pool; the search assembles it from ×\times and \sqrt{\ }.

Formulas as genes: AusdruckMutationProposer

The same moves are also available to the quality-diversity search. An AusdruckGen describes a gene whose value is a formula: name, variable names, pool of constants, allowed operators and largest depth. In the genome the formula is stored as text in a lossless notation – every constant with all digits, every inner subexpression in parentheses –, so that reading and writing give the same tree. Chains without parentheses (a+b+ca + b + c) are ambiguous and rejected, as are nesting beyond 200 levels and a text longer than 100 000 characters.

The AusdruckMutationProposer is a proposal operator like those for numbers, structures and sequences and is mixed with them in the MixedProposer. Per child it changes exactly one expression gene: with probability kreuzung a random node is replaced by a random subtree of the same gene of a second parent, otherwise by a new tree of depth 1 to 3 – the same moves as in SymbolischeRegression, from a shared building block. All other genes stay as they are. A child deeper than allowed is drawn again up to ten times and is dropped otherwise; an unreadable or missing value is replaced by a random formula.

This gives an archive of formulas over a feature – such as size –: per cell the best formula of that size, i.e. a front of error against size. On f(x,y)=x2+yf(x, y) = x^2 + y with a numeric gene beside it, MAP-Elites with this operator finds the smallest exact formula y+(x⋅x)y + (x \cdot x) with five nodes; the numeric gene is untouched, a second run with the same seeds gives the same archive.

How it is checked

The Formelprobe (16 checks) computes its expected values by hand: value, size, depth, notation and preorder of the tree in the figure, replacing without changing the original, NaN and infinity under unprotected evaluation; five simplifications; the two laws above, checked at new points and by the size of the formula; on sin⁡x0+x13\sin x_0 + x_1^3 without sine in the pool: no exact hit, same seed same formula and same history, the best score never rises – also in a population of six trees with tournament size 1, where without elitism chance rules –, and the number of evaluations is population times generations; nine error cases. For the genes: reading and writing lossless on 300 random trees, also with 10−30010^{-300} and 1/31/3, ten unreadable texts rejected, nesting 199 read and 200 not; crossing a+ba + b with itself gives exactly the seven trees counted by hand, with kreuzung 0.5 the share of crossovers lies within the range of its binomial distribution; mutation of a tree of maximal depth stays within the depth; an unreadable value is replaced, the other genes stay; MAP-Elites with the operator in the MixedProposer as above; twelve error cases. Nine mutation checks (preorder, simplification a−aa - a, elitism, scoring of non-finite formulas, exact constants, depth limit when reading, donor subtree, other genes, depth of the child) are detected.

Limits

  • Constants only from the pool. Coefficients such as 9.819.81 arise only as compositions; fitting the constants with a gradient method is missing.
  • No noise in the target. With noisy data there is no exact hit; the tree with the smallest error is returned, and the penalty γ\gamma then decides the size. The search itself forms no front of error against size (see below).
  • Only five operators. Exponential, logarithm and trigonometric functions are missing; sin⁡x\sin x is only approximated.
  • Simple simplification. No expanding, no collecting of like terms; x+xx + x stays x+xx + x.
  • Error against size only via the archive. SymbolischeRegression itself returns one formula; a front of error against size arises only via MAP-Elites with the operator for expression genes, a non-dominated sorting as in multi-objective optimisation does not exist for formulas.
