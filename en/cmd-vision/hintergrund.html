Defaults, scale and return values

The computations live in the frameworks. This page covers what the command line decides itself: how many images it takes, how a known distance becomes a scale, when it replaces a file and what its return value says.

What this is about

The tool reads a stack of images and hands it to one of two computation paths. It checks the switches first, then the output files, and only then the source. A typing error therefore costs no computing time.

How many images

The two tasks need different stacks. rekonstruiere takes 30 images, every fifth one, because geometry needs distance between the views. pruefe takes 48 consecutive images, because the traces compare neighbouring images. Both defaults can be changed with -bilder: and -abstand:. Fewer than two images are rejected.

The numeric switches have lower limits: -von: 0, -abstand: 1, -bilder: 2, -aufloesung: 8, and -brennweite: must be at least 10−310^{-3} pixels.

From image to measure

Images alone do not fix the size of a scene. Only a known distance LL gives it a scale. -strecke: names the view, two image points, the length and optionally its uncertainty σL\sigma_L. Without the uncertainty,

σL=0.01L.\sigma_L = 0.01\,L .

The length must be positive. A word in place of a number gives return value 2 and names the switch.

-modell: fits a solid to the contours instead of a free surface and writes its dimensions to the report.

-paare: names, for the light trace, a point and its shadow as four numbers each.

Existing files

In a batch run there is nobody to ask. An existing file is therefore replaced only with -ueberschreiben. The check comes before the computation, so a long run does not fail at its very end.

What the return value says

The return value describes the run, not the result of the examination. A 0 from pruefe means all traces ran. It does not mean the material is genuine. The report contains no overall verdict; the findings are listed per trace.

ValueMeaningExample
0ran
1not readable or not writablemissing source, missing anchor
2wrong callunknown switch, invalid path, target exists
3nothing usable came outimages without texture, no mesh

Two stages of the examination

Without a further switch, pruefe runs all traces. -nur-stufe1 leaves out the camera pattern and double compression, the two traces that need the most images and computing time.

If point and shadow pairs are given, the light trace runs as well.

Limits

  • The computations themselves are not described here. They are covered by the video forensics app and the frameworks.
  • The private constructor and main, which only calls lauf, are not run by a probe.
  • People appear only as image regions. The tool does not recognise faces and says nothing about identity.
