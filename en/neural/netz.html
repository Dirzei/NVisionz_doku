The network – forward pass, backpropagation, activations

The computation behind NeuralNet, DenseLayer, Activation and Init: how a multilayer network turns inputs into outputs, how the gradient of the error with respect to every weight comes about, which activations and initial values exist and how dropout interferes – with pseudocode following the source, an example worked by hand, the checks and the limits. How the gradient becomes a training step is described on the pages Training and Optimisers.

What this is about

A compressor map assigns a pressure ratio and an efficiency to two quantities – say corrected mass flow and corrected speed. Measured or computed, it exists as a cloud of points; what is needed is a function that can be evaluated quickly anywhere. A multilayer network (multilayer perceptron, MLP) is such a function with many adjustable numbers, the weights. Training means setting the weights so that the function matches the points as closely as possible.

The network is built from layers. Each layer forms weighted sums of its inputs, adds an offset (bias) and passes the result through a nonlinear activation function. Without the nonlinearity a chain of layers would be nothing but a single linear map; with it, even one hidden layer of sufficient width can approximate any continuous function on a bounded domain to arbitrary accuracy.

The library follows the C library FANN in its layout: no neuron objects, but one flat array of all weights per layer. What is computed on it is modern: activations freely chosen per layer, initial values after He or Xavier, accumulating gradients for mini-batches, and dropout.

The forward pass

A layer with ninn_\text{in} inputs and noutn_\text{out} outputs has a weight matrix WW (nout×ninn_\text{out} \times n_\text{in}), a bias vector bb and an activation ff. From the input xx it computes

zo=bo+∑i=0nin−1Woixi,ao=f(zo),o=0,…,nout−1.z_o = b_o + \sum_{i=0}^{n_\text{in}-1} W_{oi}\, x_i, \qquad a_o = f(z_o), \qquad o = 0,\dots,n_\text{out}-1.

zz is called the pre-activation, aa the activation. The activations of layer kk are the input of layer k+1k+1; the output of the last layer is the output of the network. A network 2→16→16→32 \to 16 \to 16 \to 3 has three layers and (2⋅16+16)+(16⋅16+16)+(16⋅3+3)=371(2\cdot16+16) + (16\cdot16+16) + (16\cdot3+3) = 371 parameters – that is how parameterCount() counts.

Framework convention: The weights of a layer are stored row by row in a single array, w[o·in + i] is WoiW_{oi}. All buffers (zz, aa, δ\delta, gradients) are allocated when the network is built; the training loop allocates no memory. forward returns a reference to the internal output buffer, run a copy of it.

Backpropagation

Training needs the derivative of the error LL with respect to every weight. The chain rule delivers it in a single backward pass whose cost equals that of the forward pass. The key is the error signal δ=∂L/∂z\delta = \partial L / \partial z, the derivative with respect to the pre-activation. For a layer whose output aa receives the gradient ∂L/∂a\partial L / \partial a:

δo=∂L∂aof'(zo),∂L∂Woi=δoxi,∂L∂bo=δo,∂L∂xi=∑oWoiδo.\delta_o = \frac{\partial L}{\partial a_o}\, f'(z_o), \qquad \frac{\partial L}{\partial W_{oi}} = \delta_o\, x_i, \qquad \frac{\partial L}{\partial b_o} = \delta_o, \qquad \frac{\partial L}{\partial x_i} = \sum_o W_{oi}\, \delta_o .

The last quantity is the gradient with respect to the layer input – and therefore with respect to the output of the layer before it. The signal thus travels forward layer by layer: ∂L/∂a(k−1)=W(k)Tδ(k)\partial L / \partial a^{(k-1)} = W^{(k)T} \delta^{(k)}. At the network output the chain starts with the gradient of the loss function; for the mean squared error over mm outputs ∂L/∂yj=2(yj−tj)/m\partial L / \partial y_j = 2 (y_j - t_j)/m.

Why f'f' at zz rather than at aa? For the hyperbolic tangent and the sigmoid the derivative can also be written from the function value (1−a21 - a^2, a(1−a)a(1-a)); for SiLU it cannot. The uniform choice f'(z)f'(z) fits all six activations.

Pseudocode – DenseLayer.forward(x) and DenseLayer.backward(dLdA, x, dLdX)

function forward(x):
    for o ← 0 to out−1:
        s ← b[o]
        for i ← 0 to in−1:  s ← s + w[o·in + i] · x[i]
        z[o] ← s;   a[o] ← f(s)
    if a dropout mask is set:  a[o] ← a[o] · mask[o]  for all o
    return a                                   reference to the buffer

function backward(dLdA, x, dLdX):
    for o:  δ[o] ← dLdA[o] · (mask[o], if set) · f′(z[o])
    for o:                                     ACCUMULATE gradients (+=)
        gradB[o] ← gradB[o] + δ[o]
        for i:  gradW[o·in + i] ← gradW[o·in + i] + δ[o] · x[i]
    if dLdX ≠ none:                              omitted for the first layer
        dLdX ← 0
        for o, i:  dLdX[i] ← dLdX[i] + w[o·in + i] · δ[o]

Source: envisionz-framework-neural/src/de/envisionz/neural/core/DenseLayer.java. dLdX is computed with the weights before the optimiser step; the step only comes once all samples of a batch have been processed.

Pseudocode – NeuralNet.forward(x) and NeuralNet.backward(dLdOut)

function forward(x):
    check length(x) = inputs                         otherwise exception
    lastInput ← copy of x
    cur ← lastInput
    for each layer k:  cur ← layer[k].forward(cur)
    return cur

function backward(dLdOut):
    up ← dLdOut
    for k ← K−1 down to 0:
        input ← (k = 0) ? lastInput : layer[k−1].a
        down  ← (k = 0) ? none : buffer[k]
        layer[k].backward(up, input, down)
        up ← down

Source: envisionz-framework-neural/src/de/envisionz/neural/core/NeuralNet.java. backward always belongs to the sample last computed with forward – the layers only hold its zz and aa.

Framework convention: Gradients are accumulated, not overwritten. A mini-batch is therefore just a loop: zeroGrads(), forward and backward per sample, then scaleGrads(1/batch size) and one optimiser step. The same property carries sequence training with CTC, which runs backward once per time window (CTC). Forgetting zeroGrads() drags the gradient of the previous batch along.

Initial values

The weights start at random, normally distributed with mean 0; the bias starts at 0. What matters is the spread: too large, and TANH and SIGMOID saturate so the gradient vanishes; too small, and the signal shrinks from layer to layer. Both rules choose it so that the variance of the activations stays roughly constant across layers:

He:σW=2nin,Xavier (Glorot):σW=2nin+nout.\text{He:}\quad \sigma_W = \sqrt{\frac{2}{n_\text{in}}}, \qquad\qquad \text{Xavier (Glorot):}\quad \sigma_W = \sqrt{\frac{2}{n_\text{in} + n_\text{out}}}.

He accounts for RELU setting half of the values to zero and thereby halving the variance; the rule serves as the rule of thumb for the RELU family and SILU. Xavier is meant for TANH and SIGMOID, which are symmetric and linear around zero. For the network 2→16→16→32\to16\to16\to3 with Xavier the spreads are σ=0.333\sigma = 0.333, 0.2500.250 and 0.3240.324; with He the first layer would have σ=1.0\sigma = 1.0.

Framework convention: The default is Init.HE. All layers draw in turn from one random source seeded by seed(s). Without seed the builder uses System.nanoTime() – then the run cannot be repeated. ModelSearch chooses the rule itself: Xavier for TANH and SIGMOID, He otherwise.

Dropout

During training, dropout switches off each neuron of a hidden layer with probability pp. The network cannot rely on individual neurons and spreads what it learns more widely – a regularisation against memorising noisy data. The inverted form is implemented: the surviving neurons are amplified by 1/(1−p)1/(1-p) during training already,

mo={0with probability p11−potherwise,ao=mof(zo),δo=∂L∂aomof'(zo).m_o = \begin{cases} 0 & \text{with probability } p \\ \dfrac{1}{1-p} & \text{otherwise} \end{cases}, \qquad a_o = m_o\, f(z_o), \qquad \delta_o = \frac{\partial L}{\partial a_o}\, m_o\, f'(z_o).

The expected value of aoa_o during training is thus the same as without a mask, and nothing has to be rescaled at evaluation time: the mask is simply removed.

Framework convention: pp lies in [0,1)[0, 1), the output layer never has dropout. The Trainer draws new masks before every sample from a separate random source seeded with shuffleSeed ^ 0x64726f70 (the bytes of "drop") and removes them before evaluation and at the end. Runs without dropout do not draw a single extra random number and remain bit-identical to runs that do not know the feature. The rate is stored in the .ennet file.

Snapshot, copy, concurrency

snapshot() copies all weights and biases into an array [layer][0 = weights, 1 = bias][…]; restore(snap) writes them back and checks the dimensions. Early stopping returns to the best state this way. copy() builds a network of the same topology (with seed 0) and restores the snapshot into it – a deep copy with its own buffers.

Because each layer holds its buffers for exactly one sample, a network must not be evaluated by two threads at once. The rule is: one copy per thread. Model search does this (its own networks per candidate), and so does the sensitivity analysis in app-neural.

How it is checked

  • Gradient check (GradientCheck, part of TestMain): for every parameter the backward pass is compared with the central difference quotient (L(p+ε)−L(p−ε))/(2ε)(L(p+\varepsilon) - L(p-\varepsilon))/(2\varepsilon), ε=10−6\varepsilon = 10^{-6}; a largest relative error below 10−610^{-6} is required. Network 3–5–4–2 with four combinations (SILU/LINEAR, TANH/SIGMOID, LEAKY_RELU/LINEAR, RELU/TANH), plus softmax cross-entropy on linear logits and a network with a frozen dropout mask. One run gave largest relative errors between 7.3⋅10−97.3 \cdot 10^{-9} and 5.3⋅10−85.3 \cdot 10^{-8}.
  • XOR (TestMain [2]): network 2–8–1 (TANH, SIGMOID), SGD with learning rate 0.5 and momentum 0.9, 3000 epochs; all four outputs must be closer than 0.1 to the target. The classic proof that the hidden layer works – XOR is not linearly separable.
  • Dropout (TestMain [13]): training with p=0.2p = 0.2 on noisy data must reach R2>0.9R^2 > 0.9; afterwards two evaluations are bit-identical, and after saving and loading rates and outputs match bit for bit.

Limits

  • Fully connected layers only. No convolutional, no recurrent, no normalisation layers; for sequences the network is applied per time window (CTC).
  • Computation is scalar in double. For the typical surrogates that suffices: the module documentation measures about 1.9 million predictions per second for a 2–16–16–3 network; vectorisation would only yield about a factor of 2 from roughly 256 neurons per layer.
  • Not thread-safe (see above). copy() per thread.
  • RELU neurons can fall permanently silent; in small networks a silent neuron matters. LEAKY_RELU or SILU avoid this.
  • The bare network expects normalised inputs. Only the surrogate model works on raw physical values.
