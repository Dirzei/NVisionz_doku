Line recogniser

Reading a whole line at once without first cutting it into characters: convolutions turn the image into a sequence of columns, a transformer sees the sequence in context, and the CTC loss learns which column carries which character without anyone giving the position of the characters.

The net

The line is scaled to 32 pixels height; the width WW keeps its proportion and is padded with white to a multiple of 4 (at least 8). The input is the coverage (255−Y)/255(255 - Y)/255 with the luminance YY. Four convolutions with 3×3 kernels and ReLU, max pooling in between:

StageChannelsPooling (height × width)Size after
1k1k_12 × 216 × W/2
2k2k_22 × 2 (step 4) or 2 × 1 (step 2)8 × W/4 or 8 × W/2
3k3k_3—unchanged
4k3k_32 × 14 × W/s

Each column of the result is a vector of 4k34 k_3 features; the T=W/sT = W/s columns form the sequence. A linear layer brings them to width dd, and the sine positional encoding is added

Pt,i={sin⁡(tfi)i evencos⁡(tfi)i odd,fi=10000−2⌊i/2⌋/d.P_{t,i} = \begin{cases} \sin(t\,f_i) & i \text{ even} \\ \cos(t\,f_i) & i \text{ odd} \end{cases}, \qquad f_i = 10000^{-2\lfloor i/2\rfloor/d}.

Then a transformer encoder with RMSNorm and SwiGLU (from framework-autograd) and a linear layer onto the classes. The result are logits [T,K][T,\ K]: for every window a score for every class. The default plan is k=32/64/128k = 32/64/128, d=192d = 192, four layers.

Step 2 or 4

With step 4 a window covers four pixels of the line width. A narrow i or l at 32 pixels height often occupies only one window — and CTC needs an extra blank window between two equal characters. The most frequent residual errors were therefore omitted narrow letters. With step 2 the second pooling stage halves only the height; there are twice as many windows and the computation takes about 1.85 times as long. The weights do not depend on the step, so a model can be rebuilt into the other plan and trained on. A step of 3 is rejected: pooling knows only factors 1 and 2.

Classes and CTC

Class 0 is the CTC blank (“no new character here”), class 1 the word space, then the character set follows. The label of a line is the sequence of its classes; multiple spaces become one, characters outside the set are dropped.

A path π\pi assigns a class to every window. The map B\mathcal{B} merges equal consecutive classes and then deletes the blanks. The probability of a label yy is the sum over all paths that map onto it:

P(y∣x)=∑π:B(π)=y∏t=1Tpt(πt),LCTC⁡=−ln⁡P(y∣x),P(y \mid x) = \sum_{\pi:\ \mathcal{B}(\pi) = y}\ \prod_{t=1}^{T} p_t(\pi_t), \qquad L_{\mathrm{CTC}} = -\ln P(y \mid x),

with ptp_t the softmax of the logits in window tt. The sum is computed by the forward-backward recursion from framework-neural; it returns loss and gradient with respect to the logits, which go back into the autograd graph as an external loss. A label can only be represented if there are enough windows: one per character and one more for every repetition.

The same computation scores a reading: ln⁡P(y∣x)=−LCTC⁡\ln P(y\mid x) = -L_{\mathrm{CTC}} over all paths, with the same mask as the reading. The PDF digitiser uses it to pick the most probable of several readings of a number.

Greedy reading and confidence

Reading is greedy: the best class in every window, equal consecutive ones merged, blanks deleted — that is B\mathcal{B} on the best path. Then the word rules from framework-neural apply the probabilities of the window in which each character was chosen. Two numbers tell how reliable the reading is:

  • Confidence — the smallest probability of a character read. A single doubtful character makes the whole line uncertain; the mean would hide it.
  • Missed — the largest probability of another character in a blank window, excluding the character before and after (their tails are no evidence). A high value means: a character probably stood there that the reading omitted.

A line is uncertain when the confidence is below 0.5 or “missed” reaches 0.1. For number columns there is a digit mask: the same recogniser, whose logits for all disallowed characters are set to −∞-\infty before the choice; blank and word space stay. The net is not recomputed for it.

Training

Training runs on an endless stream of painted lines: font, size, stretch, letter spacing, margins and ageing drawn from the seed, each line used only once. A batch is spread over several threads, each with a copy of the net; the gradients are summed, the optimiser is Adam. The learning rate in step ss of SS:

η(s)=η0⋅min⁡(1,srun⁡+1300)⋅(0.05+0.95⋅12(1+cos⁡(πs/S))).\eta(s) = \eta_0 \cdot \min\!\Big(1, \frac{s_{\mathrm{run}}+1}{300}\Big) \cdot \Big(0.05 + 0.95 \cdot \tfrac12\big(1 + \cos(\pi\, s/S)\big)\Big).

The first 300 steps of a run warm up linearly (skipped when the optimiser state was saved with the model), then it falls as a cosine to 5 % of the default. The cosine is computed on the total step so that a continued run does not jump. Every few hundred steps the character error rate is measured on 64 fixed test lines and the model is saved.

Limits

  • Text below 14 pixels height is read clearly worse; it was not trained in the first run.
  • Greek look-alikes (ν/v, α/a) stay indistinguishable without context.
  • The greedy reading takes only the best path; the sum over all paths is computed only for given readings.
