Decision trees and ensembles – background

The computation behind Entscheidungsbaum, Zufallswald, GradientBoosting and Isolationswald: split search by Gini and sum of squares in one pass, bagging with feature sampling and the out-of-bag error, boosting as gradient descent in function space with Newton leaves, and outlier scores from the mean path length of random trees.

What it is about

A decision tree divides the feature space into axis-parallel rectangles and predicts a constant in each: the most frequent class or the mean. It needs no model form, copes with jumps and interactions and is readable – but it varies strongly with the data. Ensembles of many trees damp this: the random forest averages many independently perturbed trees, boosting fits small trees one after another to the residuals. The isolation forest uses trees differently: it measures how quickly random splits single out a point.

Split search (CART)

At each node, over all features (or, in the forest, over randomly chosen ones) and all thresholds between neighbouring distinct values, the split that lowers the impurity most is sought. With nkn_k points of class kk, the Gini impurity weighted by nn is

nG=n(1−∑kpk2)=n−∑knk2n,n\,G = n\Big(1 - \sum_k p_k^2\Big) = n - \frac{\sum_k n_k^2}{n},

and the best split minimises nlGl+nrGrn_l G_l + n_r G_r, i.e. maximises ∑knl,k2/nl+∑knr,k2/nr\sum_k n_{l,k}^2/n_l + \sum_k n_{r,k}^2/n_r. After sorting the feature, one point after another moves from right to left; the sums of squares change by 2nl,k+12n_{l,k} + 1 and −(2nr,k−1)-(2n_{r,k} - 1), so each feature is done in one pass (O(nlog⁡n)O(n\log n) including the sort). For regression the same holds with the sum of squares about the mean: SSEl⁡+SSEr⁡\mathrm{SSE}_l + \mathrm{SSE}_r is minimised, equivalently Tl2/nl+Tr2/nrT_l^2/n_l + T_r^2/n_r maximised with the partial sums TT. The threshold lies midway between the neighbouring values. Growth stops at maximum depth, with too few points or without gain; the decrease per split, summed over the nodes, is the importance of a feature.

Random forest

Each tree sees a bootstrap sample and at each node only mm randomly chosen features (default p\sqrt p for classification, p/3p/3 for regression). The averaged class proportions or the mean of the trees are predicted. For trees with correlation ρ\rho and variance σ2\sigma^2 the mean of BB trees has variance ρσ2+(1−ρ)σ2/B\rho\sigma^2 + (1-\rho)\sigma^2/B – feature sampling lowers ρ\rho. About a third (1−1/n)n→e−1(1 - 1/n)^n \to e^{-1} of the points is missing from each bootstrap sample; the trees in which a point was missing give the out-of-bag (OOB) error without a separate test set. Without bootstrap and with all features every tree equals the single tree.

Gradient boosting

Boosting builds FM(x)=F0+ν∑m=1Mhm(x)F_M(x) = F_0 + \nu\sum_{m=1}^M h_m(x) step by step: each tree hmh_m is fitted to the negative gradients of the loss at Fm−1F_{m-1} (pseudo-residuals), the learning rate ν≤1\nu \le 1 damps. With squared loss these are the residuals y−Fy - F, and F0F_0 is the mean. With logistic loss −[ylog⁡p+(1−y)log⁡(1−p)]-[y\log p + (1-y)\log(1-p)], p=1/(1+e−F)p = 1/(1 + e^{-F}), the pseudo-residuals are y−py - p, the start is F0=ln⁡(y/(1−y))F_0 = \ln(\bar y/(1 - \bar y)), and the value of a leaf RR is a Newton step

γR=∑i∈R(yi−pi)∑i∈Rpi(1−pi).\gamma_R = \frac{\sum_{i\in R}(y_i - p_i)}{\sum_{i\in R}p_i(1 - p_i)} .

With a fraction below 1 each tree sees only a subsample (stochastic boosting after Friedman 2002).

Isolation forest

Each tree is built from a subsample of ψ\psi points (default 256) with a random feature and a random threshold between minimum and maximum, up to height ⌈log2⁡ψ⌉\lceil\log_2\psi\rceil. Outliers are separated early and have short paths. The path length h(x)h(x) counts the edges to the leaf plus c(m)c(m) for the mm points still lying there; c(n)c(n) is the mean path length of an unsuccessful search in a binary search tree,

c(n)=2H(n−1)−2(n−1)n,c(1)=0,c(2)=1,s(x)=2−E[h(x)]/c(ψ).c(n) = 2H(n-1) - \frac{2(n-1)}{n}, \qquad c(1) = 0,\ c(2) = 1, \qquad s(x) = 2^{-E[h(x)]/c(\psi)} .

Values near 1 indicate outliers, values clearly below 0.5 normal points. The harmonic number H(i)H(i) is summed up to i=50i = 50, above that ln⁡i+γ+1/(2i)−1/(12i2)\ln i + \gamma + 1/(2i) - 1/(12i^2) (more accurate than the approximation ln⁡i+γ\ln i + \gamma of the original paper).

How it is checked

baum.Baumprobe (11 checks):

  • Gini by hand: best threshold, decrease 2.4−4/32.4 - 4/3 and leaf proportions (1/3,2/3)(1/3, 2/3).
  • XOR with 400 points without training error (a single split gains nothing for XOR – the tree has to search deeper); regression tree on a staircase with four steps exactly.
  • Forest without bootstrap and with all features equal to the single tree; random forest with OOB error; regression forest equal to the mean of its trees.
  • Boosting with squared loss decreasing monotonically; logistic: F0=ln⁡(p/(1−p))F_0 = \ln(p/(1-p)), initial loss equal to the entropy, and the Newton leaf values of a stump by hand (−2/3-2/3 and 1).
  • c(n)c(n) against the written-out sum; five outliers on a circle around 500 normally distributed points take ranks 1 to 5.
  • Error cases.

Four mutation checks spoil the update of the Gini sum, the right denominator of the sum of squares, the Newton denominator and c(n)c(n); all are detected.

Limits

  • Numeric features only (categories must be encoded by the caller), no missing values, no cost-complexity pruning.
  • The splits are axis-parallel – in the isolation forest too. A normal point in a sparsely populated corner can therefore get a higher score than an outlier lying along an axis between dense regions.
  • Importance by impurity decrease favours features with many distinct values.
