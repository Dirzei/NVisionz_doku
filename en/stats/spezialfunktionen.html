Special functions – background

The computation behind SpecialFunctions: the gamma function after Lanczos, digamma, the regularised incomplete gamma and beta functions by series and continued fraction, the error function. All distribution functions, and with them every p-value of the module, are built from these few functions.

What this is about

A test ends with a probability: how likely is a test statistic at least as large as the observed one if the null hypothesis holds? That needs the distribution function of the test statistic – for a t-test that of the t distribution, for an analysis of variance that of the F distribution, for a chi-squared test that of the chi-squared distribution. None of these functions has a closed form in elementary functions. All of them, however, reduce to two integrals:

  • the incomplete gamma function – it yields chi-squared, gamma, Poisson and, as a special case, the normal distribution,
  • the incomplete beta function – it yields t, F, beta, binomial and negative binomial.

Whoever can compute these two integrals to about 15 digits has the whole basis for p-values, critical values and confidence intervals. That is the job of SpecialFunctions. The class is deliberately small: six public function families, no tables apart from the Lanczos coefficients, pure JDK.

Framework convention: Every iteration in the class stops when a term becomes smaller than ε=10−15\varepsilon = 10^{-15} relative to the result, at the latest after 10 000 steps. Divisions by almost zero inside the continued fractions are caught by the floor 10−30010^{-300}. Invalid arguments (a≤0a \le 0, x<0x < 0, NaN) return NaN, not an exception; only regularizedBeta returns 0 for x≤0x \le 0 and 1 for x≥1x \ge 1.

Gamma function after Lanczos

The gamma function generalises the factorial: Γ(n)=(n−1)!\Gamma(n) = (n-1)! for natural nn, and in general

Γ(x)=∫0∞tx−1e−tdt,x>0\Gamma(x) = \int_0^\infty t^{x-1} e^{-t} \, dt, \qquad x > 0

In statistical formulas it almost always appears in quotients, for instance Γ(ν+12)/Γ(ν2)\Gamma(\frac{\nu+1}{2}) / \Gamma(\frac{\nu}{2}) in the density of the t distribution. Already at ν=400\nu = 400 numerator and denominator would be too large for a double. The module therefore works throughout with the logarithm ln⁡Γ(x)\ln\Gamma(x) and forms quotients as differences.

In 1964 Lanczos gave a representation that manages with a fixed short sum for all x>0x > 0. With a freely chosen constant gg

Γ(x+1)=2π(x+g+12)x+1/2e−(x+g+1/2)Sg(x),Sg(x)≈c0+∑i=114cix+i\Gamma(x+1) = \sqrt{2\pi}\,\left(x + g + \tfrac12\right)^{x+1/2} e^{-(x+g+1/2)}\; S_g(x), \qquad S_g(x) \approx c_0 + \sum_{i=1}^{14} \frac{c_i}{x+i}

Because Γ(x)=Γ(x+1)/x\Gamma(x) = \Gamma(x+1)/x, the logarithm with t=x+g+12t = x + g + \frac12 is

ln⁡Γ(x)=(x+12)ln⁡t−t+12ln⁡(2π)+ln⁡Sg(x)x\ln\Gamma(x) = \left(x+\tfrac12\right)\ln t - t + \tfrac12\ln(2\pi) + \ln\frac{S_g(x)}{x}

The module uses g=607/128g = 607/128 with 15 coefficients, the same set as Apache Commons Math. The sum SgS_g is added from back to front – the small terms first, so that they are not cut off against the large ones.

Negative arguments

For x≤0x \le 0 the reflection formula applies:

Γ(x)Γ(1−x)=πsin⁡(πx)⇒Γ(x)=πsin⁡(πx)eln⁡Γ(1−x)\Gamma(x)\,\Gamma(1-x) = \frac{\pi}{\sin(\pi x)} \quad\Rightarrow\quad \Gamma(x) = \frac{\pi}{\sin(\pi x)\; e^{\ln\Gamma(1-x)}}

At the poles x=0,−1,−2,…x = 0, -1, -2, \dots gamma returns NaN. logGamma itself is defined only for x>0x > 0.

Beta function

The beta function is a quotient of gamma functions and is also formed logarithmically:

ln⁡B(a,b)=ln⁡Γ(a)+ln⁡Γ(b)−ln⁡Γ(a+b),B(a,b)=eln⁡B(a,b)\ln B(a,b) = \ln\Gamma(a) + \ln\Gamma(b) - \ln\Gamma(a+b), \qquad B(a,b) = e^{\ln B(a,b)}

Digamma

The derivative ψ(x)=ddxln⁡Γ(x)\psi(x) = \frac{d}{dx}\ln\Gamma(x) is shifted by the recurrence ψ(x)=ψ(x+1)−1/x\psi(x) = \psi(x+1) - 1/x until x≥10x \ge 10, and evaluated there with the asymptotic series

ψ(x)≈ln⁡x−12x−112x2+1120x4−1252x6+1240x8\psi(x) \approx \ln x - \frac{1}{2x} - \frac{1}{12x^2} + \frac{1}{120x^4} - \frac{1}{252x^6} + \frac{1}{240x^8}

From x=10x = 10 on the next omitted term 1132x10\frac{1}{132x^{10}} is smaller than 10−1210^{-12}.

Pseudocode – logGamma(x), gamma(x), digamma(x)

function logGamma(x):
    if x NaN or x ≤ 0: return NaN
    s ← c[0]
    for i ← 14 down to 1:  s ← s + c[i]/(x+i)        small terms first
    t ← x + 607/128 + 0.5
    return (x+0.5)·ln t − t + ½·ln(2π) + ln(s/x)

function gamma(x):
    if x > 0: return exp(logGamma(x))
    if x is an integer: return NaN                   pole
    return π / (sin(πx) · exp(logGamma(1−x)))             reflection

function digamma(x):
    if x NaN or infinite: return x
    r ← 0
    while x < 10:  r ← r − 1/x;  x ← x + 1              ψ(x) = ψ(x+1) − 1/x
    u ← 1/x²
    return r + ln x − 0.5/x − u·(1/12 − u·(1/120 − u·(1/252 − u/240)))

The regularised incomplete gamma function

Cutting the gamma integral at xx gives the lower and the upper incomplete gamma function. Divided by Γ(a)\Gamma(a) they are called regularised and lie between 0 and 1:

P(a,x)=1Γ(a)∫0xta−1e−tdt,Q(a,x)=1Γ(a)∫x∞ta−1e−tdt=1−P(a,x)P(a,x) = \frac{1}{\Gamma(a)} \int_0^x t^{a-1} e^{-t}\,dt, \qquad Q(a,x) = \frac{1}{\Gamma(a)} \int_x^\infty t^{a-1} e^{-t}\,dt = 1 - P(a,x)

P(a,x)P(a,x) is exactly the distribution function of a gamma distribution with shape aa and scale 1. The chi-squared distribution with ν\nu degrees of freedom is P(ν/2,x/2)P(\nu/2, x/2).

Although P+Q=1P + Q = 1, one does not simply compute one of them and subtract it from 1. If QQ is very small – say 10−1210^{-12} in the tail of a distribution – then PP is 1−10−121 - 10^{-12}, and in double only four significant digits of QQ survive the subtraction. There are therefore two methods, and each computes directly whichever quantity is currently small.

Series for PP when x<a+1x < a + 1

Integration by parts gives the series

P(a,x)=xae−xΓ(a)∑n=0∞xna(a+1)⋯(a+n)P(a,x) = \frac{x^a e^{-x}}{\Gamma(a)} \sum_{n=0}^{\infty} \frac{x^n}{a(a+1)\cdots(a+n)}

The ratio of two consecutive terms is x/(a+n+1)x/(a+n+1). For x<a+1x < a+1 it is below 1 from the start, so the terms decrease at once. The prefactor xae−x/Γ(a)x^a e^{-x}/\Gamma(a) is formed as exp⁡(aln⁡x−x−ln⁡Γ(a))\exp(a\ln x - x - \ln\Gamma(a)), so that neither xax^a nor Γ(a)\Gamma(a) overflows.

Continued fraction for QQ when x≥a+1x \ge a + 1

For large xx the series converges slowly. There a continued fraction exists that converges very quickly for QQ:

Q(a,x)=xae−xΓ(a)⋅1x+1−a−1⋅(1−a)x+3−a−2⋅(2−a)x+5−a−⋯Q(a,x) = \frac{x^a e^{-x}}{\Gamma(a)} \cdot \frac{1}{x+1-a-\frac{1\cdot(1-a)}{x+3-a-\frac{2\cdot(2-a)}{x+5-a-\cdots}}}

A continued fraction has the problem that one does not know in advance how deep it must go. Evaluated from the bottom up, the depth would have to be fixed beforehand. The modified Lentz method instead evaluates it from the top down: it carries two auxiliary quantities CiC_i and DiD_i whose product is the ratio of two consecutive approximations:

Di=1bi+aiDi−1,Ci=bi+aiCi−1,hi=hi−1CiDiD_i = \frac{1}{b_i + a_i D_{i-1}}, \qquad C_i = b_i + \frac{a_i}{C_{i-1}}, \qquad h_i = h_{i-1}\, C_i D_i

with ai=−i(i−a)a_i = -i(i-a) and bi=x+2i+1−ab_i = x + 2i + 1 - a. As soon as |CiDi−1|<ε|C_i D_i - 1| < \varepsilon, another term no longer changes the value, and the iteration stops. If a denominator becomes zero it is replaced by a tiny number (10−30010^{-300}) – that is the “modification”, and it avoids a division by zero without falsifying the result.

Pseudocode – regularizedGammaP(a, x) and regularizedGammaQ(a, x)

function P(a, x):
    if a ≤ 0 or x < 0 or NaN: return NaN
    if x = 0: return 0
    if x ≥ a+1: return 1 − Q(a, x)                   continued-fraction region
    ap ← a;  term ← 1/a;  sum ← term
    for n ← 0 to 9999:
        ap ← ap + 1
        term ← term · x/ap
        sum ← sum + term
        if |term| < |sum|·1e−15: break
    return sum · exp(−x + a·ln x − logGamma(a))

function Q(a, x):
    if a ≤ 0 or x < 0 or NaN: return NaN
    if x = 0: return 1
    if x < a+1: return 1 − P(a, x)                   series region
    b ← x + 1 − a;  c ← 1/1e−300;  d ← 1/b;  h ← d      modified Lentz
    for i ← 1 to 9999:
        an ← −i·(i − a)
        b ← b + 2
        d ← an·d + b;   if |d| < 1e−300: d ← 1e−300
        c ← b + an/c;   if |c| < 1e−300: c ← 1e−300
        d ← 1/d
        δ ← d·c;  h ← h·δ
        if |δ − 1| < 1e−15: break
    return exp(−x + a·ln x − logGamma(a)) · h

Source: envisionz-framework-stats/src/envisionz/stats/core/SpecialFunctions.java, methods regularizedGammaP and regularizedGammaQ. The two methods call each other, but each only in the other's region; an endless loop is therefore impossible.

How fast this is shows a count with a copy of the two loops: Q(12,4)Q(\frac12, 4) needs 25 continued-fraction steps, Q(12,25)Q(\frac12, 25) only 8, Q(12,1.6)Q(\frac12, 1.6) close to the boundary 53. The series for P(12,1.4)P(\frac12, 1.4) needs 19 terms, for P(50,49)P(50, 49) it is 65. The number of steps grows with aa and is largest close to the boundary line – there both methods converge most slowly.

The regularised incomplete beta function

The second basic function is

Ix(a,b)=1B(a,b)∫0xta−1(1−t)b−1dt,0≤x≤1I_x(a,b) = \frac{1}{B(a,b)} \int_0^x t^{a-1}(1-t)^{b-1}\,dt, \qquad 0 \le x \le 1

It is the distribution function of the beta distribution. By transforming the argument it yields the t, F, binomial and negative binomial distributions (see Distributions).

Continued fraction

Here too there is a continued fraction that converges quickly as long as xx is not too large:

Ix(a,b)=xa(1−x)baB(a,b)⋅11+d11+d21+⋯I_x(a,b) = \frac{x^a (1-x)^b}{a\,B(a,b)} \cdot \frac{1}{1+\frac{d_1}{1+\frac{d_2}{1+\cdots}}}

with the terms

d2m+1=−(a+m)(a+b+m)x(a+2m)(a+2m+1),d2m=m(b−m)x(a+2m−1)(a+2m)d_{2m+1} = -\frac{(a+m)(a+b+m)\,x}{(a+2m)(a+2m+1)}, \qquad d_{2m} = \frac{m(b-m)\,x}{(a+2m-1)(a+2m)}

The code takes one even and one odd term per loop pass, both with the Lentz method as above. The first term d1d_1 with m=0m = 0 is contained in the initialisation D=1−(a+b)xa+1D = 1 - \frac{(a+b)x}{a+1}.

Symmetry

The continued fraction converges quickly for x<a+1a+b+2x < \frac{a+1}{a+b+2}, roughly the mean of the beta distribution. To the right of it one uses the reflection

Ix(a,b)=1−I1−x(b,a)I_x(a,b) = 1 - I_{1-x}(b,a)

and evaluates the continued fraction with swapped parameters at 1−x1-x. The prefactor xa(1−x)b/B(a,b)x^a(1-x)^b/B(a,b) is again formed logarithmically: exp⁡(aln⁡x+bln⁡(1−x)−ln⁡B(a,b))\exp(a\ln x + b\ln(1-x) - \ln B(a,b)).

Pseudocode – regularizedBeta(x, a, b) and betaCf

function I(x, a, b):
    if NaN or a ≤ 0 or b ≤ 0: return NaN
    if x ≤ 0: return 0;   if x ≥ 1: return 1
    front ← exp(a·ln x + b·ln(1−x) − logBeta(a, b))
    if x < (a+1)/(a+b+2):
        return front · betaCf(x, a, b) / a
    else
        return 1 − front · betaCf(1−x, b, a) / b         reflection

function betaCf(x, a, b):                              modified Lentz
    c ← 1;  d ← 1 − (a+b)·x/(a+1);  if |d| < 1e−300: d ← 1e−300;  d ← 1/d;  h ← d
    for m ← 1 to 9999:
        α ← m·(b−m)·x / ((a−1+2m)·(a+2m))                 even term
        d ← 1/(1 + α·d);  c ← 1 + α/c;  h ← h·d·c          |denominators| each ≥ 1e−300
        α ← −(a+m)·(a+b+m)·x / ((a+2m)·(a+1+2m))          odd term
        d ← 1/(1 + α·d);  c ← 1 + α/c
        δ ← d·c;  h ← h·δ
        if |δ − 1| < 1e−15: break
    return h

Source: envisionz-framework-stats/src/envisionz/stats/core/SpecialFunctions.java, methods regularizedBeta and betaCf (after Numerical Recipes, betacf).

Error function and complementary error function

The error function is a special case of the incomplete gamma function with a=12a = \frac12:

erf⁡(x)=2π∫0xe−t2dt=sgn⁡(x)P(12,x2),erfc⁡(x)=1−erf⁡(x)=Q(12,x2) for x≥0\operatorname{erf}(x) = \frac{2}{\sqrt\pi}\int_0^x e^{-t^2}\,dt = \operatorname{sgn}(x)\; P\left(\tfrac12, x^2\right), \qquad \operatorname{erfc}(x) = 1 - \operatorname{erf}(x) = Q\left(\tfrac12, x^2\right) \text{ for } x \ge 0

The normal distribution is Φ(z)=12erfc⁡(−z/2)\Phi(z) = \frac12\operatorname{erfc}(-z/\sqrt2). For z=−8z = -8, Φ(z)≈6.2⋅10−16\Phi(z) \approx 6.2\cdot10^{-16}. Computing erfc as 1−erf⁡1 - \operatorname{erf} would leave almost nothing of it because of cancellation. That was exactly the case until September 2026 (finding ST1): Φ(−8)\Phi(-8) was 1.8 % off, Φ(−9)\Phi(-9) was zero instead of 1.13⋅10−191.13\cdot10^{-19}.

Now erfc computes Q(12,x2)Q(\frac12, x^2) directly for positive xx. From x2≥1.5x^2 \ge 1.5 on that is the continued fraction, which computes the small quantity itself. For negative xx, erfc⁡(x)=2−erfc⁡(−x)\operatorname{erfc}(x) = 2 - \operatorname{erfc}(-x); the result then lies between 1 and 2, and nothing cancels.

Pseudocode – erf(x) and erfc(x)

function erf(x):
    if x = 0: return 0
    p ← P(½, x²)
    return x ≥ 0 ? p : −p

function erfc(x):
    if x NaN: return NaN
    if x < 0: return 2 − erfc(−x)            value in (1, 2], no cancellation
    if x = 0: return 1
    if x > 27: return 0                       erfc(27) < 1e−318; x² would overflow
    return Q(½, x²)

Source: envisionz-framework-stats/src/envisionz/stats/core/SpecialFunctions.java, methods erf and erfc; the comment in the code records the fix of ST1 on 2026-09-15.

Framework convention: erf still goes through PP and becomes 1 for large xx; whoever needs a small tail probability uses erfc or Normal.cdf for the lower and Normal.sf for the upper tail (since finding WT10; the p-values of the tests go through it). Recomputed: 1−erf⁡(5)1 - \operatorname{erf}(5) gives 1.53744⋅10−121.53744\cdot10^{-12}, erfc(5) gives 1.537459794⋅10−121.537459794\cdot10^{-12} – the first value has only four correct digits left.

Worked example: a p-value of the t distribution

We want P(T≤2)P(T \le 2) for a t distribution with ν=5\nu = 5 degrees of freedom, the value a t-test with t=2t = 2 needs for the upper side. StudentT.cdf computes

x=νν+t2=59≈0.5556,Ix(ν2,12)=I5/9(2.5,0.5)x = \frac{\nu}{\nu + t^2} = \frac{5}{9} \approx 0.5556, \qquad I_x\left(\tfrac{\nu}{2}, \tfrac12\right) = I_{5/9}(2.5,\, 0.5)

  1. Boundary for the reflection: a+1a+b+2=3.55=0.7\frac{a+1}{a+b+2} = \frac{3.5}{5} = 0.7. Since x=0.5556<0.7x = 0.5556 < 0.7, the continued fraction is evaluated directly.
  2. After 10 passes (one even and one odd term each) the continued fraction has reached the accuracy 10−1510^{-15} (counted with a copy of the loop).
  3. Result: I5/9(2.5,0.5)=0.101939478829858I_{5/9}(2.5,\,0.5) = 0.101939478829858.
  4. For t>0t > 0, F(t)=1−12I=0.949030260585071F(t) = 1 - \frac12 I = 0.949030260585071.

R gives pt(2, 5) = 0.9490302605850709; DistTest checks exactly this value to 10−910^{-9}. The two-sided p-value is 2(1−0.94903)=0.101942(1 - 0.94903) = 0.10194 – which is IxI_x itself again.

A second example, this time high up in the plane: erfc⁡(2)=Q(12,4)\operatorname{erfc}(2) = Q(\frac12, 4). Here x=4≥a+1=1.5x = 4 \ge a+1 = 1.5, so continued fraction; after 25 steps 0.004677734981047260.00467773498104726 is settled.

How it is checked

Two probe classes check SpecialFunctions, both without JUnit, each with its own main. The tolerance in Check.eq is mixed absolute-relative: deviation ≤tol⋅(1+|expected|)\le \text{tol}\cdot(1 + |\text{expected}|).

  • SpecialFunctionsTest (17 checks): ln⁡Γ(0.5)\ln\Gamma(0.5), ln⁡Γ(10)\ln\Gamma(10), Γ(5)=24\Gamma(5) = 24, Γ(0.5)=π\Gamma(0.5) = \sqrt\pi, Γ(−0.5)=−2π\Gamma(-0.5) = -2\sqrt\pi to 10−1010^{-10}; digamma at 1 and 10 to 10−910^{-9}; erf(1), erfc(1), erf(−0.5) to 10−1010^{-10}; P(3,5)P(3,5), Q(3,5)Q(3,5) and I0.5(2,3)=0.6875I_{0.5}(2,3) = 0.6875, I0.7(5,2)I_{0.7}(5,2) to 10−910^{-9}; P+Q=1P + Q = 1 and Ix(1,1)=xI_x(1,1) = x to 10−1010^{-10}.
  • Quantilprobe checks the new erfc at the critical places: Φ(−7)\Phi(-7), Φ(−8)\Phi(-8), Φ(−9)\Phi(-9) relatively to 10−1010^{-10} against reference values; erfc(1) and erfc(−1) to 10−1510^{-15}; continuity across the switch from series to continued fraction at x2=1.5x^2 = 1.5 (difference between the neighbouring numbers left and right ≤10−14\le 10^{-14}); the edge values erfc(0) = 1, erfc(+∞+\infty) = 0, erfc(−∞-\infty) = 2, erfc(30) = 0, erfc(NaN) = NaN.

The Quantilprobe was sharpened with counter-experiments: three deliberately broken versions of erfc (the old state 1−erf⁡1 - \operatorname{erf}, without the branch for negative xx, without the limit 27) each make it fail.

Limits

  • gamma(x) overflows for x>171.6x > 171.6 and returns +∞+\infty; logGamma stays finite. Formulas in the module therefore use logGamma/logBeta throughout.
  • digamma has no reflection for negative arguments; the recurrence pushes a negative xx step by step up to 10 – for x=−106x = -10^6 that is a million steps. At 0,−1,−2,…0, -1, -2, \dots the result is ±∞\pm\infty. Accuracy at x=0.5x = 0.5: deviation 4.5⋅10−134.5\cdot10^{-13} from −γ−2ln⁡2-\gamma - 2\ln 2 (recomputed).
  • For very large parameters (aa around 10610^6) series and continued fraction need many steps; the limit of 10 000 steps is then reached without any message. There is no asymptotic approximation (for instance after Temme) for this range.
  • The accuracy in the working range is about 10−1210^{-12} to 10−1510^{-15}; it is limited by ln⁡Γ\ln\Gamma in the prefactor, whose absolute error acts relatively through the exponent.
  • Callers that form p-values as 1−F1 - F lose digits in the upper tail even when FF itself is accurate. That affects some tests; see Parametric tests – limits.
