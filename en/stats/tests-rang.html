Rank tests and nonparametric methods – background

The computation behind NonparametricTests: ranks with ties, Mann-Whitney U, Wilcoxon signed rank, sign test, Kruskal-Wallis, Friedman, Mood's median and the runs test – with the normal approximations, tie and continuity corrections exactly as in the code.

What this is about

The t-tests and the analysis of variance assume normally distributed data. Many technical quantities are not: lifetimes are skewed, roughness values bounded below, ratings on a scale from 1 to 5 not metric at all. Rank tests replace each value by its rank – its place in the sorted sequence – and compute only with these places.

That has three consequences: the distribution of the test statistic no longer depends on the data distribution (hence “distribution-free”); a single extreme value acts only as the largest rank, not with its magnitude; and for data that really are normal one loses surprisingly little – Mann-Whitney has an asymptotic relative efficiency of 3/π≈0.9553/\pi \approx 0.955 relative to the t-test there.

Framework convention: All rank tests except the sign test compute the p-value by the normal or chi-squared approximation, even for small samples. There are no exact distributions. Mann-Whitney and Wilcoxon use a continuity correction of ½ and a tie correction of the variance; Kruskal-Wallis a tie correction; Friedman, Mood's median and the runs test none.

Ranks and ties

Equal values (ties) receive the average of the ranks they occupy together. For {3.1;2.0;3.1;5.2}\{3.1;\ 2.0;\ 3.1;\ 5.2\} that is 3.5;1;3.5;43.5;\ 1;\ 3.5;\ 4.

Ties reduce the variance of the rank sums. All corrections use the same quantity: for each group of tt equal values one counts t3−tt^3 - t and sums:

T=∑tie groups(t3−t)T = \sum_{\text{tie groups}} (t^3 - t)

function ranks(v):
    idx ← indices 0…n−1, sorted by v
    i ← 0
    while i < n:
        j ← i
        while j+1 < n and v[idx[j+1]] = v[idx[i]]: j ← j + 1
        r ← (i + j + 2)/2                           mean of ranks i+1 … j+1
        for t ← i to j: rank[idx[t]] ← r
        i ← j + 1
    return rank

function tieSum(v):  Σ over groups of equal values of (t³ − t)

Mann-Whitney U (Wilcoxon rank-sum test)

Two independent samples. All N=n1+n2N = n_1 + n_2 values are ranked together and the ranks of the first group are summed to R1R_1. Then

U=R1−n1(n1+1)2U = R_1 - \frac{n_1(n_1+1)}{2}

is the number of pairs (xi,yj)(x_i, y_j) with xi>yjx_i > y_j (ties counted half). Under H0H_0 – both groups from the same distribution –

E(U)=n1n22,Var⁡(U)=n1n212((N+1)−TN(N−1))E(U) = \frac{n_1 n_2}{2}, \qquad \operatorname{Var}(U) = \frac{n_1 n_2}{12}\left((N+1) - \frac{T}{N(N-1)}\right)

and the standardised test statistic with continuity correction

z=U−E(U)−12sgn⁡(U−E(U))Var⁡(U)z = \frac{U - E(U) - \tfrac12\operatorname{sgn}(U - E(U))}{\sqrt{\operatorname{Var}(U)}}

is evaluated with the standard normal distribution, one- or two-sided depending on the alternative. The correction 12\frac12 accounts for UU taking only whole or half values. The reported test statistic is UU, like W in R.

Wilcoxon signed-rank test

One sample against a location parameter μ\mu – or paired data, then applied to the differences. Differences di=xi−μd_i = x_i - \mu equal to zero are discarded; nn values remain. One ranks |di||d_i| and sums the ranks of the positive differences:

V=∑di>0rank⁡|di|,E(V)=n(n+1)4,Var⁡(V)=n(n+1)(2n+1)24−T48V = \sum_{d_i > 0} \operatorname{rank}|d_i|, \qquad E(V) = \frac{n(n+1)}{4}, \qquad \operatorname{Var}(V) = \frac{n(n+1)(2n+1)}{24} - \frac{T}{48}

The test statistic zz is formed as for Mann-Whitney with continuity correction ½.

Sign test

The simplest test for the median: one counts values above μ\mu (k+k_+) and below μ\mu (k−k_-); values equal to μ\mu are dropped. Under H0H_0, k+k_+ is binomially distributed with n=k++k−n = k_+ + k_- and p=12p = \frac12. The p-value is exact:

Alternativep-value
greaterP(K≥k+)=1−FBin(k+−1)P(K \ge k_+) = 1 - F_\text{Bin}(k_+ - 1)
lessP(K≤k+)=FBin(k+)P(K \le k_+) = F_\text{Bin}(k_+)
two.sidedmin⁡(1,2FBin(min⁡(k+,k−)))\min(1,\ 2F_\text{Bin}(\min(k_+, k_-)))

The sign test uses only the direction, not the distance, and is therefore weaker than Wilcoxon – in return it does not even assume symmetry.

Kruskal-Wallis and Friedman

Kruskal-Wallis: kk independent groups

The rank version of the one-way analysis of variance. With joint ranks, rank sums RiR_i per group and NN values in total:

H=12N(N+1)∑i=1kRi2ni−3(N+1)1−TN3−NH = \frac{\dfrac{12}{N(N+1)}\sum_{i=1}^{k}\frac{R_i^2}{n_i} - 3(N+1)}{1 - \dfrac{T}{N^3 - N}}

Under H0H_0, HH is approximately chi-squared distributed with k−1k - 1 degrees of freedom; p=1−Fχ2(H)p = 1 - F_{\chi^2}(H).

Friedman: kk treatments in bb blocks

The rank version of the repeated-measures analysis of variance: each block (for instance a specimen) is measured under all kk conditions; ranking is done within each block. With the column sums RjR_j of the ranks:

Q=12bk(k+1)∑j=1kRj2−3b(k+1),ν=k−1Q = \frac{12}{b\,k(k+1)}\sum_{j=1}^{k} R_j^2 - 3b(k+1), \qquad \nu = k-1

function kruskalWallis(groups):
    r ← ranks(all values in sequence)
    H ← Σᵢ (rank sum of group i)² / nᵢ
    H ← 12/(N(N+1))·H − 3(N+1)
    H ← H / (1 − tieSum(all)/(N³ − N))              tie correction
    p ← 1 − F_χ²(H; k−1)

function friedman(data[b][k]):
    for each block: r ← ranks(block);  colSum[j] += r[j]
    Q ← 12/(b·k·(k+1)) · Σⱼ colSum[j]² − 3b(k+1)       without tie correction
    p ← 1 − F_χ²(Q; k−1)

Mood's median test and runs test

Mood's median

One determines the common median of all values and counts per group how many values lie above it and how many below or equal. That gives a 2×k2\times k table to which a chi-squared independence test without continuity correction is applied (ν=k−1\nu = k-1). Values equal to the median count towards the lower row. The test is more robust than Kruskal-Wallis but weaker.

Runs test (Wald-Wolfowitz)

Is a series of measurements arranged randomly, or are there trends or oscillations? Each value is marked “+” (above the median) or “−” (below); values equal to the median are dropped. A run is a sequence of equal signs. Too few runs point to trends or clusters, too many to regular alternation. With n1n_1 plus signs, n2n_2 minus signs and N=n1+n2N = n_1 + n_2:

E(R)=2n1n2N+1,Var⁡(R)=2n1n2(2n1n2−N)N2(N−1),z=R−E(R)Var⁡(R)E(R) = \frac{2n_1 n_2}{N} + 1, \qquad \operatorname{Var}(R) = \frac{2n_1 n_2\,(2n_1 n_2 - N)}{N^2(N-1)}, \qquad z = \frac{R - E(R)}{\sqrt{\operatorname{Var}(R)}}

two-sided via the normal distribution, without continuity correction.

How it is checked

NonparametricTest (11 checks):

  • Mann-Whitney for odd against even numbers from 1…10: U=10U = 10 exactly, p in (0,1](0, 1].
  • Wilcoxon for 1…10 against 5: V=27V = 27 (the zero at 5 is dropped, ties in |d||d|).
  • Sign test with 8 plus and 2 minus: p=0.109375p = 0.109375 exactly to 10−910^{-9}.
  • Kruskal-Wallis for three separated groups: H=7.2H = 7.2, ν=2\nu = 2, p=0.0273237p = 0.0273237 to 10−610^{-6}.
  • Friedman with identical block ranks: Q=6Q = 6, p=0.0497871p = 0.0497871 to 10−610^{-6}.
  • Mood's median and runs test: plausibility only (statistic ≥0\ge 0, p in (0,1](0, 1]).

Limits

  • No exact p-values for Mann-Whitney and Wilcoxon. For small samples (below about 10 per group) the normal approximation differs from R, which computes exactly when there are no ties.
  • Friedman has no tie correction; with many equal values within the blocks the test is conservative.
  • Mood's median and the runs test are only checked for plausibility, not against reference values.
  • No confidence interval and no Hodges-Lehmann estimator for the location shift; the estimate in the result is the statistic itself (for Mood's median the common median, for the sign test the fraction k+/nk_+/n).
  • Rank tests do not test “equal medians” but equal distributions; with different shapes (for instance unequal spread) they can reject even when the medians are equal.
