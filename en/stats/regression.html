Regression – background

The computation behind Regression, LinearModel and Glm: least squares via the QR decomposition with full diagnostics, polynomial and VIF, ridge and lasso, robust regression after Huber, quantile regression, LOESS, nonlinear fitting after Levenberg-Marquardt, logistic and Poisson regression via IRLS.

What this is about

A regression describes how a response yy depends on one or more predictors xx, and estimates the parameters of this relation from data. The linear model is

yi=β0+β1xi1+…+βpxip+εi,in shorty=Xβ+εy_i = \beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip} + \varepsilon_i, \qquad \text{in short}\quad y = X\beta + \varepsilon

“Linear” means linear in the parameters β\beta, not in xx: a polynomial β0+β1x+β2x2\beta_0 + \beta_1 x + \beta_2 x^2 is a linear model. XX is the design matrix with nn rows and kk columns; with an intercept the first column is all ones.

The methods on this page differ in what they minimise:

Least squares

The solution of minβ⁡‖y−Xβ‖2\min_\beta \|y - X\beta\|^2 satisfies the normal equations XTXβ=XTyX^TX\beta = X^Ty. Solving them directly, however, squares the condition number of XX: for badly conditioned designs (higher-degree polynomials, predictors in very different units) half the digits are lost. The module therefore computes via the Householder QR decomposition X=QRX = QR: with QTyQ^Ty, β\beta follows from the triangular system Rβ=(QTy)1..kR\beta = (Q^Ty)_{1..k} by back substitution.

Polynomial and VIF

polynomial(x, y, degree) forms the columns x,x2,…,xdegreex, x^2, \dots, x^\text{degree} as raw powers and calls ols. The variance inflation factor of a predictor jj is

VIFj⁡=11−Rj2\mathrm{VIF}_j = \frac{1}{1 - R_j^2}

with Rj2R_j^2 from the regression of xjx_j on all other predictors. It tells by what factor the variance of β^j\hat\beta_j is inflated by collinearity; values above 10 are considered critical.

Ridge and lasso

Ridge

Ridge adds λ\lambda to the diagonal of the normal equations, except for the intercept:

(XTX+λI')β=XTy,I'=diag⁡(0,1,…,1)(X^TX + \lambda I')\,\beta = X^Ty, \qquad I' = \operatorname{diag}(0, 1, \dots, 1)

This pulls all coefficients towards zero and stabilises the solution under collinearity. It is solved with the LU decomposition. The predictors are not standardised; λ\lambda therefore acts with different strength depending on the unit of a quantity.

Lasso

Lasso penalises the absolute values. Unlike ridge it sets coefficients to exactly zero and thereby selects predictors. There is no closed-form solution; the module uses cyclic coordinate descent on standardised predictors zij=(xij−xj)/σjz_{ij} = (x_{ij} - \bar x_j)/\sigma_j (population standard deviation, denominator nn) and centred yy. For a single coordinate the problem has a closed-form solution – the soft-threshold function:

βj←S(1n∑izij(ri+zijβj),λ),S(a,λ)=sgn⁡(a)max⁡(|a|−λ,0)\beta_j \leftarrow S\left(\frac1n\sum_i z_{ij}\,(r_i + z_{ij}\beta_j),\ \lambda\right), \qquad S(a, \lambda) = \operatorname{sgn}(a)\max(|a| - \lambda,\ 0)

Because 1n∑zij2=1\frac1n\sum z_{ij}^2 = 1, no further denominator is needed. After every change the residuals rr are updated. The iteration stops when the largest change in a sweep is below 10−910^{-9} or maxIter is reached. Finally the coefficients are transformed back to the original scale: βjorig=βj/σj\beta_j^\text{orig} = \beta_j/\sigma_j, β0=y−∑jβjorigxj\beta_0 = \bar y - \sum_j \beta_j^\text{orig}\bar x_j.

z ← standardised columns (denominator n);  r ← y − ȳ;  b ← 0
repeat up to maxIter:
    max ← 0
    for j ← 1 to p:
        ρ ← Σᵢ z[i][j]·(r[i] + z[i][j]·b[j])
        new ← S(ρ/n, λ)
        r ← r − z[·][j]·(new − b[j])                   update residuals
        max ← max(max, |new − b[j]|);  b[j] ← new
    if max < 1e−9: break
return [ȳ − Σ b[j]/σ[j]·x̄[j],  b[1]/σ[1], …]

Robust regression and quantile regression

Both are solved by iteratively reweighted least squares (IRLS): starting from the ordinary solution one computes residuals, from them weights wiw_i, solves the weighted problem (XTWX)β=XTWy(X^TWX)\beta = X^TWy and repeats.

Huber

The Huber loss is quadratic for small residuals and linear for large ones. That corresponds to the weights

wi=min⁡(1,c|ri|/s),s=1.4826⋅median⁡|ri−median⁡(r)|w_i = \min\left(1,\ \frac{c}{|r_i|/s}\right), \qquad s = 1.4826\cdot\operatorname{median}|r_i - \operatorname{median}(r)|

with the robust scale estimate ss from the MAD of the residuals, recomputed every round. The catalogue uses c=1.345c = 1.345 and 50 rounds; with normally distributed errors the estimator then has 95 % of the efficiency of least squares. The iteration stops when no coefficient changes by more than 10−910^{-9} or s=0s = 0.

Quantile regression

The loss τr\tau r for r≥0r \ge 0, (1−τ)|r|(1-\tau)|r| for r<0r < 0 can be written as a weighted square by setting wi=τ/|ri|w_i = \tau/|r_i| or (1−τ)/|ri|(1-\tau)/|r_i|. So that no weight becomes infinite, |ri||r_i| is bounded below by 10−610^{-6}. The iteration stops at changes below 10−810^{-8}.

Framework convention: Quantile regression via IRLS is an approximation; the exact method would be linear programming (Barrodale-Roberts or interior-point methods as in R quantreg). The floor 10−610^{-6} makes the result inaccurate to about that order near data points through which the exact solution passes.

LOESS

LOESS fits a separate straight line through the neighbourhood of each point xix_i. The neighbourhood consists of the q=max⁡(2,⌈span⋅n⌉)q = \max(2, \lceil\text{span}\cdot n\rceil) nearest points; hh is the distance of the qq-th nearest. The weights follow the tricube kernel

wj=(1−(|xj−xi|h)3)3 for |xj−xi|<h, else 0w_j = \left(1 - \left(\frac{|x_j - x_i|}{h}\right)^3\right)^3 \text{ for } |x_j - x_i| < h, \text{ else } 0

and the weighted line is computed in closed form from the weighted sums ∑w\sum w, ∑wx\sum wx, ∑wy\sum wy, ∑wx2\sum wx^2, ∑wxy\sum wxy. If their determinant is almost zero (all neighbours at the same xx), the weighted mean is taken. The result is the smoothed curve at the original xx. The catalogue uses span=0.5\text{span} = 0.5.

Framework convention: LOESS here is locally linear, one-dimensional and without Cleveland's robustness iterations (which down-weight outliers in R lowess). R loess works locally quadratic by default and interpolates on a grid; the results therefore differ.

Nonlinear fitting

nls(x, y, f, p0) fits an arbitrary model y=f(θ,x)y = f(\theta, x), for instance aebxa\,e^{bx}. Levenberg-Marquardt (from framework-math) blends Gauss-Newton and gradient descent: in each step it solves

(JTJ+λdiag⁡(JTJ))δ=−JTr(J^TJ + \lambda\,\operatorname{diag}(J^TJ))\,\delta = -J^Tr

with the Jacobian JJ of the residuals from forward differences (step 10−7(|θa|+10−7)10^{-7}(|\theta_a| + 10^{-7})). If the sum of squares decreases, the step is accepted and λ\lambda is multiplied by 0.3 (towards Gauss-Newton); otherwise λ\lambda is multiplied by ten (towards the gradient), up to 12 attempts per step. The initial value is λ=10−3\lambda = 10^{-3}. The iteration stops at a relative improvement below 10−1210^{-12} or after 200 steps. The start value p0p_0 must be near the solution; a global optimum is not guaranteed.

Logistic and Poisson regression

For a yes/no response (y∈{0,1}y ∈ \{0, 1\}) or a count (y=0,1,2,…y = 0, 1, 2, \dots) the linear model does not fit: predictions outside [0,1][0, 1] or negative counts would be possible, and the spread depends on the mean. A generalised linear model connects the linear predictor η=Xβ\eta = X\beta with the expected value μ\mu through a link function:

ModelLinkμ(η)\mu(\eta)Weight w=Var⁡(μ)w = \operatorname{Var}(\mu)
logisticln⁡μ1−μ\ln\frac{\mu}{1-\mu}1/(1+e−η)1/(1 + e^{-\eta})μ(1−μ)\mu(1-\mu)
Poissonln⁡μ\ln\mueηe^\etaμ\mu

With these canonical links Newton's method for the log-likelihood is the same as IRLS with the “working variable”

zi=ηi+yi−μiwi,β←(XTWX)−1XTWzz_i = \eta_i + \frac{y_i - \mu_i}{w_i}, \qquad \beta \leftarrow (X^TWX)^{-1}X^TWz

The deviance is twice the log-likelihood distance to the saturated model:

Dlogit=2∑i(yiln⁡yiμi+(1−yi)ln⁡1−yi1−μi),DPoisson=2∑i(yiln⁡yiμi−(yi−μi))D_\text{logit} = 2\sum_i\left(y_i\ln\frac{y_i}{\mu_i} + (1-y_i)\ln\frac{1-y_i}{1-\mu_i}\right), \qquad D_\text{Poisson} = 2\sum_i\left(y_i\ln\frac{y_i}{\mu_i} - (y_i - \mu_i)\right)

with 0ln⁡0=00\ln0 = 0. The difference between null deviance and deviance is chi-squared distributed with k−1k-1 degrees of freedom and tests the model as a whole; the caller computes that. The Poisson log-likelihood contains −ln⁡(yi!)-\ln(y_i!) via logGamma.

How it is checked

RegressionTest (28 checks):

  • Line against R lm: coefficients, standard errors, t, p, R2R^2, adjusted R2R^2, σ^\hat\sigma, AIC (to 10−510^{-5} to 10−710^{-7}), prediction at x=6x = 6 and ∑hii=k\sum h_{ii} = k.
  • Rank deficiency: columns xx and 2x2x as well as a constant column next to the intercept each lead to an IllegalArgumentException with “rangdefekt” in the message.
  • Second-degree polynomial through y=x2y = x^2: R2=1R^2 = 1, quadratic coefficient 1.
  • Ridge with λ=0\lambda = 0 equals least squares, with λ=106\lambda = 10^6 slope below 10−310^{-3}; lasso with λ=0\lambda = 0 equals least squares to 10−410^{-4}, with λ=100\lambda = 100 slope exactly 0.
  • Huber and median regression plausibly close to least squares; LOESS reproduces a straight line to 10−610^{-6}.
  • NLS: 2e0.3x2e^{0.3x} recovered from the start (1;0.1)(1;\ 0.1) to 10−410^{-4}.
  • GLM: logistic with balanced data coefficients near 0 and prediction 0.5; Poisson with constant y=2y = 2 intercept ln⁡2\ln 2 to 10−610^{-6}.

Limits

  • With rank deficiency (a column is a linear combination of others or constant next to the intercept) the QR decomposition or the inversion of XTXX^TX returns null, and ols stops with an IllegalArgumentException (“Designmatrix rangdefekt …”); there is no automatic column selection as in R. Until finding WT12 it was a NullPointerException. Only exact singularity is detected; a nearly collinear design computes through, with large standard errors.
  • The standard errors come from the explicit inverse of XTXX^TX – for badly conditioned designs (polynomials of degree 4 to 6 with raw powers; the catalogue allows up to 6) they are less accurate than the coefficients. There are no orthogonal polynomials.
  • Robust, quantile, ridge and lasso regression return only coefficients, no standard errors and no p-values.
  • Logistic regression with completely separable data: the coefficients grow until the 10−1010^{-10} bounds on μ\mu take effect or 100 steps are reached; there is no warning.
  • GLM p-values are Wald tests; likelihood-ratio tests have to be formed by the caller from the deviance. No overdispersion for Poisson.
  • LOESS is O(n2log⁡n)O(n^2\log n) (for every point all distances are sorted).
