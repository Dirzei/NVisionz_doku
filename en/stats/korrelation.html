Correlation – background

The computation behind Correlation: Pearson with t-test and Fisher z interval, Spearman, Kendall's τb\tau_b, partial correlation via the precision matrix, autocorrelation and partial autocorrelation after Durbin-Levinson.

What this is about

Two quantities are associated if large values of one go along with large (or small) values of the other. A correlation coefficient condenses this into one number between −1 and +1. The three built-in coefficients measure different things:

Coefficientmeasuressensitive to outliers
Pearson rrlinear associationstrongly
Spearman ρ\rhomonotone association (Pearson of the ranks)little
Kendall τb\tau_bexcess of concordant over discordant pairslittle

y=x3y = x^3 on [0,1][0, 1] has Spearman and Kendall equal to 1, Pearson below 1. y=x2y = x^2 on [−1,1][-1, 1] has all three near 0, although yy depends entirely on xx – correlation captures only same-direction associations. And correlation is not causation: two quantities that both depend on the ambient temperature correlate without influencing each other. That is what partial correlation is for.

Pearson: coefficient, test and interval

r=∑i(xi−x)(yi−y)∑i(xi−x)2∑i(yi−y)2r = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum_i (x_i - \bar x)^2\,\sum_i (y_i - \bar y)^2}}

computed in two passes (means first, then deviation products). The test of H0:ρ=0H_0: \rho = 0 uses that for independent normally distributed quantities

t=rn−21−r2t = r\sqrt{\frac{n-2}{1-r^2}}

is t distributed with n−2n-2 degrees of freedom. This is the same test statistic as the t value of the slope in a simple linear regression.

Fisher z interval

rr itself is strongly skewed near ±1\pm1. Fisher's transformation makes it approximately normal with a known spread:

zr=12ln⁡1+r1−r=artanhr,se(zr)=1n−3z_r = \tfrac12\ln\frac{1+r}{1-r} = \operatorname{artanh} r, \qquad \operatorname{se}(z_r) = \frac{1}{\sqrt{n-3}}

The interval is formed in zz and transformed back with tanh\operatorname{tanh}:

[tanh(zr−1.96se),tanh(zr+1.96se)]\left[\operatorname{tanh}(z_r - 1.96\,\operatorname{se}),\ \operatorname{tanh}(z_r + 1.96\,\operatorname{se})\right]

It is therefore asymmetric around rr and always stays within (−1,1)(-1, 1).

r ← pearson(x, y);  df ← n − 2
t ← r·√(df/(1 − r²))
p ← 2·(1 − F_t(|t|; df))                          always two-sided
z ← ½·ln((1 + r)/(1 − r));  se ← 1/√(n − 3)
zc ← Φ⁻¹(0.975)
CI ← [tanh(z − zc·se), tanh(z + zc·se)]            always 95 %

Source: envisionz-framework-stats/src/envisionz/stats/correlation/Correlation.java, methods pearson and pearsonTest.

Spearman and Kendall

Spearman

ρ\rho is the Pearson coefficient of the ranks (average ranks for ties, see Ranks). The test uses the same t approximation as Pearson, t=ρ(n−2)/(1−ρ2)t = \rho\sqrt{(n-2)/(1-\rho^2)} with n−2n-2 degrees of freedom – R computes exactly for small nn without ties.

Kendall τb\tau_b

For all n(n−1)/2n(n-1)/2 pairs (i,j)(i, j) one checks whether xx and yy move in the same direction (concordant, ncn_c), in opposite directions (discordant, ndn_d) or whether there is a tie. With n0=n(n−1)/2n_0 = n(n-1)/2 and the numbers txt_x, tyt_y of pairs tied in xx and in yy:

τb=nc−nd(n0−tx)(n0−ty)\tau_b = \frac{n_c - n_d}{\sqrt{(n_0 - t_x)(n_0 - t_y)}}

The test uses the normal approximation for the case without ties:

z=τ2(2n+5)9n(n−1)z = \frac{\tau}{\sqrt{\frac{2(2n+5)}{9n(n-1)}}}

nc, nd, tx, ty ← 0
for i < j:
    s ← sgn(xᵢ − xⱼ)·sgn(yᵢ − yⱼ)
    s > 0: nc++;   s < 0: nd++
    s = 0: if xᵢ = xⱼ: tx++;  if yᵢ = yⱼ: ty++     pairs tied in both count in both
n0 ← n(n−1)/2
τ ← (nc − nd)/√((n0 − tx)(n0 − ty))

Source: envisionz-framework-stats/src/envisionz/stats/correlation/Correlation.java, methods spearman, spearmanTest, kendallTau, kendallTest. Cost O(n2)O(n^2).

Partial correlation

The partial correlation of two quantities is their association after the linear influence of all other quantities has been removed. It can be formed via regressions (correlation of the residuals); more convenient is the precision matrix P=R−1P = R^{-1}, the inverse of the correlation matrix:

rij⋅rest=−PijPiiPjjr_{ij\cdot\text{rest}} = -\frac{P_{ij}}{\sqrt{P_{ii}P_{jj}}}

partialMatrix returns all pairs at once; the diagonal is 1. The inverse comes from the LU decomposition of framework-math. If RR is singular (one quantity is a linear combination of others), there is no inverse.

Autocorrelation and partial autocorrelation

For a time series one asks how strongly a value is associated with the value kk steps earlier. With the overall mean x\bar x:

ck=1n∑t=1n−k(xt−x)(xt+k−x),rk=ckc0c_k = \frac1n\sum_{t=1}^{n-k}(x_t - \bar x)(x_{t+k} - \bar x), \qquad r_k = \frac{c_k}{c_0}

The denominator is nn throughout, not n−kn-k – that is R's convention. It makes rkr_k smaller towards large lags but guarantees that the sequence of rkr_k is a valid (positive semidefinite) autocorrelation function.

Partial autocorrelation after Durbin-Levinson

The partial autocorrelation ϕkk\phi_{kk} is the association between xtx_t and xt+kx_{t+k} after removing the intermediate values – at the same time the last coefficient of an AR(kk) model. The Durbin-Levinson recursion computes all ϕkk\phi_{kk} from the rkr_k without solving a system of equations:

ϕkk=rk−∑j=1k−1ϕk−1,jrk−jvk−1,ϕkj=ϕk−1,j−ϕkkϕk−1,k−j,vk=vk−1(1−ϕkk2)\phi_{kk} = \frac{r_k - \sum_{j=1}^{k-1}\phi_{k-1,j}\,r_{k-j}}{v_{k-1}}, \qquad \phi_{kj} = \phi_{k-1,j} - \phi_{kk}\,\phi_{k-1,k-j}, \qquad v_k = v_{k-1}(1 - \phi_{kk}^2)

with v0=1v_0 = 1. vkv_k is the relative residual variance after an AR(kk) model.

ρ ← acf(x, maxLag);  v ← 1;  φ_old ← 0
for k ← 1 to maxLag:
    num ← ρ[k] − Σ_{j=1}^{k−1} φ_old[j]·ρ[k−j]
    φkk ← num / (v = 0 ? 1e−300 : v)
    φ[k] ← φkk
    for j ← 1 to k−1:  φ[j] ← φ_old[j] − φkk·φ_old[k−j]
    v ← v·(1 − φkk²)
    pacf[k] ← φkk;  φ_old ← φ
pacf[0] ← 1

Source: envisionz-framework-stats/src/envisionz/stats/correlation/Correlation.java, methods acf and pacf. The same recursion yields the AR coefficients in TimeSeries.arYuleWalker (see Time series).

Worked example

x={1,2,3,4,5}x = \{1, 2, 3, 4, 5\}, y={2,4,5,4,5}y = \{2, 4, 5, 4, 5\}:

  1. x=3\bar x = 3, y=4\bar y = 4; deviation products 2+0+0+0+2=62 + 0 + 0 + 0 + 2 = 6; ∑(x−x)2=10\sum(x-\bar x)^2 = 10, ∑(y−y)2=6\sum(y - \bar y)^2 = 6.
  2. r=6/60=0.77460r = 6/\sqrt{60} = 0.77460.
  3. t=0.77463/0.4=2.1213t = 0.7746\sqrt{3/0.4} = 2.1213, ν=3\nu = 3, p=0.12403p = 0.12403.
  4. Fisher: zr=1.0317z_r = 1.0317, se=1/2\operatorname{se} = 1/\sqrt2; 95 % interval [−0.3401;0.9842][-0.3401;\ 0.9842] – very wide, because five points say little.

For x=1…5x = 1 \dots 5, y={1,3,2,5,4}y = \{1, 3, 2, 5, 4\}: Spearman ρ=0.8\rho = 0.8 (t = 2.3094, p = 0.1041), Kendall: 8 concordant and 2 discordant pairs, τ=6/10=0.6\tau = 6/10 = 0.6, p=0.1416p = 0.1416. Values recomputed with the module.

How it is checked

CorrelationTest (12 checks): Pearson for the example to 10−710^{-7}, Pearson = 1 for an exact line; t and p of the test to 10−610^{-6}; Spearman 0.8 and Kendall 0.6 to 10−910^{-9}; correlation matrix with diagonal 1, −1-1 for xx against −x-x, and symmetry; ACF of 1…10 with r0=1r_0 = 1 and r1=0.7r_1 = 0.7 (R acf) to 10−910^{-9}; ϕ11=r1\phi_{11} = r_1.

Limits

  • All correlation tests are two-sided; the Fisher interval is always 95 %.
  • Kendall: the test takes the variance without ties, but the coefficient is τb\tau_b with tie correction. With many ties the p-value is therefore inaccurate. Cost O(n2)O(n^2).
  • Spearman and Kendall p-values are approximations, coarse for n<10n < 10.
  • At |r|=1|r| = 1, tt becomes infinite and the Fisher interval degenerates (artanh(±1)=±∞\operatorname{artanh}(\pm1) = \pm\infty).
  • Constant columns give 0/0=0/0 = NaN.
  • No check whether the precision matrix exists; for a singular correlation matrix the inverse returns null, and partialMatrix fails with an exception.
