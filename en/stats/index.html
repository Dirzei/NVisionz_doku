envisionz-framework-stats

Statistics as in R, as a compute core in Java

Function overview for the presentation of the envisionz framework, as of 28 Sep 2026. Special functions and distributions, descriptive statistics and outliers, confidence intervals, test families, correlation and regression, analysis of variance, multivariate methods, time series, statistical process control, resampling and data preparation, plus a method catalogue as the interface for the GUI. For each method: purpose, API, use in the framework, applications, examples. The examples are shortened. The display names of the catalogue are German (e.g. Deskriptiv = descriptive, Einfaktorielle ANOVA = one-way ANOVA) and are translated only under an English locale via Msg; they are shown unchanged.

Principles of the module

Analyse, not display. No GUI and domain-free: primitive arrays in, structured results out. The workbench is app-stats.
Results that explain themselves. A test returns statistic, degrees of freedom, p-value, estimate, confidence interval, alternative, checked assumptions, effect size and a plain-language interpretation. So far the t-tests (normality after Shapiro-Wilk, for the pooled test equality of variances after Brown-Forsythe) and the catalogue's analysis of variance carry checked assumptions; for the other tests the list stays empty.
Computed against the reference. Self-tests against R and NIST reference values. A finding such as Normal.cdf(-9) = 0 (because erfc was computed as 1 − erf) is fixed and recorded.
Reproducible randomness. Rng with an explicit seed; the same seed gives a bit-identical sequence. Compute kernels are stateless, Rng is not: one instance per run.
Only JDK and framework-math. No jars, no reflection, native-image ready. Linear algebra and optimisation moved to framework-math in 2026-09, bit-identical.
Locale-independent. Display names are translated, the id is not; numbers in the result HTML are formatted with Locale.ROOT.

Gamma (Lanczos with reflection), digamma, beta, regularised incomplete gamma and beta functions (series or Lentz continued fraction), erf and erfc. erfc is computed via the upper incomplete gamma function and therefore stays accurate in the tail. Used in

ready, no callers outside the probes yetinternal: BuiltinMethods (goodness of fit, contingency)

What for

Checking whether normality may be assumed; evaluating finding tables (good/bad per supplier).

A p-value says neither how likely the null hypothesis is nor how large a difference is. With ten thousand points a deviation of 0.1 % becomes significant; that is why the effect size belongs with every test.

Method catalogue for the GUI envisionz.stats.method · envisionz.stats.i18n

StatMethod, MethodRegistry, BuiltinMethods, DataView, Params, ParamSpec, MethodResult

Each method declares which roles it needs (NUMERIC, NUMERIC_MULTI, GROUP, X, Y, TIME, WEIGHT, CATEGORY_TABLE) and which options it has. The GUI shows only what fits the assigned columns and builds the options card from paramSpecs(). The result carries the computed object, HTML and overlays for the chart. The catalogue: 34 univariate, 7 group comparisons, 6 for X/Y, 4 multivariate, 3 for contingency tables, registered explicitly, without reflection.
