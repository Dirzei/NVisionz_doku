Analysis of variance and multiple testing – background

The computation behind Anova: one-way analysis of variance with η², ω² and Cohen's f, the p-value adjustments after Bonferroni, Holm, Hochberg and Benjamini-Hochberg, pairwise t-tests and Tukey's HSD with the numerically integrated distribution of the studentized range.

What this is about

Three suppliers, five tool settings, four hardening processes: do the means differ? One could compare all pairs with t-tests – with five groups that is ten tests. Each has an error probability of 5 %, and the probability that at least one fires by chance is then up to 1−0.9510≈40%1 - 0.95^{10} \approx 40\,\%. With twenty comparisons one finds on average one seemingly significant difference although there is none.

There are two ways out, and the module offers both:

  • The analysis of variance checks with a single test whether any difference exists.
  • Post-hoc comparisons with adjusted p-values then tell which pairs differ, without the error probability adding up.

One-way analysis of variance

The idea is in the name: the spread of all values around the grand mean x\bar x is decomposed into a part between the groups and a part within the groups:

∑i,j(xij−x)2⏟SST=∑ini(xi−x)2⏟SSB+∑i,j(xij−xi)2⏟SSW\underbrace{\sum_{i,j}(x_{ij} - \bar x)^2}_{SS_T} = \underbrace{\sum_i n_i(\bar x_i - \bar x)^2}_{SS_B} + \underbrace{\sum_{i,j}(x_{ij} - \bar x_i)^2}_{SS_W}

If all group means are equal, both parts – divided by their degrees of freedom – estimate the same error variance σ2\sigma^2. If the group means are apart, the between part grows. The test statistic is their ratio:

F=MSBMSW=SSB/(k−1)SSW/(N−k),p=1−FF(F;k−1,N−k)F = \frac{MS_B}{MS_W} = \frac{SS_B/(k-1)}{SS_W/(N-k)}, \qquad p = 1 - F_F(F;\ k-1,\ N-k)

with kk groups and NN values in total. Assumptions: normally distributed errors, equal variances in all groups (checkable with Brown-Forsythe), independent values. Without normality Kruskal-Wallis helps.

Adjustment for multiple testing

For mm tests with p-values p1,…,pmp_1, \dots, p_m, pAdjust returns adjusted p-values that are compared directly with α\alpha. The methods sort the p-values in ascending order, p(1)≤…≤p(m)p_{(1)} \le \dots \le p_{(m)}:

Methodadjusted value for p(i)p_{(i)}controls
Bonferronimin⁡(1,mpi)\min(1,\ m\,p_i)family-wise error (FWER), without assumptions
Holmmaxj≤i⁡min⁡(1,(m−j+1)p(j))\max_{j \le i}\ \min(1,\ (m-j+1)\,p_{(j)})FWER, without assumptions, always sharper than Bonferroni
Hochbergminj≥i⁡min⁡(1,(m−j+1)p(j))\min_{j \ge i}\ \min(1,\ (m-j+1)\,p_{(j)})FWER, assumes independence or positive dependence, sharper than Holm
Benjamini-Hochbergminj≥i⁡min⁡(1,mjp(j))\min_{j \ge i}\ \min(1,\ \frac{m}{j}\,p_{(j)})false discovery rate (FDR)

The family-wise error rate is the probability of committing any type I error at all. The false discovery rate is the expected fraction of false discoveries among all discoveries – a weaker requirement that finds considerably more with many tests (hundreds of features, measuring points).

The running maximum (Holm) or minimum (Hochberg, BH) ensures that the adjusted values keep the same order as the original ones. The implementation follows R p.adjust.

Bonferroni: out[i] ← min(1, m·p[i])
Holm:       sort ascending;   run ← 0
            for i ← 0 to m−1:  run ← max(run, min(1, (m − i)·p₍ᵢ₎));  out ← run
Hochberg:   sort descending;  run ← 1
            for i ← 0 to m−1:  run ← min(run, min(1, (i + 1)·p₍ᵢ₎));  out ← run
BH:         sort descending;  run ← 1
            for i ← 0 to m−1:  rank ← m − i;  run ← min(run, min(1, p₍ᵢ₎·m/rank));  out ← run

Post-hoc comparisons

Pairwise t-tests

pairwiseT compares all k(k−1)/2k(k-1)/2 pairs with a t-test that uses the pooled error variance MSWMS_W of the whole analysis of variance – so each comparison has N−kN - k degrees of freedom, even if the two groups are small:

tij=xi−xjMSW(1ni+1nj)t_{ij} = \frac{\bar x_i - \bar x_j}{\sqrt{MS_W\left(\frac{1}{n_i} + \frac{1}{n_j}\right)}}

The two-sided p-values are adjusted with the chosen method and returned as a symmetric k×kk\times k matrix (diagonal NaN). This corresponds to R pairwise.t.test with pool.sd = TRUE.

Tukey's HSD

Tukey does not look at each pair on its own but at the distribution of the largest difference among all kk group means. The test statistic for a pair (Tukey-Kramer form for unequal group sizes) is

qij=|xi−xj|MSW2(1ni+1nj)q_{ij} = \frac{|\bar x_i - \bar x_j|}{\sqrt{\frac{MS_W}{2}\left(\frac{1}{n_i} + \frac{1}{n_j}\right)}}

and the p-value 1−PSR(q;k,N−k)1 - P_\text{SR}(q;\ k,\ N-k) with the distribution function of the studentized range: the range of kk independent standard normal values divided by an independent estimate of the standard deviation with ν\nu degrees of freedom.

The studentized range, numerically

For a known standard deviation (ν=∞\nu = \infty) the distribution of the range WW of kk standard normal values is

P(W<w)=k∫−∞∞φ(u)(Φ(u)−Φ(u−w))k−1duP(W < w) = k\int_{-\infty}^{\infty}\varphi(u)\,\bigl(\Phi(u) - \Phi(u - w)\bigr)^{k-1}\,du

– the largest value lies at uu (factor kk for the choice of which one it is), and the other k−1k-1 lie between u−wu - w and uu. For finite ν\nu the standard deviation is estimated by ss; s/σ=χν2/νs/\sigma = \sqrt{\chi^2_\nu/\nu} has the density

gν(v)=2(ν/2)ν/2Γ(ν/2)vν−1e−νv2/2g_\nu(v) = \frac{2\,(\nu/2)^{\nu/2}}{\Gamma(\nu/2)}\,v^{\nu-1}\,e^{-\nu v^2/2}

and one averages over it:

PSR(q;k,ν)=∫0∞P(W<qv)gν(v)dvP_\text{SR}(q;\ k,\ \nu) = \int_0^\infty P(W < qv)\,g_\nu(v)\,dv

function pRange(w, k):                                  ν = ∞
    if w ≤ 0: return 0
    h ← 16/400;  sum ← 0
    for i ← 0 to 400:                                   trapezoidal rule on [−8, 8]
        u ← −8 + i·h
        f ← φ(u)·(Φ(u) − Φ(u − w))^(k−1)
        sum ← sum + (i = 0 or i = 400 ? ½ : 1)·f
    return min(1, k·sum·h)

function ptukey(q, k, ν):
    if ν > 2000: return pRange(q, k)
    h ← 4/200;  c ← 2·exp((ν/2)·ln(ν/2) − lnΓ(ν/2))
    sum ← 0
    for i ← 1 to 200:                                   rectangle rule on (0, 4]
        v ← i·h
        sum ← sum + pRange(q·v, k) · c·v^(ν−1)·e^(−ν v²/2) · h
    return min(1, sum)

Worked examples

Three groups

A={1,2,3}A = \{1, 2, 3\}, B={4,5,6}B = \{4, 5, 6\}, C={7,8,9}C = \{7, 8, 9\}, grand mean 5:

  1. Group means 2, 5, 8: SSB=3⋅((2−5)2+(5−5)2+(8−5)2)=3⋅18=54SS_B = 3\cdot((2-5)^2 + (5-5)^2 + (8-5)^2) = 3\cdot18 = 54; SSW=3⋅2=6SS_W = 3\cdot2 = 6.
  2. MSB=27MS_B = 27, MSW=1MS_W = 1, F=27F = 27 with (2; 6) degrees of freedom; p=0.001p = 0.001 exactly (here 1−I0.9(1,3)=0.131 - I_{0.9}(1, 3) = 0.1^3).
  3. η2=54/60=0.9\eta^2 = 54/60 = 0.9; ω2=(54−2)/(60+1)=0.8525\omega^2 = (54 - 2)/(60 + 1) = 0.8525; Cohen's f=0.9/0.1=3f = \sqrt{0.9/0.1} = 3.

How it is checked

AnovaTest (17 checks): analysis of variance of the example with F=27F = 27, degrees of freedom, SSBSS_B, SSWSS_W, η2\eta^2 to 10−610^{-6} and p=0.001p = 0.001 to 10−910^{-9}; Bonferroni, Holm and BH for {0.01;0.02;0.03;0.04}\{0.01;\ 0.02;\ 0.03;\ 0.04\} (for instance Holm 0.04;0.06;0.06;0.060.04;\ 0.06;\ 0.06;\ 0.06, BH 0.04 throughout); pairwise t-tests (A against C significant); Tukey: all p in [0,1][0, 1], the largest difference significant.

Limits

  • Only the one-way analysis of variance; multi-factor, repeated-measures ANOVA and ANCOVA are not implemented (recorded as open in the module).
  • No Welch ANOVA for unequal variances.
  • Tukey p-values are checked in the probe only for plausibility, not against R. The fixed rectangle rule on (0,4](0, 4] becomes inaccurate for ν=1\nu = 1, because the density of ss decays very slowly there.
  • Tukey returns difference, qq and p-value, but no simultaneous confidence interval of the difference.
  • Hochberg assumes independence or positive dependence of the tests; the module does not check this.
