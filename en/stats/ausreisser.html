Detecting outliers – background

The computation behind Outlier: Tukey fences, z-scores and robust z-scores, the tests after Grubbs, Dixon and Rosner, the Hampel filter for series, and winsorising and trimming. With the masking effect that explains why robust methods are needed.

What this is about

An outlier is a value that does not fit the rest of the data: a typo, a sensor jump, a wrongly entered unit factor – or a genuine, rare state that is precisely the most interesting part of the series. The methods on this page flag suspicious values. Whether to remove them is a decision for the domain expert; the module deletes nothing on its own.

The difficulty: an outlier changes exactly the quantities one wants to use to detect it. It pulls the mean towards itself and inflates the standard deviation. A large value can thereby make itself inconspicuous, and two large values can hide each other. This is called masking. The methods differ in how they deal with it:

  • robust measures (median, quartiles, MAD) that a single value hardly moves – Tukey fences, robust z-scores, Hampel filter;
  • tests with a known distribution of the test statistic under “no outliers, normally distributed” – Grubbs, Dixon;
  • stepwise removal with recomputed statistics – Rosner.

Tukey fences, z-scores, robust z-scores

Tukey fences

xi suspicious if xi<Q1−1.5IQR⁡ or xi>Q3+1.5IQR⁡x_i \text{ suspicious if } x_i < Q_1 - 1.5\,\mathrm{IQR} \text{ or } x_i > Q_3 + 1.5\,\mathrm{IQR}

Quartiles by type 7 (see Quantiles). Under normality the fences lie at about ±2.7σ\pm 2.7\,\sigma; roughly 0.7 % of the values fall outside even without any disturbance. tukeyOutliers returns the indices.

z-scores

zi=xi−xsz_i = \frac{x_i - \bar x}{s}

The common rule of thumb |z|>3|z| > 3 fails fundamentally for small samples: for nn values |z||z| can never exceed (n−1)/n(n-1)/\sqrt n, for n=10n = 10 therefore never 2.85. A single outlier among ten values never reaches the threshold 3, however large it is.

Robust z-scores

After Iglewicz and Hoaglin, mean and standard deviation are replaced by median and MAD:

Mi=0.6745(xi−x˜)MAD⁡,MAD⁡=mediani⁡|xi−x˜|M_i = \frac{0.6745\,(x_i - \tilde x)}{\operatorname{MAD}}, \qquad \operatorname{MAD} = \operatorname{median}_i |x_i - \tilde x|

Here the MAD is meant without the factor 1.4826; the factor 0.6745 =1/1.4826= 1/1.4826 is in the numerator. The result is the same as (xi−x˜)/(1.4826⋅MAD⁡)(x_i - \tilde x)/(1.4826\cdot\operatorname{MAD}). Iglewicz and Hoaglin recommend the threshold |Mi|>3.5|M_i| > 3.5; the module only returns the values, the caller sets the threshold.

Grubbs test

The Grubbs test checks whether the most extreme value of a normally distributed sample is too extreme. Test statistic:

G=maxi⁡|xi−x|sG = \max_i \frac{|x_i - \bar x|}{s}

The distribution of GG under the null hypothesis is related to the t distribution. The usual critical value is

Gcrit=n−1nt2n−2+t2,t=t1−α/(2n);n−2G_\text{crit} = \frac{n-1}{\sqrt n}\sqrt{\frac{t^2}{n-2+t^2}}, \qquad t = t_{1-\alpha/(2n);\,n-2}

The module inverts this relation: from the observed GG the corresponding tt is determined,

u=G2n(n−1)2,t2=u(n−2)1−uu = \frac{G^2\,n}{(n-1)^2}, \qquad t^2 = \frac{u\,(n-2)}{1-u}

and the p-value is formed as a two-sided Bonferroni bound over all nn possible candidates:

p=min⁡(1,2n(1−Ft,n−2(t)))p = \min\bigl(1,\ 2n\,(1 - F_{t,\,n-2}(t))\bigr)

This is exactly the inverse of the critical value: p≤αp \le \alpha if and only if G≥GcritG \ge G_\text{crit}.

m ← mean(x);  s ← sd(x)
G ← max |xᵢ − m|/s;  remember index of the maximum
u ← G²·n / (n−1)²
t ← √max(0, u·(n−2)/(1−u))
p ← min(1, 2n · (1 − F_t(t; n−2)))
return result(G, df = n−2, p, estimate = most extreme value,
              interpretation "is (not) an outlier (α = 0.05)")

Dixon's Q test

For very small samples (3 to 30 values) Dixon's Q compares the gap at the edge with the range:

Qlow=x(2)−x(1)x(n)−x(1),Qhigh=x(n)−x(n−1)x(n)−x(1),Q=max⁡(Qlow,Qhigh)Q_\text{low} = \frac{x_{(2)} - x_{(1)}}{x_{(n)} - x_{(1)}}, \qquad Q_\text{high} = \frac{x_{(n)} - x_{(n-1)}}{x_{(n)} - x_{(1)}}, \qquad Q = \max(Q_\text{low}, Q_\text{high})

This is the simplest Dixon statistic r10r_{10}. QQ is compared with a tabulated critical value. The module contains the table for α=0.05\alpha = 0.05 after Rorabacher (1991), n=3…30n = 3 \dots 30: from 0.970 at n=3n = 3 via 0.710 at n=5n = 5 and 0.466 at n=10n = 10 to 0.290 at n=30n = 30.

Framework convention: Only α=0.05\alpha = 0.05 is tabulated. Outside 3≤n≤303 \le n \le 30 the critical value is NaN, and the test reports no outlier. Dixon returns no p-value, only Q, critical value, decision, affected value and side.

Rosner ESD: several outliers

Rosner's generalised ESD test (extreme studentized deviate) looks for up to rr outliers. It removes the currently most extreme value one after the other and recomputes mean and standard deviation each time. In step ii with nin_i remaining values:

Ri=maxj⁡|xj−x|s,λi=(ni−1)t(ni−2+t2)ni,t=t1−α/(2ni);ni−2R_i = \max_j \frac{|x_j - \bar x|}{s}, \qquad \lambda_i = \frac{(n_i - 1)\,t}{\sqrt{(n_i - 2 + t^2)\,n_i}}, \quad t = t_{1-\alpha/(2n_i);\,n_i-2}

The number of outliers is the largest ii with Ri>λiR_i > \lambda_i – even if earlier steps stayed below their threshold. That is exactly what removes masking: when two large values hide each other, the first step remains inconspicuous but the second does not.

pool ← all values;  found ← 0
for i ← 1 to maxOutliers, while |pool| > 2:
    m ← mean(pool);  s ← sd(pool);  nᵢ ← |pool|
    R ← max |x − m|/s,  worst ← its index
    t ← quantile of the t distribution(1 − 0.05/(2nᵢ); nᵢ − 2)
    λ ← (nᵢ − 1)·t / √((nᵢ − 2 + t²)·nᵢ)
    remove worst from pool
    if R > λ: found ← i
return found

Source: envisionz-framework-stats/src/envisionz/stats/outlier/Outlier.java, method rosnerESD. α=0.05\alpha = 0.05 is fixed; only the count is returned, not the indices.

Hampel filter for series

In time series a value is not conspicuous relative to all others but relative to its neighbours. The Hampel filter takes a window of kk neighbours on each side of every point (truncated at the edges) and flags the point if

|xi−x˜window|>nσ⋅1.4826⋅MADwindow⁡|x_i - \tilde x_\text{window}| > n_\sigma \cdot 1.4826\cdot\operatorname{MAD}_\text{window}

If the MAD in the window is zero (more than half the values equal), nothing is flagged. The filter replaces nothing; it returns a boolean[].

Winsorising and trimming

  • Winsorising (winsorize(x, f)): values below the ff quantile are set to that quantile, values above the (1−f)(1-f) quantile to that one (type 7). Length and order are preserved.
  • Trimming (trim(x, f)): the sorted values without ⌊nf⌋\lfloor nf\rfloor values at each end. The result is shorter and sorted.

Limits

  • Grubbs, Dixon and Rosner assume that the data without outliers are normally distributed. For skewed distributions (lifetimes, concentrations) they report genuine tail values as outliers; transform beforehand in that case (log, Box-Cox).
  • Grubbs only tests the single most extreme value. The p-value is a Bonferroni bound and hence slightly conservative.
  • Dixon and Rosner work with a fixed α=0.05\alpha = 0.05; Dixon only for 3≤n≤303 \le n \le 30.
  • rosnerESD reports the count, not which values; the values are the ones removed first.
  • Robust z-scores fail when the MAD is zero (more than half the values equal): division by zero gives ±∞\pm\infty or NaN.
  • In measurement series with sections (for instance tables digitised block by block), column-wise methods regularly flag the values at section boundaries; that is expected and not a fault.
