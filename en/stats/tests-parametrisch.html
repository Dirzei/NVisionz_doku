Parametric tests – background

The computation behind ParametricTests: t-tests for one, two (Welch or pooled) and paired samples, z-test, F-test for equal variances, Bartlett, Levene and Brown-Forsythe, z-tests for proportions. Test statistics, degrees of freedom and p-values exactly as in the code.

What this is about

A test asks: could the observed result also have arisen by chance if in truth nothing is going on? “Nothing going on” is the null hypothesis H0H_0 – for instance “both batches have the same mean”. The test computes a test statistic whose distribution under H0H_0 is known, and from it the p-value: the probability of seeing a test statistic at least as extreme under H0H_0.

“Parametric” means: the distribution of the test statistic follows from an assumption about the data distribution, almost always the normal distribution. If the assumption holds these tests are the sharpest; if it is grossly violated the rank tests help.

A small p-value does not say how large a difference is or whether it matters. With ten thousand measurements a deviation of 0.1 % becomes significant – correctly computed and practically meaningless. That is why the t-tests also return an effect size (Cohen's dd).

Alternative hypothesis and p-value

The alternative hypothesis is passed as a string, as in R:

alternativeMeaningp-value from the t distributionp-value from the normal distribution
"two.sided" (default)difference in either direction2Ft(|t|)2\,\bar F_t(|t|)2Φ(|z|)2\,\bar\Phi(|z|)
"greater"statistic larger than under H0H_0Ft(t)\bar F_t(t)Φ(z)\bar\Phi(z)
"less"statistic smallerFt(t)F_t(t)Φ(z)\Phi(z)

Here F=1−F\bar F = 1 - F is the survival function. The module computes it directly (Distribution.sf: normal via erfc, t and F via the regularised beta, chi² via Q(a,x)Q(a, x)) and not as 1−F1 - F; otherwise a small p-value would cancel out in the difference (since finding WT10, see limits). Any other string is treated like "two.sided". The result is an HTestResult with the name of the method, test statistic, one or two degrees of freedom, p-value, estimate, where applicable confidence interval and effect size, and a plain-language interpretation.

function pFromT(t, df, alt):
    F ← StudentT(df)
    alt = "greater": return F.sf(t)               sf = 1 − cdf, computed directly
    alt = "less":    return F.cdf(t)
    otherwise:       return 2·F.sf(|t|)
// pFromZ likewise with the standard normal distribution

t-tests

One sample

Is the mean at a target value μ0\mu_0?

t=x−μ0s/n,ν=n−1,d=x−μ0st = \frac{\bar x - \mu_0}{s/\sqrt n}, \qquad \nu = n - 1, \qquad d = \frac{\bar x - \mu_0}{s}

The result contains the confidence interval at level 1−α1-\alpha (default 95 %, oneSampleT(x, μ₀, alt, level)), matching the alternative as in R t.test: two-sided x±t1−α/2;n−1s/n\bar x \pm t_{1-\alpha/2;\,n-1}\,s/\sqrt n, for "greater" [x−t1−α;n−1s/n,∞)[\bar x - t_{1-\alpha;\,n-1}\,s/\sqrt n,\ \infty), for "less" (−∞,x+t1−α;n−1s/n](-\infty,\ \bar x + t_{1-\alpha;\,n-1}\,s/\sqrt n]. Under assumptions is the normality check of the data after Shapiro-Wilk (judged at α=0.05\alpha = 0.05; for n<3n < 3, n>5000n > 5000 or all values equal “not checkable”). Until finding WT10 the interval was always two-sided at 95 %, until WT11 assumptions stayed empty.

Two independent samples: Welch or pooled

The classical (pooled) t-test assumes that both groups have the same variance and estimates it jointly:

sp2=(nx−1)sx2+(ny−1)sy2nx+ny−2,t=x−ysp1nx+1ny,ν=nx+ny−2s_p^2 = \frac{(n_x-1)s_x^2 + (n_y-1)s_y^2}{n_x + n_y - 2}, \qquad t = \frac{\bar x - \bar y}{s_p\sqrt{\frac{1}{n_x} + \frac{1}{n_y}}}, \qquad \nu = n_x + n_y - 2

Welch dispenses with this assumption. The test statistic takes each variance on its own:

t=x−ysx2nx+sy2nyt = \frac{\bar x - \bar y}{\sqrt{\frac{s_x^2}{n_x} + \frac{s_y^2}{n_y}}}

It is then no longer exactly t distributed, but very well approximated by a t distribution with non-integer degrees of freedom after Welch and Satterthwaite:

ν=(a+b)2a2nx−1+b2ny−1,a=sx2nx,b=sy2ny\nu = \frac{(a + b)^2}{\frac{a^2}{n_x - 1} + \frac{b^2}{n_y - 1}}, \qquad a = \frac{s_x^2}{n_x}, \quad b = \frac{s_y^2}{n_y}

ν\nu lies between min⁡(nx,ny)−1\min(n_x, n_y) - 1 and nx+ny−2n_x + n_y - 2. With equal variances and equal group sizes Welch loses almost nothing; with unequal variances and unequal group sizes the pooled test does not keep its level. That is why Welch is the default – as in R.

Framework convention: The GUI catalogue sets “Welch” as default (welch = true). Cohen's dd is formed in both cases with the pooled standard deviation sps_p, d=(x−y)/spd = (\bar x - \bar y)/s_p, so that the effect size does not depend on the chosen test variant. The estimate is x−y\bar x - \bar y; a confidence interval of the difference is not returned. Under assumptions are the normality checks of both groups (Shapiro-Wilk), for the pooled test additionally equality of variances after Brown-Forsythe.

Paired samples

If the same part is measured before and after, the pairs are not independent. The paired test forms the differences di=xi−yid_i = x_i - y_i and runs a one-sample t-test with μ0=0\mu_0 = 0 on them; degrees of freedom n−1n - 1, Cohen's d=d/sdd = \bar d/s_d. Confidence interval as in the one-sample test (pairedT(x, y, alt, level)); normality of the differences is checked.

Pseudocode – twoSampleT(x, y, alt, welch)

mx, my ← means;  vx, vy ← sample variances (n−1)
if welch:
    t ← (mx − my) / √(vx/nx + vy/ny)
    a ← vx/nx;  b ← vy/ny
    df ← (a + b)² / (a²/(nx−1) + b²/(ny−1))
else
    sp ← √(((nx−1)·vx + (ny−1)·vy) / (nx + ny − 2))
    t ← (mx − my) / (sp·√(1/nx + 1/ny))
    df ← nx + ny − 2
p ← pFromT(t, df, alt)
d ← (mx − my) / pooled standard deviation              in both cases
return result(t, df, p, estimate = mx − my, effect = d)

Source: envisionz-framework-stats/src/envisionz/stats/test/ParametricTests.java, methods oneSampleT, twoSampleT, pairedT.

z-test and proportion tests

If the standard deviation σ\sigma is known (for instance from long process experience), its estimation and with it the t distribution are no longer needed:

z=x−μ0σ/nz = \frac{\bar x - \mu_0}{\sigma/\sqrt n}

For proportions one uses the normal approximation of the binomial distribution. One sample with kk hits against the target proportion p0p_0:

z=p^−p0p0(1−p0)/nz = \frac{\hat p - p_0}{\sqrt{p_0(1-p_0)/n}}

The standard error is formed with p0p_0, not with p^\hat p – under H0H_0, p0p_0 is the true proportion. Two samples with pooled proportion p=(k1+k2)/(n1+n2)\bar p = (k_1+k_2)/(n_1+n_2):

z=p^1−p^2p(1−p)(1n1+1n2)z = \frac{\hat p_1 - \hat p_2}{\sqrt{\bar p(1-\bar p)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}

Both proportion tests compute without continuity correction. Their square is the chi-squared statistic of R prop.test(..., correct = FALSE).

Tests for equal variances

F-test

F=sx2sy2,ν1=nx−1,ν2=ny−1F = \frac{s_x^2}{s_y^2}, \qquad \nu_1 = n_x - 1, \quad \nu_2 = n_y - 1

Two-sided, p=2min⁡(FF(F),1−FF(F))p = 2\min(F_F(F),\ 1 - F_F(F)). The F-test is extremely sensitive to departures from normality: even slightly heavy-tailed data lead to far too many rejections. It is included anyway because standards require it.

Bartlett

For kk groups with NN values in total:

χ2=(N−k)ln⁡sp2−∑i(ni−1)ln⁡si2C,C=1+13(k−1)(∑i1ni−1−1N−k)\chi^2 = \frac{(N-k)\ln s_p^2 - \sum_i (n_i - 1)\ln s_i^2}{C}, \qquad C = 1 + \frac{1}{3(k-1)}\left(\sum_i \frac{1}{n_i - 1} - \frac{1}{N-k}\right)

with sp2=∑(ni−1)si2/(N−k)s_p^2 = \sum (n_i-1)s_i^2 / (N-k), chi-squared distributed with k−1k - 1 degrees of freedom. The numerator compares the logarithm of the weighted arithmetic mean of the variances with the geometric one – the two are equal only if all variances are equal. CC is a correction for small groups. Bartlett shares the normality sensitivity of the F-test.

Levene and Brown-Forsythe

Levene turns the variance question into a mean question: one forms the absolute deviations from the group centre

zij=|xij−ci|z_{ij} = |x_{ij} - c_i|

and runs a one-way analysis of variance on them:

F=∑ini(zi−z)2/(k−1)∑i∑j(zij−zi)2/(N−k),ν1=k−1,ν2=N−kF = \frac{\sum_i n_i(\bar z_i - \bar z)^2/(k-1)}{\sum_i\sum_j (z_{ij} - \bar z_i)^2/(N-k)}, \qquad \nu_1 = k-1, \quad \nu_2 = N-k

In Levene's original test cic_i is the group mean, in Brown-Forsythe the group median. The median version is robust against skewed distributions and the usual choice; it corresponds to R car::leveneTest in its default setting.

for each group i:
    cᵢ ← median ? median(group) : mean(group)
    zᵢⱼ ← |xᵢⱼ − cᵢ|
z̄ ← mean of all z
SSB ← Σᵢ nᵢ·(z̄ᵢ − z̄)²;   SSW ← Σᵢ Σⱼ (zᵢⱼ − z̄ᵢ)²
F ← (SSB/(k−1)) / (SSW/(N−k))
p ← F̄_F(F; k−1, N−k)                              survival function sf

Source: envisionz-framework-stats/src/envisionz/stats/test/ParametricTests.java, methods fTestVariance, bartlett, leveneTest(groups, median). The name in the result is “Brown-Forsythe” for median = true, otherwise “Levene”.

Framework convention: In the catalogue (“Varianzhomogenität”), “Levene (Median)”, that is Brown-Forsythe, is the default.

Worked example

Two groups, x={1,2,3,4,5}x = \{1, 2, 3, 4, 5\} and y={2,4,6,8,10}y = \{2, 4, 6, 8, 10\}: same size, but the variance of yy is four times as large.

  1. x=3\bar x = 3, y=6\bar y = 6, sx2=2.5s_x^2 = 2.5, sy2=10s_y^2 = 10.
  2. Welch: a=0.5a = 0.5, b=2b = 2, t=−3/2.5=−1.8974t = -3/\sqrt{2.5} = -1.8974, ν=2.52/(0.25/4+4/4)=6.25/1.0625=5.8824\nu = 2.5^2/(0.25/4 + 4/4) = 6.25/1.0625 = 5.8824, p=0.10753p = 0.10753.
  3. Pooled: sp2=6.25s_p^2 = 6.25, t=−3/(2.5⋅0.4)=−1.8974t = -3/(2.5\cdot\sqrt{0.4}) = -1.8974 (the same statistic for equal group sizes), but ν=8\nu = 8 and hence p=0.09435p = 0.09435.
  4. Cohen's d=−3/2.5=−1.2d = -3/2.5 = -1.2 in both cases.
  5. Variance tests: F=2.5/10=0.25F = 2.5/10 = 0.25, p=0.208p = 0.208; Bartlett χ2=1.5868\chi^2 = 1.5868, p=0.2078p = 0.2078; Brown-Forsythe F=2.0571F = 2.0571, p=0.1894p = 0.1894.

With equal group sizes Welch and pooled differ only in the degrees of freedom. With unequal sizes the statistic can also differ considerably – when the smaller group has the larger variance, the pooled test is too optimistic. Values recomputed with the module; R t.test(x, y) gives the same numbers (t = −1.8974, df = 5.8824, p = 0.1075).

Limits

  • The p-values come from the survival function and stay relatively accurate in the tail (2Φ(9)=2.26⋅10−192\bar\Phi(9) = 2.26\cdot10^{-19}); below about 10−30010^{-300} it too becomes 0. Until finding WT10 they were formed as 1−F1 - F and were 0 from |z|>8.3|z| > 8.3.
  • A confidence interval exists only for the one-sample and the paired test, not for the difference of two independent groups.
  • The checked assumptions are a hint, not a decision: Shapiro-Wilk has little power for small nn and fires on irrelevant deviations for large nn. A Q-Q plot belongs with it.
  • F-test and Bartlett are only reliable for normally distributed data; when in doubt, Brown-Forsythe.
  • Proportion tests without continuity correction and without an exact variant; for small nn the exact Clopper-Pearson interval or Fisher's test is better.
