Contingency tables – background

The computation behind CategoricalTests: chi-squared independence test with Yates correction, Fisher's exact test, McNemar, Cochran's Q and the measures phi, Cramér's V, odds ratio and Cohen's kappa.

What this is about

Not all data are measurements. “good/scrap”, “supplier A/B/C”, “before/after the change-over” are attributes with categories. Counting how often each combination of two attributes occurs gives a contingency table:

scrapgoodtotal
line 1a=10a = 10b=20b = 2030
line 2c=30c = 30d=40d = 4070
total4060100

The question is: does the scrap rate depend on the line, or are the two attributes independent? For independent attributes one expects in each cell

Eij=(row totali)(column totalj)NE_{ij} = \frac{(\text{row total}_i)(\text{column total}_j)}{N}

The tests compare the observed counts OijO_{ij} with these expectations. The table is passed as an int[][], rows first.

Chi-squared independence test

χ2=∑i,j(Oij−Eij)2Eij,ν=(r−1)(c−1)\chi^2 = \sum_{i,j}\frac{(O_{ij} - E_{ij})^2}{E_{ij}}, \qquad \nu = (r-1)(c-1)

Under independence χ2\chi^2 is approximately chi-squared distributed. The approximation is good when all EijE_{ij} are at least about 5.

Yates correction

For a 2×22\times2 table χ2\chi^2 takes only a few discrete values, and the continuous chi-squared distribution then overstates the significance. Yates reduces every distance by ½:

χYates2=∑i,j(max⁡(0,|Oij−Eij|−12))2Eij\chi^2_\text{Yates} = \sum_{i,j}\frac{\left(\max(0,\ |O_{ij} - E_{ij}| - \tfrac12)\right)^2}{E_{ij}}

The correction is applied only if requested and the table is 2×22\times2; for larger tables it is silently omitted, and the name of the result then does not contain “(Yates)”. The floor 0 prevents a distance from arising when |O−E|<12|O - E| < \frac12.

form row totals, column totals and N
yates ← requested and r = 2 and c = 2
χ² ← 0
for each cell (i, j):
    E ← row[i]·col[j]/N
    δ ← |O[i][j] − E|
    if yates: δ ← max(0, δ − 0.5)
    χ² ← χ² + δ²/E
ν ← (r−1)(c−1);  p ← 1 − F_χ²(χ²; ν)

Source: envisionz-framework-stats/src/envisionz/stats/categorical/CategoricalTests.java, method chiSquareIndependence.

Framework convention: In the GUI catalogue the Yates correction is switched off (yates = false), unlike R chisq.test, which applies it by default for 2×22\times2.

Fisher's exact test

With small counts the chi-squared approximation is unreliable. Fisher computes exactly: if all row and column totals of a 2×22\times2 table are held fixed, cell aa determines all others, and aa is hypergeometrically distributed – as if one drew r1r_1 (first row total) balls without replacement from an urn with NN balls, of which c1c_1 (first column total) are marked:

P(a)=C(c1,a)C(N−c1,r1−a)C(N,r1),C(n,k)=n!k!(n−k)!P(a) = \frac{C(c_1, a)\; C(N-c_1,\ r_1-a)}{C(N, r_1)}, \qquad C(n, k) = \frac{n!}{k!\,(n-k)!}

The two-sided p-value is the sum of the probabilities of all tables that are at most as probable as the observed one. So that rounding differences do not exclude equally probable tables, the comparison uses the factor 1+10−71 + 10^{-7} – the same trick as in R.

h ← Hypergeometric(N, c₁, r₁)
p_obs ← h.pdf(a)
p ← Σ over k from max(0, r₁ − (N − c₁)) to min(r₁, c₁):
        h.pdf(k), if h.pdf(k) ≤ p_obs·(1 + 1e−7)
odds ratio ← a·d / (b·c)                            sample OR, not conditional ML as in R
return result(p = min(1, p), estimate = odds ratio)

Source: envisionz-framework-stats/src/envisionz/stats/categorical/CategoricalTests.java, method fisherExact (2×22\times2 only).

Paired categories: McNemar and Cochran's Q

McNemar

If the same parts are assessed twice (before/after, inspector A/B), only the parts whose verdict changed are of interest: bb (first yes, then no) and cc (first no, then yes). Under H0H_0 – no systematic change – bb and cc are equally likely:

χ2=(max⁡(0,|b−c|−1))2b+c,ν=1\chi^2 = \frac{\left(\max(0,\ |b - c| - 1)\right)^2}{b + c}, \qquad \nu = 1

with the continuity correction 1 after Edwards (can be switched off; switched on in the catalogue). Without correction the numerator is (b−c)2(b-c)^2.

Cochran's Q

The extension to kk conditions: nn blocks (parts), each with kk binary verdicts (0/1). With row totals RiR_i and column totals CjC_j:

Q=(k−1)(k∑jCj2−(∑jCj)2)k∑iRi−∑iRi2,ν=k−1Q = \frac{(k-1)\left(k\sum_j C_j^2 - \left(\sum_j C_j\right)^2\right)}{k\sum_i R_i - \sum_i R_i^2}, \qquad \nu = k-1

Measures of association and agreement

MeasureFormulaRange
phiϕ=χ2/N\phi = \sqrt{\chi^2/N}0 to 1 for 2×22\times2
Cramér's VV=χ2Nmin⁡(r−1,c−1)V = \sqrt{\dfrac{\chi^2}{N\,\min(r-1, c-1)}}0 to 1
odds ratioadbc\dfrac{ad}{bc}0 to ∞\infty, 1 = no association
Cohen's kappaκ=po−pe1−pe\kappa = \dfrac{p_o - p_e}{1 - p_e}, po=∑inii/Np_o = \sum_i n_{ii}/N, pe=∑ini⋅Nn⋅iNp_e = \sum_i \frac{n_{i\cdot}}{N}\frac{n_{\cdot i}}{N}≤1\le 1; 0 = chance agreement

Phi and V always use the uncorrected χ2\chi^2 (without Yates) and have no sign. Kappa answers a different question from the tests above: not “are the verdicts associated?” but “do two inspectors agree beyond chance?”. It needs a square table with the same categories in rows and columns.

Limits

  • Fisher only for 2×22\times2 tables, only two-sided, without a confidence interval of the odds ratio. The reported odds ratio is the sample value ad/bcad/bc, not the conditional ML estimate that R fisher.test gives.
  • If a row or column contains only zeros, some Eij=0E_{ij} = 0, and χ2\chi^2 becomes NaN. The rule Eij≥5E_{ij} \ge 5 is not checked.
  • Odds ratio with b=0b = 0 or c=0c = 0 is infinite or NaN; there is no correction (for instance +0.5 per cell).
  • McNemar without an exact binomial variant; for b+cb + c below about 25 the chi-squared approximation is coarse.
  • Kappa without standard error and without a weighted variant for ordered categories.
