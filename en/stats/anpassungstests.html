Goodness-of-fit tests – background

The computation behind GofTests: Shapiro-Wilk after Royston, Kolmogorov-Smirnov for one and two samples, Lilliefors, Anderson-Darling, Cramér-von Mises, Jarque-Bera and the chi-squared goodness-of-fit test – with the approximations the p-values come from.

What this is about

Many methods assume a particular distribution – usually the normal distribution. A goodness-of-fit test checks whether the data contradict this assumption. The null hypothesis is “the data come from the distribution”; a small p-value speaks against it.

Two things matter here. First, a large p-value does not prove normality, it only finds no contradiction – with 10 values almost anything is “normal”. Second, with large samples every deviation, however small and practically irrelevant, becomes significant. A Q-Q plot (see Q-Q points) often says more than the p-value.

The tests differ in what they are sensitive to:

The Kolmogorov-Smirnov test expects a fully specified distribution. All p-values are clamped to [0,1][0, 1].

Shapiro-Wilk after Royston

The idea: if the data are normally distributed, the sorted values x(i)x_{(i)} lie on a straight line against the expected order statistics of the standard normal distribution. The test statistic is the square of a correlation of this kind:

W=(∑i=1⌊n/2⌋ai(x(n+1−i)−x(i)))2∑i=1n(xi−x)2W = \frac{\left(\sum_{i=1}^{\lfloor n/2\rfloor} a_i\,(x_{(n+1-i)} - x_{(i)})\right)^2}{\sum_{i=1}^{n}(x_i - \bar x)^2}

WW lies between 0 and 1; values close to 1 speak for normality. The exact weights aia_i depend on covariances of the normal order statistics and are costly. Royston (1992, algorithm AS R94) approximates them:

  1. Approximation of the expected order statistics after Blom: mi=Φ−1(i−3/8n+1/4)m_i = \Phi^{-1}\left(\frac{i - 3/8}{n + 1/4}\right), i=1…⌊n/2⌋i = 1 \dots \lfloor n/2\rfloor, and ∑m2\sum m^2 over both halves.
  2. The two outermost weights receive polynomial corrections in u=1/nu = 1/\sqrt n: an=|m1|∑m2+0.221157u−0.147981u2−2.071190u3+4.434685u4−2.706056u5a_n = \frac{|m_1|}{\sqrt{\sum m^2}} + 0.221157u - 0.147981u^2 - 2.071190u^3 + 4.434685u^4 - 2.706056u^5 and for n>5n > 5 correspondingly an−1a_{n-1} with the coefficients 0.042981; −0.293762; −1.752461; 5.682633; −3.582633.
  3. The remaining weights are |mi||m_i| divided by a factor that ensures ∑ai2=1\sum a_i^2 = 1.
  4. For n=3n = 3, a1=1/2a_1 = \sqrt{1/2} exactly.

p-value

Royston transforms WW so that it is approximately normally distributed and gives mean and spread of this normal distribution as polynomials in nn or ln⁡n\ln n:

  • n=3n = 3, exact: p=6π(arcsin⁡W−arcsin⁡3/4)p = \frac{6}{\pi}\left(\operatorname{arcsin}\sqrt W - \operatorname{arcsin}\sqrt{3/4}\right)
  • 4≤n≤114 \le n \le 11: y=−ln⁡(γ−ln⁡(1−W)),γ=−2.273+0.459ny = -\ln(\gamma - \ln(1-W)), \quad \gamma = -2.273 + 0.459n μ=0.544−0.39978n+0.025054n2−0.0006714n3\mu = 0.544 - 0.39978n + 0.025054n^2 - 0.0006714n^3 σ=exp⁡(1.3822−0.77857n+0.062767n2−0.0020322n3)\sigma = \exp(1.3822 - 0.77857n + 0.062767n^2 - 0.0020322n^3)
  • n≥12n \ge 12, with v=ln⁡nv = \ln n: y=ln⁡(1−W)y = \ln(1-W) μ=−1.5861−0.31082v−0.083751v2+0.0038915v3,σ=exp⁡(−0.4803−0.082676v+0.0030302v2)\mu = -1.5861 - 0.31082v - 0.083751v^2 + 0.0038915v^3, \qquad \sigma = \exp(-0.4803 - 0.082676v + 0.0030302v^2)

and p=1−Φ(y−μσ)p = 1 - \Phi\left(\frac{y - \mu}{\sigma}\right). According to Royston the approximation holds for 3≤n≤50003 \le n \le 5000.

Pseudocode – GofTests.shapiroWilk(x)

x ← sorted;  h ← ⌊n/2⌋
if n = 3: a[1] ← √½
else
    for i ← 1 to h: m[i] ← Φ⁻¹((i − 0.375)/(n + 0.25))       negative, since i ≤ n/2
    S ← 2·Σ m[i]²;  u ← 1/√n
    a1 ← C1(u) − m[1]/√S                                   = polynomial + |m₁|/√S
    if n > 5:
        a2 ← C2(u) − m[2]/√S
        fac ← √((S − 2m[1]² − 2m[2]²)/(1 − 2a1² − 2a2²));  a[2] ← a2;  from ← 3
    else
        fac ← √((S − 2m[1]²)/(1 − 2a1²));  from ← 2
    a[1] ← a1
    for i ← from to h: a[i] ← −m[i]/fac
b ← Σᵢ a[i]·(x[n+1−i] − x[i]);   W ← b² / Σ(x − x̄)²
if n = 3: p ← 6/π·(arcsin √W − arcsin √0.75)
else if n ≤ 11: y ← −ln(γ(n) − ln(1−W));  p ← Φ̄((y − μ(n))/σ(n))
else            y ← ln(1−W);             p ← Φ̄((y − μ(ln n))/σ(ln n))
Φ̄ = 1 − Φ, computed directly via erfc (Normal.sf)

Kolmogorov-Smirnov and Lilliefors

One sample

The test statistic is the largest vertical distance between the empirical distribution function and the given FF. Because F^\hat F jumps at every data point, both sides of the step are checked:

D=maxi⁡max⁡(in−F(x(i)),F(x(i))−i−1n)D = \max_i \max\left(\frac{i}{n} - F(x_{(i)}),\ F(x_{(i)}) - \frac{i-1}{n}\right)

The p-value comes from the asymptotic Kolmogorov distribution, with Stephens' correction for finite nn:

t=(n+0.12+0.11n)D,p=QKS(t)=2∑j=1∞(−1)j−1e−2j2t2t = \left(\sqrt n + 0.12 + \frac{0.11}{\sqrt n}\right)D, \qquad p = Q_\text{KS}(t) = 2\sum_{j=1}^{\infty}(-1)^{j-1}e^{-2j^2t^2}

The series is stopped as soon as a term is smaller than 10−1210^{-12}, at the latest after 200 terms; for t<10−12t < 10^{-12}, p=1p = 1.

Two samples

Both samples are sorted and traversed together; DD is the largest distance between their empirical distribution functions. For equal values in both samples both pointers advance simultaneously, so that ties produce no spurious distance. The p-value as above with the effective size ne=n1n2/(n1+n2)n_e = n_1 n_2/(n_1 + n_2) instead of nn.

Lilliefors

If μ\mu and σ\sigma are estimated from the same data, FF automatically fits better, and DD becomes smaller. With the Kolmogorov distribution the p-value would then be far too large. Lilliefors determined the correct distribution by simulation; the module uses the approximation formula of Dallal and Wilkinson (1986), as does the R package nortest:

p=exp⁡(−7.01256D2(n+2.78019)+2.99587Dn+2.78019−0.122119+0.974598n+1.67997n)p = \exp\left(-7.01256\,D^2(n + 2.78019) + 2.99587\,D\sqrt{n + 2.78019} - 0.122119 + \frac{0.974598}{\sqrt n} + \frac{1.67997}{n}\right)

For n>100n > 100, D←D(n/100)0.49D \leftarrow D\,(n/100)^{0.49} and n←100n \leftarrow 100 are set beforehand. If the result exceeds 0.1 the formula is inaccurate; then, with k=(n−0.01+0.85/n)Dk = (\sqrt n - 0.01 + 0.85/\sqrt n)\,D, a piecewise polynomial approximation applies (four ranges up to k=1.31k = 1.31; p=1p = 1 for k≤0.302k \le 0.302).

Framework convention: The GUI catalogue offers “Kolmogorov-Smirnov (Normal)” with the normal distribution taken from the mean and standard deviation of the data – exactly the case for which the KS p-value is too large. The entry therefore reports the distance DD with the p-value after Lilliefors; it thus computes the same as the Lilliefors entry. Until finding WT11 the p-value came from the Kolmogorov distribution: for the ten values 1.2 1.9 2.1 2.2 2.4 2.6 3.9 4.8 6.5 9.7 it read p=0.416p = 0.416, after Lilliefors p=0.043p = 0.043. Anyone who needs a KS test against a specified distribution calls GofTests.ksOneSample directly.

Anderson-Darling and Cramér-von Mises

Both measure the distance of the distribution functions not only at the worst point but integrated over the whole range. With Fi=Φ((x(i)−x)/s)F_i = \Phi\left((x_{(i)} - \bar x)/s\right):

Anderson-Darling

A2=−n−1n∑i=1n(2i−1)(ln⁡Fi+ln⁡(1−Fn+1−i))A^2 = -n - \frac1n\sum_{i=1}^{n}(2i-1)\left(\ln F_i + \ln(1 - F_{n+1-i})\right)

The weight 1/(F(1−F))1/(F(1-F)) in the underlying integral emphasises the tails. For estimated parameters A*2=A2(1+0.75/n+2.25/n2)A^{*2} = A^2(1 + 0.75/n + 2.25/n^2) is formed and the p-value computed piecewise after D'Agostino and Stephens (1986):

Cramér-von Mises

W2=112n+∑i=1n(Fi−2i−12n)2,W*2=W2(1+0.5n)W^2 = \frac{1}{12n} + \sum_{i=1}^{n}\left(F_i - \frac{2i-1}{2n}\right)^2, \qquad W^{*2} = W^2\left(1 + \frac{0.5}{n}\right)

The p-value likewise piecewise, with boundaries at W*2W^{*2} = 0.0275, 0.051 and 0.092.

Framework convention: The reported test statistics are A2A^2 and W2W^2 without the small-sample correction; only the p-value uses A*2A^{*2} or W*2W^{*2}. R nortest::ad.test and cvm.test also report the uncorrected quantity.

Jarque-Bera and chi-squared goodness of fit

Jarque-Bera

With the skewness g1g_1 and the excess kurtosis g2g_2 (moment definition, see Summary statistics):

JB=n6(g12+g224)∼χ22JB = \frac{n}{6}\left(g_1^2 + \frac{g_2^2}{4}\right) \sim \chi^2_2

Under normality n/6g1\sqrt{n/6}\,g_1 and n/24g2\sqrt{n/24}\,g_2 are asymptotically independent standard normal; the sum of their squares is chi-squared with 2 degrees of freedom. The approximation is good only for large nn (several hundred).

Chi-squared goodness of fit

For kk classes with observed frequencies OiO_i and expected EiE_i:

χ2=∑i=1k(Oi−Ei)2Ei,ν=k−1−ddof\chi^2 = \sum_{i=1}^{k}\frac{(O_i - E_i)^2}{E_i}, \qquad \nu = k - 1 - \text{ddof}

ddof\text{ddof} is the number of distribution parameters estimated from the data (for a normal distribution with estimated μ\mu, σ\sigma therefore 2). Classes and expected frequencies are supplied by the caller; the module does not check the rule of thumb Ei≥5E_i \ge 5.

How it is checked

GofTest (17 checks):

  • Jarque-Bera for 1…10 against R tseries: JB=0.6245JB = 0.6245 to 2⋅10−32\cdot10^{-3}, p around 0.7318.
  • Chi-squared goodness of fit {10,20,30,40}\{10, 20, 30, 40\} against uniform: χ2=20\chi^2 = 20, ν=3\nu = 3, p=1.6974⋅10−4p = 1.6974\cdot10^{-4} to 10−810^{-8}.
  • KS against U(0,10)U(0, 10) for {2,4,6,8,10}\{2, 4, 6, 8, 10\}: D=0.2D = 0.2 exactly; two-sample KS with complete separation: D=1D = 1, p<0.1p < 0.1.
  • Shapiro-Wilk n=3n = 3 for {1,2,4}\{1, 2, 4\}: W=0.9642857W = 0.9642857 to 10−610^{-6}; for 1…10 WW between 0.96 and 0.98 and p>0.5p > 0.5; the skewed sample above is rejected with p<0.05p < 0.05.
  • Anderson-Darling, Cramér-von Mises, Lilliefors: plausibility only (statistic positive, p in (0,1](0, 1]).

Limits

  • Anderson-Darling, Cramér-von Mises and Lilliefors are set up only for normality with estimated parameters; other distributions are tested only by KS (with fully specified parameters) or the chi-squared goodness of fit.
  • All p-values except Shapiro-Wilk at n=3n = 3 are approximations. The KS p-values are asymptotic with Stephens' correction, not exact as in R for small nn.
  • Shapiro-Wilk is designed after Royston for 3≤n≤50003 \le n \le 5000; the module does not check the limits. With many equal values (rounded data) WW becomes small without the underlying distribution necessarily being non-normal.
  • Anderson-Darling, Cramér-von Mises and Lilliefors are not secured against reference values in the probe, only for plausibility.
  • Anderson-Darling forms ln⁡(1−Fn+1−i)\ln(1 - F_{n+1-i}). If a value lies more than about 8.3 standard deviations above the mean, F=1F = 1 in double and the logarithm becomes −∞-\infty; downwards the same happens only at about 38 standard deviations, because Φ\Phi stays accurate there through erfc.
