DBSCAN and Gaussian mixtures – background

The computation behind Dbscan and Mischung: density-based clustering with core, border and noise points; mixture distributions with the EM method, k-means++ start and model choice by BIC.

What it is about

k-means and hierarchical clustering (in the package multivariate) look for spherical groups and assign every point. DBSCAN finds groups of any shape and declares isolated points noise. Gaussian mixtures describe the data as a superposition of normal distributions with their own covariances and give each point probabilities instead of a hard assignment.

DBSCAN

A point is a core point if at least minPoints points lie within distance ε\varepsilon (itself included). A cluster is the set of all points reachable from a core point via a chain of core points; a border point lies near a core point without being one and belongs to the cluster that reaches it first. The rest is noise (label −1).

for each point p not yet visited:
    N ← neighbours(p, ε);  if |N| < minPoints: p provisionally noise; continue
    new cluster c;  queue ← N
    while queue not empty:  q ← next
        if q noise or without cluster: q → c
        if q core point: its neighbours without cluster into the queue

What depends on the order and what does not. Two core points are density-connected if a chain of core points joins them in which consecutive ones are at most ε\varepsilon apart. This relation is reflexive, symmetric (the distance is) and transitive (chains can be joined) – an equivalence relation; its classes are the clusters, the same for every traversal order (Ester et al. 1996, Lemmas 1 and 2). Only a border point can lie near two clusters. It then belongs to the cluster that reaches it first; in the code that is the cluster with the smallest first core point in input order. The bound ≤ε\le \varepsilon is closed: a point at exactly distance ε\varepsilon counts as a neighbour.

Cost. The neighbour lists cost n2n^2 distances; afterwards each point enters the queue at most once and each core point's neighbour list is traversed once – together O(n2)O(n^2) time and, if almost all points are neighbours, as much memory.

Mixtures with EM

The model p(x)=∑kπkN(x∣μk,Σk)p(x) = \sum_k \pi_k\,N(x \mid \mu_k, \Sigma_k) is fitted with the EM method. E-step: responsibilities γik=πkN(xi∣μk,Σk)/∑jπjN(xi∣μj,Σj)\gamma_{ik} = \pi_k N(x_i \mid \mu_k, \Sigma_k)/\sum_j \pi_j N(x_i \mid \mu_j, \Sigma_j). M-step: Nk=∑iγikN_k = \sum_i\gamma_{ik}, πk=Nk/n\pi_k = N_k/n, μk=∑iγikxi/Nk\mu_k = \sum_i\gamma_{ik}x_i/N_k, Σk=∑iγik(xi−μk)(xi−μk)T/Nk+10−9I\Sigma_k = \sum_i\gamma_{ik}(x_i - \mu_k)(x_i - \mu_k)^T/N_k + 10^{-9}I (against degeneracy). The log-likelihood rises in every step; stop when its relative change falls below the tolerance. Start after k-means++ with a fixed random source. For choosing kk:

BIC⁡=−2log⁡L+pln⁡n,p=k−1+kd+kd(d+1)2.\mathrm{BIC} = -2\log L + p\ln n, \qquad p = k - 1 + k d + k\,\frac{d(d+1)}{2}.

The number pp of free quantities: k−1k - 1 weights (the last follows from ∑πk=1\sum\pi_k = 1), kdk d means and per component the d(d+1)/2d(d+1)/2 entries of a symmetric covariance matrix. The penalty pln⁡np\ln n comes from the Laplace approximation of the integral over the parameters (Schwarz 1978); it grows with nn and therefore, unlike AIC, picks the true kk with probability tending to one as the data grow.

Why EM never lowers the likelihood

For every distribution γi⋅\gamma_{i\cdot} over the components, Jensen's inequality (the logarithm is concave) gives

log⁡L=∑ilog⁡∑kπkN(xi∣μk,Σk)≥∑i∑kγiklog⁡πkN(xi∣μk,Σk)γik,\log L = \sum_i \log\sum_k \pi_k N(x_i \mid \mu_k, \Sigma_k) \;\ge\; \sum_i\sum_k \gamma_{ik}\,\log\frac{\pi_k N(x_i \mid \mu_k, \Sigma_k)}{\gamma_{ik}},

with equality exactly when γik\gamma_{ik} is the posterior probability – that is the E-step. The M-step maximises the right-hand side for fixed γ\gamma: differentiating with respect to μk\mu_k gives the weighted mean, with respect to Σk\Sigma_k the weighted covariance, and for πk\pi_k, with the Lagrange multiplier for ∑πk=1\sum\pi_k = 1, the share Nk/nN_k/n. The lower bound rises in the M-step and touches log⁡L\log L again in the next E-step; hence log⁡L\log L cannot fall (Dempster, Laird, Rubin 1977). This says nothing about the global maximum – the likelihood of a mixture has many local maxima and is even unbounded: put one μk\mu_k on a data point and let Σk→0\Sigma_k \to 0, and log⁡L\log L grows without limit. The addition 10−9I10^{-9}I to every covariance prevents exactly this collapse.

Computing in logarithms

For a point far from all centres every πkN(xi∣⋅)\pi_k N(x_i \mid \cdot) is below the smallest representable number, and the responsibilities would be 0/0. The code therefore computes gik=log⁡πk+log⁡N(xi∣μk,Σk)g_{ik} = \log\pi_k + \log N(x_i \mid \mu_k, \Sigma_k) and

log⁡∑kegik=mi+log⁡∑kegik−mi,mi=maxk⁡gik,log⁡det⁡Σk=2∑alog⁡Laa,\log\sum_k e^{g_{ik}} = m_i + \log\sum_k e^{g_{ik} - m_i}, \quad m_i = \max_k g_{ik}, \qquad \log\det\Sigma_k = 2\sum_a \log L_{aa},

with the Cholesky factorisation Σk=LLT\Sigma_k = L L^T; the largest term is then exactly e0=1e^0 = 1 and nothing underflows. If the Cholesky factorisation fails, the covariance is degenerate and the computation stops with a message.

Start after k-means++

The first centre is a random data point; each further one is drawn with probability D(x)2/∑D2D(x)^2/\sum D^2, D(x)D(x) the distance to the nearest centre already chosen. For k-means the expected error sum of this start is at most O(log⁡k)O(\log k) times the best (Arthur and Vassilvitskii 2007); for EM it is merely a good beginning. The random source is fixed, so the result is repeatable. Gap: no counter-probe checks the D2D^2 weighting – with well-separated groups EM finds the same maximum even from a worse start.

How it is checked

  • DBSCAN by hand: chain with border points at both ends one cluster, group of three a second, outlier noise; in 2D a point next to a border point only is noise as well.
  • One component: EM gives the closed-form maximum-likelihood estimate to 1e-12.
  • Two separated normal distributions (1200 points): weights, means and variances equal to the per-group statistics to 1e-4, log-likelihood rises in every step, BIC by hand, BIC chooses k=2k = 2.

Limits

Neighbour search quadratic (up to some tens of thousands of points); Euclidean distance; one ε\varepsilon for all densities (DBSCAN does not separate groups of very different density). EM finds a local maximum, depending on the start; full covariances cost O(nkd2+kd3)O(n k d^2 + k d^3) per step.
