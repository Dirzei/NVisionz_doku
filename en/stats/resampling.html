Resampling, power and data preparation – background

The computation behind Resample and Prep: jackknife, permutation test, Monte Carlo, k-fold cross-validation, power and sample size of the t-test; imputing missing values, Box-Cox with optimal λ, Yeo-Johnson, standardising, weighted statistics and group aggregation.

What this is about

The classical methods derive the distribution of a statistic from assumptions – normality, large samples. Resampling goes the other way: it generates many new samples from the available data and looks at how the statistic varies across them. That needs computing time instead of formulas and works also for statistics for which no formula exists.

Data preparation is on the same page because it often decides whether a classical method is applicable: a skewed quantity becomes approximately normal through a Box-Cox transformation, and then t-test and analysis of variance hold again.

Framework convention: All random procedures receive an Rng with a fixed seed (see Random numbers). Same seed, same result – bit-identical. The bootstrap intervals are in Estimate (see Bootstrap intervals).

Jackknife

The jackknife (Quenouille, Tukey) leaves out each value once and computes the statistic θ^(i)\hat\theta_{(i)} on the remaining n−1n-1 values. Bias and standard error follow from the spread of these nn values:

θ(⋅)=1n∑iθ^(i),bias^=(n−1)(θ(⋅)−θ^),se^=n−1n∑i(θ^(i)−θ(⋅))2\bar\theta_{(\cdot)} = \frac1n\sum_i\hat\theta_{(i)}, \qquad \widehat{\text{bias}} = (n-1)(\bar\theta_{(\cdot)} - \hat\theta), \qquad \widehat{\text{se}} = \sqrt{\frac{n-1}{n}\sum_i(\hat\theta_{(i)} - \bar\theta_{(\cdot)})^2}

The factor n−1n-1 compensates for the subsamples being almost identical. For the mean the jackknife gives exactly s/ns/\sqrt n and bias 0. For non-smooth statistics like the median the jackknife standard error is unreliable; the bootstrap is better there.

θ ← f(x)
for i ← 1 to n:  jack[i] ← f(x without xᵢ)
θ̄ ← mean(jack)
bias ← (n − 1)·(θ̄ − θ)
se ← √((n − 1)/n · Σ(jack[i] − θ̄)²)
return (θ, bias, se)                               θ uncorrected

Source: envisionz-framework-stats/src/envisionz/stats/resample/Resample.java, method jackknife.

Permutation test

Under the null hypothesis “both groups come from the same distribution” the group labels are arbitrary. So one shuffles the pooled values, splits them again into groups of the original sizes and recomputes the test statistic. The fraction of shuffles with a test statistic at least as extreme is the p-value – without any distributional assumption.

p=1+#{b:|Tb|≥|Tobs|}1+Bp = \frac{1 + \#\{b: |T_b| \ge |T_\text{obs}|\}}{1 + B}

The “+1” in numerator and denominator counts the observed arrangement itself as one of the possible ones; so pp is never zero, and the test keeps its level exactly. For two groups of 5 values there are only C(10,5)=252C(10, 5) = 252 splits; with B=3000B = 3000 random shuffles each is drawn about twelve times on average.

T_obs ← |stat(x, y)|;  pool ← x ∪ y;  count ← 0
for b ← 1 to B:
    π ← rng.permutation(N)
    a ← pool[π[1..n₁]];  c ← pool[π[n₁+1..N]]
    if |stat(a, c)| ≥ T_obs·(1 − 10⁻¹⁰): count ← count + 1   count equal values despite rounding
return (count + 1)/(B + 1)

Source: envisionz-framework-stats/src/envisionz/stats/resample/Resample.java, method permutationTest; the default statistic is the difference of means. The test is always two-sided via the absolute value. In the catalogue: B=3000B = 3000, seed 1.

Cross-validation and Monte Carlo

k-fold cross-validation estimates how well a model predicts new data – more honestly than R2R^2, which rises with every additional term. The data are shuffled randomly and distributed to kk parts (position ii of the shuffle goes into part imod⁡ki \,\operatorname{mod}\, k). Each part serves once as the test set while the model is fitted on the others:

MSECV⁡=1n∑parts∑i∈part(y^i(−part)−yi)2\mathrm{MSE}_\text{CV} = \frac1n\sum_{\text{parts}}\ \sum_{i ∈ \text{part}}(\hat y_i^{(-\text{part})} - y_i)^2

The model is a function CvModel.predict(trainX, trainY, testX), i.e. arbitrary. monteCarlo(sampler, stat, B) averages a statistic over BB generated samples – for instance to study the behaviour of an estimator under an assumed distribution.

Power and sample size of the t-test

The power of a test is the probability of detecting a difference that really exists. For the two-sided two-sample t-test with nn values per group and standardised effect d=Δ/σd = \Delta/\sigma the module computes with the normal approximation:

δ=dn/2,1−β=1−Φ(z1−α/2−δ)+Φ(−z1−α/2−δ)\delta = d\sqrt{n/2}, \qquad 1 - \beta = 1 - \Phi(z_{1-\alpha/2} - \delta) + \Phi(-z_{1-\alpha/2} - \delta)

Conversely the sample size per group for a desired power is

n=⌈2(z1−α/2+z1−βd)2⌉n = \left\lceil 2\left(\frac{z_{1-\alpha/2} + z_{1-\beta}}{d}\right)^2\right\rceil

Framework convention: Both formulas use the normal distribution instead of the noncentral t distribution. This slightly underestimates the required sample size, noticeably for small nn: for d=0.5d = 0.5, power 80 % and α=0.05\alpha = 0.05 the module gives 63 per group, the exact computation with the noncentral t distribution 64.

Data preparation

Missing values

Missing values are NaN. meanImpute and medianImpute replace them by the mean or median of the available values; missingFraction reports the fraction. Imputation artificially reduces the spread and is only acceptable for a few gaps.

Box-Cox

For positive values the Box-Cox transformation

x(λ)={xλ−1λλ≠0ln⁡xλ=0x^{(\lambda)} = \begin{cases}\dfrac{x^\lambda - 1}{\lambda} & \lambda \ne 0\\ \ln x & \lambda = 0\end{cases}

is continuous in λ\lambda and includes reciprocal (λ=−1\lambda = -1), logarithm (0), square root (½) and identity (1). The best λ\lambda is the one under which the transformed data are closest to normal – measured by the profile log-likelihood:

ℓ(λ)=−n2ln⁡σ^2(λ)+(λ−1)∑iln⁡xiℓ(\lambda) = -\frac n2\ln\hat\sigma^2(\lambda) + (\lambda - 1)\sum_i\ln x_i

with the population variance σ^2(λ)\hat\sigma^2(\lambda) of the transformed values. The second term is the Jacobian of the transformation; without it variances for different λ\lambda would not be comparable. The module maximises ℓℓ with Brent's method for one-dimensional minimisation (from framework-math) on [−2,2][-2, 2], tolerance 10−610^{-6}.

function boxCoxLambda(x):
    negLL(λ) ← −( −n/2·ln(populationVariance(boxCox(x, λ))) + (λ − 1)·Σ ln xᵢ )
    return Optimize.brentMin(negLL, −2, 2, 1e−6)

Source: envisionz-framework-stats/src/envisionz/stats/prep/Prep.java, methods boxCox, boxCoxLambda, boxCoxLogLik.

Yeo-Johnson

Box-Cox requires positive values. Yeo-Johnson extends it to all real numbers by treating positive and negative values separately:

ψ(x,λ)={(x+1)λ−1λx≥0,λ≠0ln⁡(x+1)x≥0,λ=0−(1−x)2−λ−12−λx<0,λ≠2−ln⁡(1−x)x<0,λ=2\psi(x, \lambda) = \begin{cases}\dfrac{(x+1)^\lambda - 1}{\lambda} & x \ge 0,\ \lambda \ne 0\\ \ln(x+1) & x \ge 0,\ \lambda = 0\\ -\dfrac{(1-x)^{2-\lambda} - 1}{2-\lambda} & x < 0,\ \lambda \ne 2\\ -\ln(1-x) & x < 0,\ \lambda = 2\end{cases}

The module does not compute an optimal λ\lambda for Yeo-Johnson; it is supplied.

Scaling, ranks, weights, aggregation

  • standardize: (x−x)/s(x - \bar x)/s, with ss using denominator n−1n-1.
  • minMaxScale(x, a, b): a+(x−min⁡)/(max⁡−min⁡)⋅(b−a)a + (x - \min)/(\max - \min)\cdot(b - a).
  • rank: average ranks as in the rank tests.
  • weightedMean: ∑wixi/∑wi\sum w_i x_i/\sum w_i; weightedVariance: ∑wi(xi−xw)2/∑wi\sum w_i(x_i - \bar x_w)^2/\sum w_i, without a correction for the degrees of freedom.
  • aggregate(values, groups, f): splits by group key, applies ff per group and returns the results in order of first appearance (“split-apply-combine”).

Worked examples

Jackknife of the standard deviation

For the ten diameters with the outlier 9.8 (see Summary statistics): s=2.382s = 2.382, jackknife bias −0.978-0.978, standard error 2.134. The standard error is almost as large as the estimate – a clear hint that ss depends on a single value.

Permutation test

{4.1;5.0;4.6;5.3;4.8}\{4.1;\ 5.0;\ 4.6;\ 5.3;\ 4.8\} against {5.2;5.9;5.1;6.0;5.5}\{5.2;\ 5.9;\ 5.1;\ 6.0;\ 5.5\}, B=9999B = 9999, seed 1: p=0.0300p = 0.0300; exactly, over all (105)=252\binom{10}{5} = 252 splits, it is 8/252=0.03178/252 = 0.0317. Equal values of |T||T| count, even when the sum in a different order comes out one rounding step smaller (until 2026-09-29 they were dropped and the module gave 0.0229). For completely separated groups {1…5}\{1 \dots 5\} against {10…14}\{10 \dots 14\} the exact value is 2/252=0.00792/252 = 0.0079; with B=3000B = 3000 the module gives 0.0097.

Power

d=0.5d = 0.5, α=0.05\alpha = 0.05: power 0.201 at n=10n = 10, 0.353 at n=20n = 20, 0.807 at n=64n = 64 per group. Sample size for 80 % power: 63; for d=0.8d = 0.8 and 90 %: 33.

Box-Cox

For the right-skewed values 0.5 0.8 1.1 1.3 1.9 2.4 3.5 5.2 8.8 15.0 (skewness 1.54), λ^=−0.151\hat\lambda = -0.151, close to the logarithm; afterwards the skewness is 0.053. For the Fibonacci numbers 1 … 34, λ^=0.039\hat\lambda = 0.039. All values recomputed with the module.

How it is checked

ResampledPrepTest (16 checks): jackknife of the mean with bias 0 and standard error s/ns/\sqrt n to 10−910^{-9}; permutation test with separated groups p<0.05p < 0.05, with identical groups p>0.5p > 0.5; power between 0 and 1 and rising with nn; sample size positive; cross-validation of an exact straight line with MSE⁡<10−9\mathrm{MSE} < 10^{-9}; mean imputation, fraction of missing values, Box-Cox with λ=0\lambda = 0 equal to ln⁡\ln, standardising (mean 0, standard deviation 1), min-max scaling, weighted mean and group aggregation.

Limits

  • Power and sample size only for the two-sided two-sample t-test and only with the normal approximation.
  • The permutation test shuffles randomly; there is no complete enumeration of all splits for small groups. Two-sided only.
  • Box-Cox searches λ\lambda only in [−2,2][-2, 2]; if the optimum lies outside, the boundary is returned. Values ≤0\le 0 give NaN.
  • No optimal λ\lambda for Yeo-Johnson.
  • The weighted variance is the population form; for frequency weights the correction ∑w/(∑w−1)\sum w/(\sum w - 1) is missing.
  • Cross-validation only with squared error; no stratified split.
