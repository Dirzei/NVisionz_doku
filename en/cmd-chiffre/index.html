envisionz-commandline-chiffre

Encrypt, decrypt, analyse and break ciphers

Overview of the command-line tool, as of 29 September 2026. It makes the methods of the cipher module usable from the command line: list them, describe them, encrypt and decrypt, analyse a text, break a method and query the collection of pieces.

8tasks (-op:)
2source files in package cmd.chiffre
5return values
18checks in the call probe

What the tool is for

The cipher module contains methods, analysis tools and breakers. This tool hands them to the command line without having to write a program: text in, key alongside, result out. Key parts are passed as -<name>:<value>; -op:info names them for each method.

What it can do

java cmd.chiffre.Chiffre -op:liste
java cmd.chiffre.Chiffre -op:info -verfahren:vigenere
java cmd.chiffre.Chiffre -op:ver -verfahren:vigenere -schluesselwort:LEMON -text:"attack at dawn"
java cmd.chiffre.Chiffre -op:ent -verfahren:enigma -walzen:"II IV V" -ringe:BUL -grundstellung:BLA -ein:spruch.txt
java cmd.chiffre.Chiffre -op:analyse -ein:geheim.txt
java cmd.chiffre.Chiffre -op:brich [-verfahren:vigenere] -sprache:de -ein:geheim.txt
java cmd.chiffre.Chiffre -op:sammlung [-stueck:<name>] [-loesung:ja]
java cmd.chiffre.Chiffre -op:tafel -de:<korpus> -en:<korpus> -ziel:<ordner>

Methods

liste names the available methods, info describes one with its key parts. ver encrypts, ent decrypts. The text comes from -text or from a file (-ein).

Analysis and breaking

analyse examines a ciphertext. brich tries to break the method, for a given method if wanted, and names the language of the expected plaintext (-sprache). If the plaintext found is not convincing, the return value 10 says so.

Collection and tables

sammlung queries the collection of pieces, a single piece and, if wanted, its solution. tafel builds tables into a target folder from one corpus each in German and English.

Values from files

A key value of the form @datei is read from the file. This applies, for example, to the key text of a book cipher.

Return values

ValueMeaning
0fine
1no switch given, or help
2wrong switch or key
3other error
10when breaking, no convincing plaintext (language similarity below 0.6)

What it builds on

  • chiffre: all methods, analyses, breakers and the collection. It is the only dependency of this tool.

The user interface to this module is the app app-chiffre.

State and limits

  • All eight tasks exist. main only calls lauf(args, aus, err); the call probe tests lauf directly and covers each task once, plus the return values, unknown switches and @datei.
  • The tool contains no method logic of its own, only switch evaluation and output.
