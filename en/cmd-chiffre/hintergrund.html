Switches, breaking and language tables

What the command line decides although methods and breakers live in the framework: how switches become a key, when a broken text counts as convincing and what a language table contains.

What this is about

The tool does not know the individual methods. It reads their key parts from the catalogue and passes them on. It makes decisions of its own only at the edges: with the switches, with the choice of breakers and with the return value.

From switch to key

Whatever is not control must be a key part of the method. A typing error such as -schlussel: therefore does not go unnoticed but gives return value 2 with the list of possible names. If a value starts with @, the named file is read; this is meant for the key text of a book cipher.

-op:info shows each default on one line. More than 50 characters are cut to 47 and ended with three dots, line breaks appear as \n.

Groups of five

Letter-preserving methods output groups of five when encrypting, as was usual in radio traffic. When decrypting the default is 0, no groups. -gruppen: sets the length explicitly. Methods that do not produce letters stay ungrouped.

When a text counts as broken

The breakers rate their candidates by language similarity aa (formula on the background page of the app). The tool takes the best candidate over all methods tried:

return value={0max⁡a≥0.610otherwise or without a candidate.\text{return value} = \begin{cases} 0 & \max a \ge 0.6 \\ 10 & \text{otherwise or without a candidate.} \end{cases}

Without -verfahren the tool tries the guesses of the analysis and names them first. The choice is deliberately visible: whoever gets an unexpected result can see which methods were considered at all.

Language tables from a corpus

-op:tafel reads all files below the given folders, including subfolders. Per language they yield two files: quadgramme_xx.bin.gz with the groups of four and einzel_xx.txt with the single letters. A language without a switch is skipped.

Limits

  • Return value 0 when breaking means “looks like the language”, not “is the right plaintext”.
  • At the command line nobody can be asked. An existing file under -aus: or an existing table therefore gives return value 2 and stays untouched; only -ueberschreiben replaces it.
