Continuation methods – background

Homotopy with predictor and corrector (HomotopySolver) and arc-length continuation (ArcLengthHomotopySolver) for systems that Newton cannot reach from the start.

What this is about

Newton methods converge fast if the start lies near the solution, and not at all if it lies far away or the system is near a singularity – at the sonic limit of a nozzle, say, or at a regime change. Continuation (homotopy) avoids this: instead of solving the hard problem at once, one begins with a trivial one whose solution is the start point itself and deforms it step by step into the desired one. Every intermediate step is an easy Newton problem with the last solution as its start.

The embedding

From the start point x0\mathbf x_0 and the Jacobian J0=J(x0)\mathbf J_0=\mathbf J(\mathbf x_0) one forms a linear auxiliary problem F0(x)=J0(x−x0)\mathbf F_0(\mathbf x)=\mathbf J_0(\mathbf x-\mathbf x_0), whose solution is x0\mathbf x_0, and blends it with the actual problem:

H(x,t)=(1−t)J0(x−x0)+tF(x)=0,t∈[0,1]\mathbf H(\mathbf x,t) = (1-t)\,\mathbf J_0(\mathbf x-\mathbf x_0) + t\,\mathbf F(\mathbf x) = \mathbf 0, \qquad t\in[0,1]

At t=0t=0 the solution is x0\mathbf x_0, at t=1t=1 we have H=F\mathbf H=\mathbf F. The solutions x(t)\mathbf x(t) form a path that is followed from t=0t=0 to t=1t=1. Between path points a predictor-corrector method is used: the predictor estimates the next path point from the tangent, the corrector improves the estimate with Newton on H(x,tk+1)=0\mathbf H(\mathbf x,t_{k+1})=\mathbf 0. The tangent follows from differentiating H(x(t),t)=0\mathbf H(\mathbf x(t),t)=\mathbf 0 with respect to tt:

∂H∂xdxdt+∂H∂t=0,∂H∂x=tJ(x)+(1−t)J0,∂H∂t=F(x)−J0(x−x0)\frac{\partial\mathbf H}{\partial\mathbf x}\,\frac{d\mathbf x}{dt} + \frac{\partial\mathbf H}{\partial t} = \mathbf 0, \qquad \frac{\partial\mathbf H}{\partial\mathbf x} = t\,\mathbf J(\mathbf x) + (1-t)\,\mathbf J_0, \quad \frac{\partial\mathbf H}{\partial t} = \mathbf F(\mathbf x) - \mathbf J_0(\mathbf x-\mathbf x_0)

Worked example

For F(x)=x3−3x+1F(x)=x^3-3x+1 and x0=2x_0=2 we have F(x0)=3F(x_0)=3 and J0=9J_0=9. On the path, at t=0.5t=0.5, lies the point x=1.8232x=1.8232. There ∂H/∂x=0.5⋅(3x2−3)+0.5⋅9=7.986\partial H/\partial x=0.5\cdot(3x^2-3)+0.5\cdot 9=7.986 and ∂H/∂t=F−J0(x−x0)=3.182\partial H/\partial t=F-J_0(x-x_0)=3.182, so dx/dt=−0.3984dx/dt=-0.3984. The predictor for t=0.75t=0.75 is x=1.8232−0.25⋅0.3984=1.7236x=1.8232-0.25\cdot0.3984=1.7236. The corrector solves 0.25⋅9(x−2)+0.75F(x)=00.25\cdot 9\,(x-2)+0.75\,F(x)=0 and finds x=1.7100x=1.7100 (check: −0.6525+0.6528≈0-0.6525+0.6528\approx 0). At t=1t=1 the path ends at the root x=1.532x=1.532. (Recomputed with a small script outside the module.)

The method HomotopySolver

The solver stands outside the Newton family and uses one of its members as inner corrector (SolverFactory.create with the inner configuration; without an explicit choice its scaling is STATIC_NORM). The parameter is tt itself; the step size dsds is a piece of parameter. The predictor is limited (limitPredictorStep) and projected onto the variable bounds.

  • Success of the corrector: residual below the tolerance of the inner solver. The path point is then accepted.
  • Failure: dsds is multiplied by the reduction factor, the predictor is recomputed, up to the maximum number of reductions; if dsds falls below dsmin⁡ds_{\min}, the run stops at the tt reached so far.
  • Step size control by the corrector effort: few inner iterations (below the target) enlarge dsds, more than twice the target reduce it.
  • Stagnation: if the corrector residual improves by less than 5 % three times in a row, the run stops and points to a physical singularity on the path; the recommendation is then Newton with a different start.
Convention in the framework: defaults of HomotopyConfig: ds0=0.1ds_0=0.1, dsmin⁡=10−4ds_{\min}=10^{-4}, dsmax⁡=0.5ds_{\max}=0.5, reduction factor 0.5, growth factor 1.5, target 5 inner iterations, at most 10 reductions per step. There are prepared configurations, for instance one for the transition at the sonic limit with smaller steps (ds0=0.02ds_0=0.02, dsmax⁡=0.1ds_{\max}=0.1).

Arc-length continuation

With tt as parameter one fails when the path has a turning point: there dx/dt→∞d\mathbf x/dt\to\infty, and tt would have to decrease for a while. Arc-length continuation therefore makes the arc length the parameter. It stays finite even where dx/dtd\mathbf x/dt becomes large; the step then runs mainly in x\mathbf x. The implementation in the framework does not, however, pass through a genuine turning point in tt: the tangent is mirrored as soon as its tt component points backwards (see the convention below). The state is extended to y=(x,t)∈Rn+1\mathbf y=(\mathbf x,t)\in\mathbb R^{n+1}, and the arc equation is added to the nn equations H=0\mathbf H=\mathbf 0:

N(y)=‖w∘(y−yprev⁡)‖2−ds2=0N(\mathbf y) = \lVert\mathbf w\circ(\mathbf y-\mathbf y_{\mathrm{prev}})\rVert^2 - ds^2 = 0

The weight vector w\mathbf w (1/1/magnitude of the variables, 11 for tt) makes sure that variables of very different size enter the length fairly. Per path step: tangent y˙\dot{\mathbf y} from ∂H/∂yy˙=0\partial\mathbf H/\partial\mathbf y\,\dot{\mathbf y}=\mathbf 0 with ‖w∘y˙‖=1\lVert\mathbf w\circ\dot{\mathbf y}\rVert=1; predictor y+dsy˙\mathbf y+ds\,\dot{\mathbf y}; corrector: Newton in the extended space on G=(H,N)\mathbf G=(\mathbf H,N) with Armijo damping.

Convention in the framework: if the predictor goes beyond t=1t=1, it is cut back to t=1t=1. In the last step the target plane t−1=0t-1=0 replaces the arc equation; the corrector then solves H(x,1)=F(x)=0\mathbf H(\mathbf x,1)=\mathbf F(\mathbf x)=\mathbf 0, i.e. the real system. This was a bug and has been fixed: the corrector was previously allowed to run beyond t=1t=1 in the extended space, and any overshoot counted as success. On the test model X⋅X+Y=6,X−Y=0X\cdot X+Y=6,\;X-Y=0 the "solution" came out at t=1.0435t=1.0435 with X=2.0256X=2.0256 instead of 2; for t≠1t\neq1 a path point is not a root of F\mathbf F. The tangent is kept in the forward direction of tt (if its tt component points down, the whole tangent is mirrored); tt thus runs monotonically forward, and a turning point is not passed through. If the corrector fails at such a narrow spot, dsds is halved instead of turning back – with the artificial Newton embedding a reversal in tt is a numerical artefact anyway, not a genuine fold point. Further fixed values: corrector tolerance 10−710^{-7} on ‖G‖\lVert\mathbf G\rVert, at most 50 corrector iterations, Armijo with c1=10−4c_1=10^{-4}, ρ=0.5\rho=0.5, αmin⁡=10−8\alpha_{\min}=10^{-8}, at most 200 path steps; dsds stays constant and is only halved after a failure.

Pseudocode – HomotopySolver.solve and ArcLengthHomotopySolver.solve

// natural parameter t (HomotopySolver)
x ← x0;  J0 ← Jacobian(x0);  t ← 0;  ds ← dsInit
while t < 1:
    tNext ← min(t + ds, 1)
    xP ← x + (tNext − t)·dx/dt                  tangent from t·J(x)+(1−t)·J0
    limit and project xP
    repeat until success or reductions exhausted:
        solve H(x, tNext) = 0 with inner solver from xP
        if residual < tolerance: accept;  leave the repeat
        else ds ← ds·reductionFactor;  if ds < dsMin: stop without success
        tNext ← t + ds;  new predictor
    check stagnation (three steps under 5 %: stop)
    t ← tNext;  ds ← adapt(ds, inner iterations)

// arc length (ArcLengthHomotopySolver)
y ← (x0, 0);  tangent ← initial tangent, weighted and normalised
while y[t] < 1 and steps < 200:
    yP ← y + ds·tangent;  if yP[t] > 1: cut back to t = 1
    targetPlane ← (yP[t] ≥ 1);  if targetPlane: yP[t] ← 1
    y′ ← corrector(yP)                          Newton on G = (H, arc equation or t−1)
    if not converged: ds ← ds/2;  if ds < dsMin: stop;  continue
    tangent ← recomputed at y′;  turned into forward t direction
    y ← y′

How it is tested

Limits

  • The linear embedding F0=J0(x−x0)\mathbf F_0=\mathbf J_0(\mathbf x-\mathbf x_0) does not reproduce any nonlinearity; if a physical singularity (sonic transition, phase boundary, structural discontinuity) lies on the path, the path can stagnate. The solver reports this and advises Newton with a good start.
  • Arc-length continuation is implemented in the "phase 1" version: constant step size, no step size control by corrector effort, no turning-point diagnostics, no equilibration in the extended system. The tangent is kept in the forward direction of tt; a turning point in tt is not passed through, and paths with a genuine backward loop in tt are not followed. For an embedding with genuine fold points the method would not be suitable in this form.
  • Both methods require a square system (as many free variables as equations).
  • The run is sequential along the path and expensive with many path steps: each step is a complete Newton run.
