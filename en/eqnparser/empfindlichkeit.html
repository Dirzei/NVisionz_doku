Sensitivity, uncertainty and model fitting – background

How strongly the solution depends on the parameters (Empfindlichkeit), how their uncertainty propagates (Unsicherheit, linear and Monte Carlo), and which parameters best match measurements (Modellanpassung, Levenberg-Marquardt).

What this is about

A solved model answers “what comes out?”. The next question is almost always “how sure is that?” An efficiency from a test rig is known to half a percent, a tip clearance to a tenth of a millimetre – what does that mean for thrust and fuel flow? And the other way round: which loss coefficients make the model match the measurement? All three questions lead to the same quantity, the derivative of the solution with respect to the parameters. After the solve it costs only one factorisation of the Jacobian the solver had anyway.

Sensitivity from the implicit function theorem

The model is F(x,p)=0\mathbf F(\mathbf x,\mathbf p)=\mathbf 0 with free quantities x∈Rn\mathbf x\in\mathbb R^n and fixed quantities p∈Rm\mathbf p\in\mathbb R^m, some of which are chosen as parameters. If Jx=∂F/∂x\mathbf J_x=\partial\mathbf F/\partial\mathbf x is regular at the solution, the implicit function theorem gives a smooth solution function x(p)\mathbf x(\mathbf p). Differentiating F(x(p),p)=0\mathbf F(\mathbf x(\mathbf p),\mathbf p)=\mathbf 0 with respect to p\mathbf p yields

Jx∂x∂p=−Jp,Jp=∂F∂p∈Rn×m.\mathbf J_x\,\frac{\partial\mathbf x}{\partial\mathbf p}=-\mathbf J_p,\qquad \mathbf J_p=\frac{\partial\mathbf F}{\partial\mathbf p}\in\mathbb R^{n\times m}.

One LU factorisation of Jx\mathbf J_x and mm back substitutions give the whole matrix S=∂x/∂p\mathbf S=\partial\mathbf x/\partial\mathbf p. Both Jacobians come from the same symbolic derivatives the solver uses; there is no difference quotient and no step size. For comparisons across quantities of different dimension the relative sensitivity is handier, the change in percent per percent:

sijrel⁡=∂xi∂pjpjxi.s_{ij}^{\mathrm{rel}}=\frac{\partial x_i}{\partial p_j}\,\frac{p_j}{x_i}.

If Jx\mathbf J_x is singular at the solution there is no unique solution function; the method reports this instead of returning a number.

Propagation of uncertainty

Linear (first order)

If the parameters have covariance Cp\mathbf C_p (for independent parameters diag⁡(σpj2)\mathrm{diag}(\sigma_{p_j}^2)), then to first order

Cx=SCpST,σxi=(Cx)ii.\mathbf C_x=\mathbf S\,\mathbf C_p\,\mathbf S^{\mathsf T},\qquad \sigma_{x_i}=\sqrt{(\mathbf C_x)_{ii}}.

This is exact as long as x(p)\mathbf x(\mathbf p) is linear over the spread, and costs nothing beyond S\mathbf S. The off-diagonal shows whether two results rise together or move in opposite directions – in the linear example X+Y=A,X−Y=BX+Y=A,\;X-Y=B one has cov⁡(X,Y)=(σA2−σB2)/4\mathrm{cov}(X,Y)=(\sigma_A^2-\sigma_B^2)/4, negative as soon as BB is less certain than AA.

Monte Carlo

Where linearisation does not hold (large spread, kinks, regime changes), the model is solved for many parameter sets and the sample is evaluated. The sets do not come from a random number generator but from a Sobol sequence, mapped onto the distribution through the normal quantile:

pj(k)=pj+σpjΦ−1(uj(k)),u(k)Sobol point k.p_j^{(k)}=\bar p_j+\sigma_{p_j}\,\Phi^{-1}\!\big(u_j^{(k)}\big),\qquad \mathbf u^{(k)}\ \text{Sobol point }k.

Quasi-random points fill the cube more evenly than random numbers; for smooth models the error of the mean falls almost like 1/N1/N instead of 1/N1/\sqrt N. And the result is repeatable: same seed, same numbers. Each sample starts from the solution at the mean (warm start); runs that do not converge are counted and left out. Afterwards the parameters are back at the mean.

Model fitting

Given are data points k=1…Kk=1\dots K, each with settings (operating point) and measured quantities yk,iy_{k,i} with uncertainty σk,i\sigma_{k,i}. Sought are parameters p\mathbf p for which the model best matches the measurements:

minp⁡χ2(p)=∑k∑irk,i2,rk,i=xk,i(p)−yk,iσk,i.\min_{\mathbf p}\ \chi^2(\mathbf p)=\sum_k\sum_i r_{k,i}^2,\qquad r_{k,i}=\frac{x_{k,i}(\mathbf p)-y_{k,i}}{\sigma_{k,i}}.

Each evaluation of r\mathbf r is a complete solve of the model per data point; the derivative A=∂r/∂p\mathbf A=\partial\mathbf r/\partial\mathbf p is, row by row, the sensitivity from above divided by σ\sigma. The step after Levenberg and Marquardt solves

(ATA+λdiag⁡(ATA))δ=−ATr;\big(\mathbf A^{\mathsf T}\mathbf A+\lambda\,\mathrm{diag}(\mathbf A^{\mathsf T}\mathbf A)\big)\,\delta=-\mathbf A^{\mathsf T}\mathbf r ;

if χ2\chi^2 falls, the step is accepted and λ\lambda divided by ten, otherwise rejected and λ\lambda multiplied by ten. Small λ\lambda is Gauss-Newton, large λ\lambda a short gradient step. At the end

Cp=(ATA)−1\mathbf C_p=(\mathbf A^{\mathsf T}\mathbf A)^{-1}

is the covariance of the parameters, provided the σ\sigma are the true measurement uncertainties. If they are only weights, the uncertainty is taken from the scatter and scaled by χ2/(N−m)\chi^2/(N-m) (NN measured values, mm parameters). For a linear model y=Ku+Cy=Ku+C this is exactly the weighted regression line from the normal equations; the probe compares against it in closed form.

Settings in the framework: start value λ=10−3\lambda=10^{-3}, at most 60 steps, stop at a relative parameter step below 10−1010^{-10} or χ2=0\chi^2=0, give up at λ>1016\lambda>10^{16}. A data point whose model does not converge invalidates the step (treated like a rise of χ2\chi^2). At the end the fitted parameters are set in the interface and the settings of the data points are back at their model values.

Pseudocode

// sensitivity at the solution x*
J_x ← ∂F/∂x(x*),  J_p ← ∂F/∂p(x*)          // symbolic, the same derivatives as the solver
LU ← factorise(J_x);  if singular: error
for each parameter j:  S[:, j] ← LU.solve(−J_p[:, j])

// Monte Carlo
for k = 1 … N:
    u ← Sobol(k + seed);  p ← p̄ + σ · Φ⁻¹(u)
    solve F(x, p) = 0 from the mean;  if converged: collect x
set p ← p̄;  mean, covariance (with N − 1)

// Levenberg-Marquardt over data points
r, A ← for each point: solve, r = (x − y)/σ,  A = S/σ
while not done:
    solve (AᵀA + λ diag AᵀA) δ = −Aᵀr;  p' ← p + δ
    if χ²(p') < χ²(p):  p ← p',  λ ← λ/10   else  λ ← 10 λ
C_p ← (AᵀA)⁻¹

How it is tested

Empfindlichkeitsprobe (9 checks): the linear system with all derivatives ±12\pm\tfrac12, X2=A,Y=XBX^2=A,\;Y=XB with ∂X/∂A=1/(2A)\partial X/\partial A=1/(2\sqrt A), the implicit X3+AX=10X^3+AX=10 with −X/(3X2+A)-X/(3X^2+A) and additionally against the central difference quotient from two new solutions, rejection of free, unknown and duplicate parameters, the reported singularity, the command line. Unsicherheitsprobe (8): linear propagation with and without correlation in closed form, Monte Carlo against it to 3 % (512 points), same seed same numbers, σX=σA/(2A)\sigma_X=\sigma_A/(2\sqrt A) for X2=AX^2=A. Anpassungsprobe (7): the power law Y=KUNY=KU^N returns K=2.5,N=1.3K=2.5,\;N=1.3, the weighted line with covariance and χ2\chi^2 from the normal equations, an implicit model with two measured quantities per point, the command line with a generated data file. Every equation with evidence has a red counter-test.

Limits

  • Linear propagation is first order. For X2=AX^2=A with σA/A=0.25%\sigma_A/A=0.25\,\% the difference to Monte Carlo is negligible, at 30 % it is not; then use Monte Carlo.
  • Regime changes (conditional equations, MIN/MAX) make x(p)\mathbf x(\mathbf p) only piecewise smooth. The sensitivity then holds for the branch the solution lies in.
  • The Monte Carlo sample is normally distributed without correlation between parameters; correlated inputs only enter through linear propagation.
  • The fit finds a local minimum of χ2\chi^2; the start value decides which. It does not reject as many or fewer measured values than parameters; the covariance is then meaningless (no degrees of freedom).
  • Procedure calls (CALL) enter with the derivatives the solver uses (five-point differences for the property procedures).
