Network blocks and transformer – attention, masks and positions

The computation behind MultiHeadAttention and PositionalEncoding: scaled dot product, splitting into heads by reshaping and permuting, additive masks for causal language models and padded positions, and the sinusoidal positional encoding – with a derivation of the scaling, pseudocode following the source, a worked example, the probes and the limits.

What this is about

A sequence – phonemes, words, tokens – is to be processed so that every position can fetch information from other positions: whether a vowel is stressed depends on the start of the word; whether an intonation rises, on the last character; which word comes next, on the whole sentence so far. A fixed neighbourhood as in a filter is not enough, because the important positions are sometimes near and sometimes far.

Attention solves this with a learned weighting: every position issues a query, every position offers a key, and the better query and key match, the more of that position's value flows in. Which positions match, the network learns by itself.

Scaled dot product

From the input X∈RT×DX \in \mathbb{R}^{T\times D} (TT positions, DD features) three linear maps produce queries, keys and values:

Q=XWq,K=XWk,V=XWv.Q = X W_q,\qquad K = X W_k,\qquad V = X W_v.

The score of position ii for position jj is the dot product of its query with the key, divided by Dh\sqrt{D_h}; softmax over jj turns these into weights that sum to one per row:

S=QKTDh+M,A=softmaxrow⁡(S),ctx⁡=AV.S = \frac{Q K^T}{\sqrt{D_h}} + M, \qquad A = \mathrm{softmax}_{\text{row}}(S), \qquad \mathrm{ctx} = A\,V.

MM is an additive mask (section Masks). Why the scaling: if the entries of qq and kk have mean 0 and variance 1 and are independent, then

Var⁡(q⋅k)=∑d=1DhVar⁡(qd)Var⁡(kd)=Dh.\mathrm{Var}(q\cdot k) = \sum_{d=1}^{D_h} \mathrm{Var}(q_d)\,\mathrm{Var}(k_d) = D_h.

Without scaling the spread of the scores would grow with the head width; softmax would saturate – one weight near one, all others near zero –, and the gradients y(g−∑gy)y(g - \sum g\,y) would become vanishingly small. Dividing by Dh\sqrt{D_h} brings the spread back to 1.

Several heads

A single set of weights can only represent one kind of relation. Therefore the width DD is split into HH heads of Dh=D/HD_h = D/H each; every head computes its own attention, and the results are concatenated again and mixed by a fourth map WoW_o:

MHA⁡(X)=[ctx1⁡,…,ctxH⁡]Wo+bo.\mathrm{MHA}(X) = \big[\mathrm{ctx}_1, \dots, \mathrm{ctx}_H\big]\, W_o + b_o.

The split is implemented without a loop over heads: the projection [T,D][T, D] is reshaped to [T,H,Dh][T, H, D_h] and permuted to [H,T,Dh][H, T, D_h]. The heads are then a batch axis, and the matrix product QKTQK^T computes all heads in one call (form batch times batch, see Matrix product). Afterwards it is permuted back to [T,H,Dh][T, H, D_h] and reshaped to [T,D][T, D].

Pseudocode – MultiHeadAttention.forward(x, mask, rnd, training)

check x has shape [T, D]
split(t) := permute(reshape(t, T, H, Dh), 1, 0, 2)      [T,D] → [H,T,Dh]
q ← split(x·W_q);  k ← split(x·W_k);  v ← split(x·W_v)   without bias
s ← (q · transposeLast(k)) · 1/sqrt(Dh)                 [H,T,T]
if mask ≠ null: s ← s + mask                          [T,T] stretched over H
a ← softmaxLastDim(s)
if training and p > 0: a ← dropout(a, p, rnd)
ctx ← a · v                                             [H,T,Dh]
return reshape(permute(ctx, 1, 0, 2), T, D) · W_o + b_o

Source: envisionz-framework-autograd/src/envisionz/autograd/nn/MultiHeadAttention.java. The constructor throws if DD is not divisible by HH; WqW_q, WkW_k, WvW_v are created without bias, WoW_o with.

Masks

A mask is a matrix M∈RT×TM \in \mathbb{R}^{T\times T} that is added to the scores before softmax: 0 means allowed, a strongly negative value means blocked. After softmax the weight of a blocked position is practically zero. The mask is stretched right-aligned over the head axis; no dedicated operation is needed for that.

MaskEntry MijM_{ij}Purpose
causalMask(T)0 for j≤ij \le i, else −109-10^9language model: position ii sees only itself and earlier ones
paddingMask(valid)0 if position jj is valid, else −109-10^9hide padded positions as keys
causalPaddingMask(valid)0 for j≤ij \le i and jj valid, else −109-10^9both at once – applied separately they would overwrite each other

The causal mask is the precondition for any language model. During training the whole sequence is in memory; without the mask position ii would see token i+1i+1, which it is supposed to predict. The model would appear to learn superbly and fail completely when generating – a fault that only shows at the very end.

Decision in the framework: the blocking value is −109-10^9 and not −∞-\infty. With −∞-\infty the backward path would produce ∞⋅0\infty \cdot 0, i.e. NaN, at blocked positions, and the whole run would be spoiled. e−109e^{-10^9} is exactly 0 in double precision – so the weight still vanishes completely. The padding mask blocks positions as keys (column jj); the rows of padded positions themselves are still computed and must be skipped in the loss (ignoreIndex).

Positional encoding

Attention on its own knows no order: swapping two positions in the input only swaps the corresponding rows in the output (permutation equivariance). "The compressor drives the turbine" and every rearrangement of the same words would look alike. Therefore a positional encoding is added to the embedding of every position, following Vaswani and colleagues with sine and cosine of different wavelengths:

PE⁡(p,2i)=sin⁡(p100002i/d),PE⁡(p,2i+1)=cos⁡(p100002i/d).\mathrm{PE}(p, 2i) = \sin\!\left(\frac{p}{10000^{2i/d}}\right), \qquad \mathrm{PE}(p, 2i+1) = \cos\!\left(\frac{p}{10000^{2i/d}}\right).

The wavelengths range geometrically from 2π2\pi to 10000⋅2π10000\cdot 2\pi. For every fixed distance kk, PE⁡(p+k)\mathrm{PE}(p+k) is a linear function of PE⁡(p)\mathrm{PE}(p) (a rotation per pair), which makes relative positions easily accessible to the network.

Decision in the framework: the encoding has no learnable parameters. It is defined for any length, even for sequences longer than anything seen in training; a learned table would be bound to the training length. The values are computed once up to maxLen and cached; add(x) adds the first TT rows as a constant (without gradient) and throws if TT exceeds maxLen or the width does not match.

Worked example

Causal weights. Row 1 of the figure: softmax⁡(0.5,1,−109)=(e0.5,e1,0)/(e0.5+e1)=(0.377541,0.622459,0)\mathrm{softmax}(0.5,\ 1,\ -10^9) = (e^{0.5}, e^{1}, 0)/(e^{0.5} + e^{1}) = (0.377541,\ 0.622459,\ 0). Row 2: softmax⁡(2,0,1)=(0.665241,0.090031,0.244728)\mathrm{softmax}(2,\ 0,\ 1) = (0.665241,\ 0.090031,\ 0.244728). That is what softmaxLastDim(S + causalMask(3)) returns.

Scaling. With Dh=32D_h = 32 and entries of variance 1 the unscaled dot product has the standard deviation 32=5.66\sqrt{32} = 5.66. Two scores that differ by two standard deviations would give a weight ratio of e11.3≈8⋅104e^{11.3} \approx 8\cdot 10^4 without scaling, and e2≈7.4e^{2} \approx 7.4 with it.

Positional encoding. For d=4d = 4: position 0 is (0,1,0,1)(0,\ 1,\ 0,\ 1), position 1 is (sin⁡1,cos⁡1,sin⁡0.01,cos⁡0.01)=(0.841471,0.540302,0.010000,0.999950)(\sin 1,\ \cos 1,\ \sin 0.01,\ \cos 0.01) = (0.841471,\ 0.540302,\ 0.010000,\ 0.999950), position 2 is (0.909297,−0.416147,0.019999,0.999800)(0.909297,\ -0.416147,\ 0.019999,\ 0.999800). The first pair rotates quickly (wavelength 2π2\pi), the second slowly (wavelength 100⋅2π100\cdot 2\pi).

How it is checked

  • EncoderTest: gradients of attention against central differences; a position blocked as key does not influence the other outputs (deviation below 10−710^{-7}, only the valid rows are compared); without positional encoding the encoder is permutation-equivariant (deviation below 10−910^{-9}, exactly 0 according to the module documentation), with it the order is distinguished (above 10−310^{-3}) – only both checks together show that the encoding has an effect; the attention weights sum to 1 per row (below 10−1210^{-12}); the positional encoding lies in [−1,1][-1, 1] and is deterministic.
  • LanguageModelTest: the causal mask is lower triangular; a later token does not influence the output at earlier positions (below 10−910^{-9}), while the last position does change (above 10−310^{-3}); without the mask the future leaks through (above 10−310^{-3}) – the counter-check that the first result is due to the mask; causal and padding blocking work together.

Limits

  • Quadratic cost. Scores and weights are H×T×TH\times T\times T; computing time and memory grow with T2T^2. That is why the tokeniser should keep sequences short (see Byte pair encoding).
  • No batch axis. Input and output are [T,D][T, D], one sequence per call. Batches are formed in the trainer by accumulating gradients (see Sequence training).
  • Fully blocked rows. If all keys are blocked for a query (for example the first position when the first position is invalid in causalPaddingMask), all scores are shifted by 10910^9 and softmax distributes uniformly – over blocked positions. Such rows belong ignored in the loss.
  • Positions up to maxLen. The encoding itself would be defined for any length, the cached table is not; longer sequences are rejected.
