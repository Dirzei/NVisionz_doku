Derivatives of the operations – what each backward function computes

The backward paths of the operations in Ops, derived and written down the way the source computes them: element-wise functions, reshaping, softmax, cross-entropy fused with softmax, LayerNorm and RMSNorm, GELU and SwiGLU, embedding and losses – with pseudocode, worked examples, the probes and the places where a derivative is defined rather than computed.

What this is about

The backward pass (see Reverse mode) is only as good as the derivatives each operation brings along. An operation y=f(x)y = f(x) receives the gradient gy=∂L/∂yg_y = \partial L/\partial y on the way back and must form

gx+=(∂y∂x)Tgyg_x += \left(\frac{\partial y}{\partial x}\right)^{T} g_y

– the vector-Jacobian product – without building the Jacobian. For element-wise functions the Jacobian is diagonal and the product is gy⊙f'(x)g_y \odot f'(x). For softmax, normalisations and losses every output couples to many inputs; there the derivation pays off, because the sum over the Jacobian collapses into one or two dot products per row.

A mistake here does not show up as a crash. A forgotten factor 2 or a wrong sign lets a model keep learning, only worse – which is why each of the 37 public operations is checked against central differences, and many additionally against a hand-derived derivative.

The binary operations mul and div deliver both partial derivatives, summed over the stretched axes for the second operand (see Stretching): for y=aby = a\,b they are gybg_y\,b and gyag_y\,a, for y=a/by = a/b they are gy/bg_y/b and −gya/b2-g_y\,a/b^2.

GELU is implemented in the tanh approximation, the usual form in transformers. With c=2/πc = \sqrt{2/\pi} and u=c(x+0.044715x3)u = c\,(x + 0.044715\,x^3):

gelu⁡(x)=12x(1+tanh⁡u),gelu⁡'(x)=12(1+tanh⁡u)+12x(1−tanh2⁡u)c(1+3⋅0.044715x2).\mathrm{gelu}(x) = \tfrac12\,x\,(1 + \tanh u), \qquad \mathrm{gelu}'(x) = \tfrac12 (1 + \tanh u) + \tfrac12\,x\,(1 - \tanh^2 u)\; c\,(1 + 3\cdot 0.044715\,x^2).

Dropout is the inverted form: during training each element is zeroed with probability pp and the others are scaled by 1/(1−p)1/(1-p). The expected value stays the same, and in evaluation (training = false) the tensor is passed through unchanged – no rescaling needed. The mask is drawn in the forward pass and kept for the backward path; the randomness comes from the Random passed in.

Reshaping

Reshaping operations compute nothing, they reorder. Their backward path is therefore the inverse reordering, and where the forward pass copies, the backward pass sums.

  • reshape: the same values in the same order; the gradient is handed back one to one.
  • permute(perm): result position oo with coordinates cc reads the source ∑icisperm⁡[i]a\sum_i c_i\,s^a_{\mathrm{perm}[i]}. Backwards gy[o]g_y[o] is added to exactly that source. transposeLast is permute with the last two axes swapped.
  • sliceLastDim(a, from, to) and concatLastDim(parts…) are inverse to each other: the slice returns its gradient into columns [from⁡,to⁡)[\mathrm{from}, \mathrm{to}), the concatenation distributes its gradient column-wise to the parts.

Softmax

Softmax over the last axis, per row:

yi=exi−μ∑jexj−μ,μ=maxj⁡xj.y_i = \frac{e^{x_i - \mu}}{\sum_j e^{x_j - \mu}}, \qquad \mu = \max_j x_j.

Subtracting the maximum does not change the result (it cancels) but prevents overflow of exe^{x} for large values. The Jacobian is ∂yi/∂xk=yi(δik−yk)\partial y_i/\partial x_k = y_i(\delta_{ik} - y_k). The vector-Jacobian product becomes

gx,k=∑igy,iyi(δik−yk)=yk(gy,k−∑igy,iyi),g_{x,k} = \sum_i g_{y,i}\,y_i(\delta_{ik} - y_k) = y_k \Big(g_{y,k} - \sum_i g_{y,i}\,y_i\Big),

i.e. one dot product and one element-wise operation per row. That is exactly what the code does.

Cross-entropy fused with softmax

For a language model or a classifier the network delivers raw scores z∈RVz \in \mathbb{R}^V (logits) per row; the target is a class index tt. The loss is the negative log-probability of the correct class under softmax:

ℓ=−ln⁡ezt∑kezk=μ+ln⁡∑kezk−μ⏟logsumexp⁡(z)−zt,μ=maxk⁡zk.\ell = -\ln \frac{e^{z_t}}{\sum_k e^{z_k}} = \underbrace{\mu + \ln \sum_k e^{z_k - \mu}}_{\mathrm{logsumexp}(z)} - z_t, \qquad \mu = \max_k z_k.

The naive route – first p=softmax⁡(z)p = \mathrm{softmax}(z), then −ln⁡pt-\ln p_t – fails for large vocabularies: pkp_k drops below the representable range for many classes, and ln⁡0=−∞\ln 0 = -\infty ends the run. Fused, there is neither overflow nor underflow. The derivative is remarkably simple:

∂ℓ∂zk=ezk∑jezj−δkt=pk−δkt.\frac{\partial \ell}{\partial z_k} = \frac{e^{z_k}}{\sum_j e^{z_j}} - \delta_{kt} = p_k - \delta_{kt}.

crossEntropyLoss(logits, targets, ignoreIndex) averages over the N'N' counted rows; rows whose target is ignoreIndex (padding positions) contribute neither to the loss nor to the gradient, and the denominator is the number of counted rows, not of all rows.

Pseudocode – Ops.crossEntropyLoss(logits, targets, ignoreIndex)

check logits has shape [N, V], |targets| = N
sum ← 0;  counted ← 0
for i ← 0 to N−1:
    t ← targets[i];  if t = ignoreIndex: continue
    check 0 ≤ t < V
    μ ← max_k z[i,k];   s ← Σ_k exp(z[i,k] − μ)
    sum += (μ + ln s) − z[i,t];   counted += 1
if counted = 0: throw "all targets are ignoreIndex"
ℓ ← sum / counted
backward:
    f ← g_ℓ / counted
    for each counted row i:                μ and s are recomputed
        for k:  z.grad[i,k] += f · (exp(z[i,k] − μ)/s − [k = t])

Source: envisionz-framework-autograd/src/envisionz/autograd/Ops.java, method crossEntropyLoss; the short form without the third parameter sets ignoreIndex = -1.

Decision in the framework: cross-entropy expects raw logits of shape [N,V][N, V] – without a preceding softmax – and averages over the counted rows. A call in which all targets are ignored throws instead of returning a loss of 0/0. For an untrained model that guesses uniformly the loss is exactly ln⁡V\ln V; the start check of the language-model trainer builds on that (see Language model).

LayerNorm and RMSNorm

LayerNorm over the last axis of width DD, per row:

μ=1D∑ixi,σ2=1D∑i(xi−μ)2,x^i=xi−μσ2+ε,yi=γix^i+βi.\mu = \frac1D\sum_i x_i,\quad \sigma^2 = \frac1D\sum_i (x_i - \mu)^2,\quad \hat x_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \varepsilon}},\quad y_i = \gamma_i\,\hat x_i + \beta_i.

The variance is divided by DD, not by D−1D-1. For the backward path set g^i=gy,iγi\hat g_i = g_{y,i}\,\gamma_i and r=1/σ2+εr = 1/\sqrt{\sigma^2+\varepsilon}. Each xkx_k acts on x^i\hat x_i along three routes: directly, via μ\mu and via σ2\sigma^2. With ∂x^i/∂xk=r(δik−1D−1Dx^ix^k)\partial \hat x_i/\partial x_k = r\,(\delta_{ik} - \frac1D - \frac1D\,\hat x_i\,\hat x_k) this gives

gx,k=r(g^k−1D∑ig^i−x^k1D∑ig^ix^i),gγ,i=∑rowsgy,ix^i,gβ,i=∑rowsgy,i.g_{x,k} = r\Big(\hat g_k - \frac1D\sum_i \hat g_i - \hat x_k\,\frac1D\sum_i \hat g_i\,\hat x_i\Big),\qquad g_{\gamma,i} = \sum_{\text{rows}} g_{y,i}\,\hat x_i,\qquad g_{\beta,i} = \sum_{\text{rows}} g_{y,i}.

Per row these are two sums – ∑g^\sum \hat g and ∑g^x^\sum \hat g\,\hat x – instead of a D×DD\times D Jacobian. The sum of gxg_x over a row is zero: shifting all xix_i by the same constant does not change x^\hat x.

RMSNorm omits the centring and therefore has only γ\gamma:

r=(1D∑ixi2+ε)−1/2,yi=xirγi,gx,k=rg^k−xkr31D∑ig^ixi.r = \Big(\frac1D\sum_i x_i^2 + \varepsilon\Big)^{-1/2}, \qquad y_i = x_i\,r\,\gamma_i, \qquad g_{x,k} = r\,\hat g_k - x_k\,r^3\,\frac1D\sum_i \hat g_i\,x_i.

One term less on the way back: each output depends on all inputs only through the sum of squares, not additionally through the mean.

Pseudocode – backward path of Ops.layerNorm

// stored in the forward pass: x̂ per element, r = 1/sqrt(σ²+ε) per row
for each row:
    sG ← Σ_i g[i]·γ[i];   sGH ← Σ_i g[i]·γ[i]·x̂[i]
    for i ← 0 to D−1:
        ĝ ← g[i]·γ[i]
        if x.grad ≠ null:  x.grad[i] += (ĝ − sG/D − x̂[i]·sGH/D) · r
        if γ.grad ≠ null:  γ.grad[i] += g[i]·x̂[i]
        if β.grad ≠ null:  β.grad[i] += g[i]

Source: envisionz-framework-autograd/src/envisionz/autograd/Ops.java, methods layerNorm and rmsNorm.

SwiGLU

The feed-forward network of the modern variant (see Encoder) uses a gate instead of a fixed characteristic: one branch decides multiplicatively how much of the other passes,

y=silu⁡(a)⊙b,silu⁡(a)=aσ(a).y = \mathrm{silu}(a) \odot b, \qquad \mathrm{silu}(a) = a\,\sigma(a).

Backwards: ga=gyb(σ(a)+aσ(a)(1−σ(a)))g_a = g_y\,b\,(\sigma(a) + a\,\sigma(a)(1-\sigma(a))) and gb=gysilu⁡(a)g_b = g_y\,\mathrm{silu}(a). Both inputs must have the same shape.

Embedding, sums and losses

  • embedding(W, ids) selects rows from W∈RV×DW \in \mathbb{R}^{V\times D}. Backwards the gradient of each output row is added into row ids[i] of gWg_W – if a symbol occurs several times its contributions sum up. An index outside [0,V)[0, V) throws.
  • sum and mean over all values: backwards every element receives gg or g/ng/n.
  • mseLoss: 1n∑(p−t)2\frac1n\sum (p-t)^2, backwards 2n(p−t)\frac2n (p-t) for the prediction and the negative for the target, if that carries a gradient.
  • l1Loss: 1n∑|p−t|\frac1n\sum |p-t|, backwards 1nsgn⁡(p−t)\frac1n\,\mathrm{sgn}(p-t).

How it is checked

  • AutogradTest: every operation against central differences (tolerance 10−610^{-6}); relu and l1Loss with starting values well away from the kink.
  • Gradientenprobe against derivatives by hand with tolerance 10−1010^{-10}: x2x^2, tanh, sigmoid, exp, log, sqrt, sin, cos, softplus individually; chain rule on sin⁡(x2)\sin(x^2), e−x2e^{-x^2}, tanh⁡(3x+1)\tanh(3x+1), 1+sin2⁡x\sqrt{1+\sin^2 x} and ln⁡σ(x)\ln\sigma(x); softmax as sk(wk−∑ws)s_k(w_k - \sum w\,s); cross-entropy as (p−one-hot)/N(p - \text{one-hot})/N, also with an ignored row and the denominator equal to the counted rows; LayerNorm gradients with respect to β\beta (column sum) and γ\gamma (∑Wx^\sum W\hat x).
  • LanguageModelTest: a uniform distribution gives ln⁡V\ln V to 10−1210^{-12}; a confident correct prediction gives practically 0; logits around ±800\pm 800 and uniformly huge logits stay finite; ignored positions receive exactly no gradient.
  • Normierungsprobe (17 checks) for LayerNorm: definition by hand with variance divided by DD (to 10−1510^{-15}); with ε=0.75\varepsilon = 0.75 the denominator becomes 1.25+0.75=2\sqrt{1.25 + 0.75} = \sqrt 2; a constant row gives 0 and not NaN, but NaN with ε=0\varepsilon = 0; the gradient with respect to xx sums to 0 per row.
  • ModernTest: RMSNorm sets the root mean square to 1 (to 10−910^{-9}) and does not centre; SwiGLU acts as a gate – a gate branch of 0 blocks, a large one opens.

Limits

  • Kinks are defined, not computed. relu passes the gradient 0 at x=0x = 0, l1Loss likewise at p=tp = t (sgn⁡(0)=0\mathrm{sgn}(0) = 0). Central differences are systematically wrong exactly there; the probes avoid these points.
  • No guards. log, sqrt and div do not check their arguments. A denominator that can become zero is a modelling error that a silently caught infinity would only hide; callers keep their distance (for example ε\varepsilon in the logarithm of the spectrum).
  • softplus switches to the identity above x=30x = 30; the difference there is below 10−1310^{-13}. The derivative, in contrast, is always computed as σ(x)\sigma(x).
  • GELU is the tanh approximation, not the exact form with the error function. Whoever takes over weights from a model with exact GELU computes slightly differently.
  • Dropout requires 0≤p<10 \le p \lt 1; for p=0p = 0 or in evaluation the input itself is returned, without a new node.
  • Cross-entropy only for rank 2; sequences with a batch axis must be reshaped first.
