Formula Setting and Drawing – Background

How the viewer sets TeX formulas: atom classes, the spacing table of the TeXbook, fractions and scripts with their dimensions. Also how it splits SVG arcs into curves.

What this is about

A formula such as a+b=ca + b = c looks right only if its characters are not set at equal distances: there is more air around the equals sign than around the plus sign, none after an opening bracket, and less in an exponent than in the line. Knuth put this into a table in the TeXbook; the viewer sets by that table. Formulas appear in the text as \( … \) (text style) or as $$ … $$ (displayed, display style), and the same parser supplies the web with MathML, so that website and help share one reading of the formula.

The path has three stages: the parser turns the TeX text into an atom tree (every atom has a class and possibly a superscript and subscript), the layout engine lays the tree out from the inside out (width, height above the baseline, depth below), the painter draws the glyphs and rules at their places. Every dimension is a multiple of the font size ss in pixels.

The gaps depend only on the classes of the two neighbouring atoms. The viewer knows eight classes, as the TeXbook does:

The spacing table

The gap between left and right neighbour is given in units μ\mu (math units), with 1μ=118em1\,\mu = \tfrac{1}{18}\,\text{em}. There are three steps: thin 3μ3\,\mu, medium 4μ4\,\mu, thick 5μ5\,\mu. The gap in pixels is Δx=μ18⋅s\Delta x = \dfrac{\mu}{18} \cdot s.

In the script styles (subscript and superscript, second-order script) all fields that stand in brackets there drop out, the thin ones too; only the five thin gaps before an operator without brackets remain: from Ord, Op, Close and Inner before Op, and from Op before Ord.

A fraction with a numerator of total height HNH_N and a denominator of total height HDH_D (height plus depth) has the width max⁡(WN,WD)+2⋅0.15s\max(W_N, W_D) + 2 \cdot 0.15\,s, and above and below the baseline respectively:

height=a+t2+g+HN,depth=−a+t2+g+HD\text{height} = a + \frac{t}{2} + g + H_N, \qquad \text{depth} = -a + \frac{t}{2} + g + H_D

The rule lies on the axis, aa above the baseline; numerator and denominator are centred on the rule. Superscript and subscript stand to the right of the base, shifted by 0.02s0.02\,s (after a visible bracket by 0.14s0.14\,s). If both are present and too close, they move apart by half the difference each until the gap reaches 0.10s0.10\,s. For a base with a large bracket the shifts follow the top and bottom of the bracket.

A worked example for the table: for a+b=ca + b = c in text style with s=18s = 18 pixels the gaps are 418⋅18=4\tfrac{4}{18}\cdot 18 = 4, 44, 518⋅18=5\tfrac{5}{18}\cdot 18 = 5 and 55 pixels, 18 in all, exactly one em. Set as an exponent, all four gaps are zero.

SVG arcs: curves from ellipses

The same painter draws the SVG parts of the website. Paths read all commands of SVG 1.1 (M L H V C S Q T A Z, upper and lower case, with repetition and numbers without separators). The arc command A is the only one that must first be converted: it gives two end points, the radii rx,ryr_x, r_y, a rotation φ\varphi and two flags, not the centre. The viewer converts to the centre form according to SVG 1.1, appendix F.6.5.

  1. Radii that are too small are enlarged (F.6.6): with Λ=x1'2rx2+y1'2ry2\Lambda = \dfrac{x_1'^2}{r_x^2} + \dfrac{y_1'^2}{r_y^2} and Λ>1\Lambda > 1 both radii are multiplied by Λ\sqrt{\Lambda}. Radius 0 gives a line segment, equal end points give no arc.
  2. From the end points follow the centre, and from the angles θ1\theta_1 (start) and Δθ\Delta\theta (sweep), depending on the flags with Δθ\Delta\theta in [0,2π][0, 2\pi] or [−2π,0][-2\pi, 0].
  3. The sweep is divided into n=⌈|Δθ|/90∘⌉n = \lceil |\Delta\theta| / 90^\circ \rceil equal pieces, each with δ=Δθ/n\delta = \Delta\theta / n.
  4. Each piece becomes a cubic curve with control points at the distance τ=43tan⁡δ4\tau = \tfrac{4}{3}\tan\tfrac{\delta}{4} on the tangent of the unit circle; the points are stretched onto the ellipse, rotated and shifted. For a quarter circle τ=43tan⁡22.5∘≈0.5523\tau = \tfrac{4}{3}\tan 22.5^\circ \approx 0.5523.

The deviation of the curves from the true arc is below 3⋅10−43\cdot 10^{-4} of the radius, according to the class header comment. The remaining features of SVG drawing (transform, use, tspan, opacity, gradients, patterns, markers, filters, masks, clipping) implement the descriptions of the standard; worth mentioning are only the opacity of a group, which is laid over as a whole through an intermediate image (SVG 1.1, 14.5), and the mask, whose luminance is computed from the sRGB values, as in the browser.

Pseudocode

function setRow(atoms, style, s):
    parts ← [ layout(a, style, s) for a in atoms ]
    H ← max height of parts;  D ← max depth of parts;  x ← 0;  before ← none
    for i = 0 to count(parts) - 1:
        if before ≠ none:
            x ← x + gap(before, atoms[i].class, style) · s      // in pixels
        put parts[i] at x so that its baseline lies at H
        x ← x + parts[i].width;  before ← atoms[i].class
    return Part(width = x, height = H, depth = D)

function gap(left, right, style):                // in em
    mu ← table[left][right]                         // 0, 3, 4 or 5
    if style is SCRIPT or SCRIPTSCRIPT and mu > 0 and field bracketed:
        mu ← 0
    return mu / 18

function setFraction(n, d, style, s):
    display ← (style = DISPLAY)
    inner ← display ? TEXT : style.fraction()
    g ← display ? 0.10 : 0.04;  a ← 0.25 · s;  t ← 0.048 · s
    num ← layout(n, inner, display ? s : 0.9 · s)
    den ← layout(d, inner, display ? s : 0.9 · s)
    width ← max(num.width, den.width) + 2 · 0.15 · s
    height ← a + t / 2 + g · s + num.totalHeight
    depth ← -a + t / 2 + g · s + den.totalHeight
    ruleY ← height - a                              // measured from the top
    centre num and den above and below the rule
    return Part(width, height, depth)

function scripts(base, sub, sup, style, s):
    sup' ← layout(sup, style.sub(), 0.75 · s);  sub' ← layout(sub, style.sub(), 0.75 · s)
    u ← 0.42 · s;  d ← 0.20 · s
    if both present and (sup'.depth - u) + 0.10 · s > d - sub'.height:
        push ← ((-u + sup'.depth) + 0.10 · s - (d - sub'.height)) / 2
        u ← u + push;  d ← d + push
    put both at x = base.width + 0.02 · s
    return Part(width = base.width + 0.02 · s + max(script widths), …)

function arc(p1, rx, ry, phi, large, positive, p2):
    if p1 = p2: return nothing
    if rx = 0 or ry = 0: line to p2;  return nothing
    Λ ← x1'² / rx² + y1'² / ry²;  if Λ > 1: rx, ry ← rx · √Λ, ry · √Λ
    compute centre, θ1 and Δθ per F.6.5; Δθ on [0, 2π] or [-2π, 0] by positive
    n ← ceil(|Δθ| / (π / 2));  δ ← Δθ / n;  τ ← 4/3 · tan(δ / 4)
    for k = 0 to n - 1:
        c1 ← point(θ) + τ · tangent(θ);  c2 ← point(θ + δ) - τ · tangent(θ + δ)
        cubicCurve(c1, c2, k = n - 1 ? p2 : point(θ + δ));  θ ← θ + δ

Source: envisionz.viewer.math.MathLayout (layoutRow, recomputeFraction, attachScripts), .Spacing, .MathConstants, .TexSymbols, .Atom and envisionz.viewer.svg.Pfad.bogen.

Decision in the framework: the table is that of the TeXbook, page 170; in the script styles all bracketed fields drop out, the thin ones too (after TeXbook p. 170). After punctuation there is always a thin gap, also before a closing bracket. A minus is set as U+2212, the atom tree keeps -. The decimal comma {,} is an ordinary character. Arcs are split into pieces of at most 90 degrees and drawn as cubic curves; the last piece ends exactly on the end point.

How it is checked

math.Abstandsprobe (44 checks) holds the table against the TeXbook: every field, the steps (only 0, 3, 4 or 5 μ\mu, tolerance 10−910^{-9}) and the script styles. math.Formelsetzerprobe (24) checks the setting of formulas, math.Mathmlprobe (88) the MathML through the same parser and paint.Mathschriftprobe (16) the formula font. Arcs and paths are checked by svg.Zeichenprobe (60), opacity, gradients, filters and masks by svg.Effektprobe (47), each against the standard and compared with Chromium.

Limits

  • The model of the styles is simplified: there are no cramped variants, and the font steps are the fixed factors of the table.
  • An operator sign at the start of a row or after a relation, an opening bracket or a punctuation mark is not reinterpreted as an ordinary character (rule 5 in the TeXbook); the table applies literally to the class the parser assigns.
  • The root has no index (\sqrt[n]{…}).
  • The curly under-brace (\underbrace) is drawn by the browser only with a math font that can stretch it.
  • For SVG, among others, feTurbulence, feImage, feTile, feMorphology, feComponentTransfer, feConvolveMatrix, lighting filters, textPath with method or spacing, nested svg with its own viewBox and animation are missing.
