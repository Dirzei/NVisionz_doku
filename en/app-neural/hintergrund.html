Training in the background – Background

What happens between the “Train” button and the finished surrogate model: which work runs on which thread, how the loss curve follows during training, how ensemble and quantile band come about and how the result reaches the evaluation and other apps. The methods themselves are described in framework-neural.

What it is about

A training run takes seconds to hours. During that time the interface must stay usable, show the curve and accept a stop. The app therefore separates strictly: reading settings and showing results on the event thread, all computing in a background thread.

The path of a training run

The button reads the settings on the event thread and checks them; if data are missing, it ends with a message in the status line. Otherwise a background task starts. It fits the normalisation to the raw data (for classification only the inputs; the targets stay one-hot), splits into training and validation and then trains one net of its own per quantile and per ensemble member, each member with a different seed. With quantile regression these are the quantiles 0.1, 0.5 and 0.9; the median model is delivered, the other two span the prediction band.

During the run the trainer reports its epochs (how often is stated under Limits). Only the first median run feeds the loss curve; the report goes through the background task to the event thread, where the curve gets its point. When the task is done, the event thread takes over the model: it hands it to the evaluation and publishes a copy as an event so that other apps can pick it up.

Stop and close

The stop button sets a flag that the trainer checks after every epoch; a running epoch is computed to its end. What has been learnt by then is taken over like a finished run, with a note that it was stopped. If one stops before the first median run is finished, there is no model; the status line then reports the abort, and nothing is taken over. If the app is closed while a training runs, it cancels the task; then, too, no model is taken over.

Limits

  • The runs of an ensemble and of the quantiles run one after another in the same background thread, not at the same time.
  • The loss curve shows only the first median run; the other runs appear as a counter in the status line.
  • The curve is limited to about 200 points: every max⁡(1,⌊E/200⌋)\max(1, \lfloor E/200 \rfloor)-th epoch is reported for EE epochs.
