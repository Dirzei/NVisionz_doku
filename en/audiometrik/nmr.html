Noise-to-mask ratio (NMR) – background

The computation behind Masse.nmrDb: how the error is set against the masking threshold of the reference per frame and Bark band, how mean and peak are formed from it, pseudocode following the source, two worked examples showing what the number is good for and what not, and the state of testing.

What this is about

SNR and segmental SNR ask how large the error is. For a lossy encoder that is the wrong question: it is not supposed to make the error as small as possible but as inaudible as possible – and for that it may well let the error grow in some frequency ranges if it is masked by the signal there. The noise-to-mask ratio (NMR) measures exactly this: for each frequency band it relates the energy of the error to the masking threshold that the reference produces at that point.

  • NMR below 0 dB: on average the error lies below the threshold – inaudible according to the model.
  • NMR above 0 dB: the error rises above the threshold.

The model behind it is deliberately coarse (fixed offset, no tonality, no threshold in quiet). The NMR of this module is therefore suitable for comparing two methods on the same material, not as an absolute statement about audibility. The module documentation says so explicitly, “so that nobody later takes the NMR value for more than it is”.

Definition

The signal is split into frames of length RR with hop HH (default 1024 and 512). For each frame mm that is not silent:

  1. Reference and error e=b−pe = b - p are weighted with the same Hann window ww.
  2. From both the power spectrum is formed and summed to Bark band energies: EjbE^b_j for the reference, EjeE^e_j for the error, j=0,…,B−1j = 0, \dots, B-1.
  3. From EbE^b the masking threshold TjT_j is formed with spreading and offset ΔdB\Delta_{\text{dB}}.
  4. The ratio per band is averaged linearly over the bands and then converted to dB:

NMRm⁡=10log10⁡(1B∑j=0B−1Eje+εTj+ε),ε=10−20\mathrm{NMR}_m = 10 \log_{10}\left(\frac{1}{B} \sum_{j=0}^{B-1} \frac{E^e_j + \varepsilon}{T_j + \varepsilon}\right), \qquad \varepsilon = 10^{-20}

Over all evaluated frames m∈Mm \in M (and all channels) nmrDb returns two numbers:

NMRmean⁡=1|M|∑m∈MNMRm⁡,NMRpeak⁡=maxm∈M⁡NMRm⁡\mathrm{NMR}_{\text{mean}} = \frac{1}{|M|}\sum_{m \in M} \mathrm{NMR}_m, \qquad \mathrm{NMR}_{\text{peak}} = \max_{m \in M} \mathrm{NMR}_m

The average over the bands is linear, the one over the frames, in contrast, is in dB. Linear averaging over the bands means: the worst band determines the frame. A single band 30 dB above the threshold raises the frame value with 25 bands to at least 30−10log10⁡25=1630 - 10\log_{10} 25 = 16 dB, even if all others lie far below. This is intended – an audible error in one band is audible – but it makes the number sensitive to bands in which the threshold lies unrealistically low (see below).

Silent frames

A frame does not count if the mean power of the unwindowed reference lies more than 40 dB below the square of the peak value of the whole reference – the same rule as for the segmental SNR. In silence there is no masking, the threshold would be almost zero and the NMR arbitrarily large.

Pseudocode – Masse.nmrDb(bezug, pruef, rahmen, vorschub, abzugDb)

w ← Fenster.hann(frame)
scale ← Barkskala(frame/2 + 1, sampleRate)
silence ← peak(ref)² · 10^(−40/10)
sum ← 0;  peak ← −∞;  counted ← 0
for each channel c:
    n ← min(length b, length p)
    for start ← 0, hop, … while start + frame ≤ n:
        if (Σ b[c][i]²) / frame < silence: continue     unwindowed
        gb ← anwenden(b[c], start, w)
        ge[i] ← (b[c][start+i] − p[c][start+i]) · w[i]
        Eb ← scale.bandenergien(leistungsspektrum(gb))
        Ee ← scale.bandenergien(leistungsspektrum(ge))
        T  ← scale.verdeckungsschwelle(Eb, offsetDb)
        v  ← Σ_j (Ee[j] + 10⁻²⁰) / (T[j] + 10⁻²⁰)
        value ← 10 · log10(v / bandCount)
        sum ← sum + value;  peak ← max(peak, value);  counted ← counted + 1
if counted = 0: return (NaN, NaN)
return (sum / counted, peak)

Source: envisionz-framework-audiometrik/src/envisionz/audiometrik/Masse.java. The band partition is formed once per call from the frame length and the sample rate of the reference; the threshold anew for each frame.

Convention in the framework: the measurement chain calls the NMR with frame 1024, hop 512 and an offset of 10 dB (nmrAbzugDb, on the command line -abzug:). It outputs two values, “NMR Mittel” (mean) with the remark “negativ = unter der Schwelle” (negative = below the threshold) and “NMR Spitze” (peak), both with “small is better”. The error is formed in the time domain and then windowed – not as the difference of two spectra. A pure phase error therefore enters the NMR as well.

Worked examples

Noise as reference, noise as error

Reference: uniformly distributed noise of amplitude 0.5, 1 s at 48 kHz. Error: independent uniformly distributed noise of smaller amplitude. Both spectra are flat, every band is occupied. Computed with Masse, measurement-chain defaults:

Error amplitudeSNRNMR meanNMR peakSNR + NMR mean
0.0519.97 dB−11.08 dB−7.18 dB8.89 dB
0.00539.97 dB−31.08 dB−27.18 dB8.89 dB
0.000559.97 dB−51.08 dB−47.18 dB8.89 dB

Here the NMR behaves as one would expect: it follows the SNR with opposite sign and a fixed distance. The distance of 8.89 dB is made up of the offset of 10 dB and the gain from spreading – neighbouring bands raise the threshold by about 1 dB for broadband material. Already at 20 dB SNR white noise lies below the threshold of a white noise.

A four-note chord as reference

Reference: four tones (440, 554.37, 659.25, 880 Hz, amplitude 0.2 each), nothing else. Error as above:

Error amplitudeSNRNMR meanNMR peak
0.113.79 dB121.71 dB133.70 dB
0.0133.79 dB101.71 dB113.70 dB
0.00153.79 dB81.71 dB93.70 dB
0.000173.79 dB61.71 dB73.70 dB

Here too the NMR falls by 20 dB per tenfold reduction of the error amplitude, but it lies about 100 dB higher than with the noise reference – for an error 54 dB below the signal it reports 82 dB above the threshold. Why is shown by a single frame:

The tones lie in bands 3 to 7. There the threshold is high, and the error stays 56 to 71 dB below it. Upwards the threshold falls with the spreading by about 9 to 10 dB per Bark – down to −114 dB in band 24 –, while the error noise stays equally high everywhere. In bands 15 to 24 the error lies above the threshold, in band 24 by 97.6 dB. Because of the linear averaging this one band almost alone determines the frame: 97.6−10log10⁡25=83.697.6 - 10\log_{10} 25 = 83.6 dB, the frame has 84.1 dB.

According to the model this is consistent – above 15 Bark there is nothing in the reference that could mask. A listener would still not necessarily hear the error there, because it may lie below the threshold in quiet. The model lacks it. Hence: the NMR ranks two encoders on the same material correctly (less noise gives a smaller value), but its absolute height depends strongly on the material and says little about audibility.

An error-free test signal

If the test signal is identical after alignment, Eje=0E^e_j = 0 and each ratio is ε/(Tj+ε)\varepsilon / (T_j + \varepsilon). For the chord, delayed by 500 values and aligned by the measurement chain, this gives NMR mean −100.97 dB and peak −89.36 dB – values expressing nothing but ε\varepsilon against the threshold. An error-free path shows in the measure “Bitgenau” (bit-exact), not in the NMR.

How it is tested

For the NMR there is no anchor of its own in the module's probes. It is covered only indirectly: Masseprobe checks that the measurement chain delivers a complete, named series of values (at least seven values), and Barkprobe checks band partition and threshold for consistency (see Hearing model). An anchor computable in closed form could be built from the noise case above, where SNR and NMR are a fixed amount apart; it is not in the source.

Limits

  • No threshold in quiet. In bands that are empty in the reference, the threshold falls to the tails of the spreading and becomes unrealistically low. Every broadband error ends up far above the threshold there. Tonal or band-limited material therefore gets very high NMR values (example above: +82 dB at 54 dB SNR).
  • Linear averaging over the bands. The worst band determines the frame value. Together with the missing threshold in quiet this means: often the top band decides.
  • Fixed offset, no tonality. Noise and tone maskers are treated the same; an encoder that hides noise under a tone is rated too favourably.
  • No temporal masking. The threshold of a frame depends only on that frame. A pre-echo lying within a frame of 1024 values (21 ms at 48 kHz) before a transient counts as masked by the energy of the whole frame.
  • Channels separately. Each channel is computed on its own and weighted equally; binaural effects are missing.
  • Dependence on frame length. The band partition depends on the frame length (see Hearing model). Values with different frame lengths are not comparable.
  • No substitute for listening tests. According to the module documentation a refined psychoacoustic model replaces this basic model in stage 5, when the distortion measure enters the encoder's objective function.
