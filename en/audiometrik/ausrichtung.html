Alignment – offset, valid range and level

The computation behind Ausrichtung: how the time offset of a test signal is found via the cross-correlation, which range may still be measured afterwards, how the level factor is obtained by least squares. With pseudocode following the source, worked examples, the probes and the cases in which the estimate goes wrong.

What this is about

Every encoder brings its own delay: block transforms need a lead-in, filters a settling time, some decoders prepend silence. The decoded version is then correct in content but shifted against the original by a few hundred or thousand samples. All time-domain measures compare value by value – and a single sample of offset already turns an error-free signal into one that appears completely wrong.

How drastic this is shows a generated example: a four-note chord (440, 554.37, 659.25 and 880 Hz, amplitude 0.2 each) over one second at 48 kHz, plus uniformly distributed noise of amplitude 0.01, delayed by 500 samples. Computed with the measurement chain:

without alignmentwith alignment
offset found–500 samples (10.417 ms)
SNR−2.47 dB33.79 dB
largest deviation1.01490.0100

The expected SNR for this case is known in closed form: signal power 4⋅0.22/2=0.084 \cdot 0.2^2/2 = 0.08, noise power 0.012/30.01^2/3, together 10log10⁡(0.08⋅3/10−4)=33.8010\log_{10}(0.08 \cdot 3 / 10^{-4}) = 33.80 dB. Only after alignment does the measure measure what it is supposed to.

Estimating the offset

Suppose the test signal is the shifted reference, pn=bn−vp_n = b_{n-v}, plus some error. The cross-correlation

rk=∑npn+kbn=∑nbn+k−vbnr_k = \sum_{n} p_{n+k}\, b_n = \sum_n b_{n+k-v}\, b_n

is then the autocorrelation of the reference, shifted by vv. An autocorrelation is largest at shift zero – by the Cauchy-Schwarz inequality ∑bn+jbn≤∑bn2\sum b_{n+j} b_n \le \sum b_n^2. So the maximum of rkr_k lies at k=vk = v. As long as the error is small compared with the signal, this remains so. If the test signal is inverted, pn=−bn−vp_n = -b_{n-v}, the sign flips: there is then a deep minimum at the true offset. The largest |rk||r_k| is therefore sought.

The computation uses Spektren.kreuzkorrelation via the FFT. So that positive and negative shifts do not overlap in the cyclic correlation, the signals are zero-padded to a power of two n≥2(max⁡(Lb,Lp)+vmax⁡+1)n \ge 2\,(\max(L_b, L_p) + v_{\max} + 1). Only the range −vmax⁡≤k≤vmax⁡-v_{\max} \le k \le v_{\max} is searched; a negative kk lies at index n+kn + k in the cyclic correlation.

Pseudocode – Ausrichtung.schaetzeVersatz(bezug, pruef, maxVersatz)

needed ← max(length(ref), length(test)) + maxOffset + 1
n ← next power of two ≥ 2 · needed
r ← Spektren.kreuzkorrelation(test, ref, n)         r[k] = Σ test[i+k]·ref[i]
best ← −∞;  v* ← 0
for v ← −maxOffset to maxOffset:
    index ← ((v mod n) + n) mod n                   negative → upper end
    if |r[index]| > best:  best ← |r[index]|;  v* ← v
return v*                                           positive: test signal lags

Source: envisionz-framework-audiometrik/src/envisionz/audiometrik/Ausrichtung.java. The largest magnitude is sought, so that an inverted test signal is aligned correctly as well; level matching then picks up the sign as a negative factor. With equal magnitudes the offset reached first when running up from −vmax⁡-v_{\max} wins, because only a strictly larger value replaces the candidate.

Shifting and the valid range

richteAus first forms the mono sums of both signals (mean over the channels), estimates a single offset vv from them and then shifts all channels of the test signal by −v-v. Afterwards the test signal is brought to the length of the reference. Shifting drops values at one end and creates zeros at the other. These zeros are not a coding error and must not be measured. With LbL_b and LpL_p for the lengths of reference and test signal:

von=max⁡(0,−v),bis=min⁡(Lb,Lp−v)\text{von} = \max(0, -v), \qquad \text{bis} = \min(L_b,\ L_p - v)

  • v>0v > 0 (test signal lags): nothing is missing at the front, vv values are missing at the end – the valid range is [0,Lp−v)[0, L_p - v).
  • v<0v < 0 (test signal leads): shifting back creates |v||v| zeros at the front – the range starts at |v||v|.
  • If the test signal is shorter than the reference, its length additionally limits the end.

If no value remains (bis≤von\text{bis} \le \text{von}), the code sets bis=min⁡(Lb,von+1)\text{bis} = \min(L_b, \text{von} + 1) so that the excerpt is not empty.

The level factor

Some methods change the level – a normalisation, a different scaling factor in the decoder. A level difference is then not a sound error but would push the SNR down strongly. On request the alignment therefore estimates a factor gg by which the test signal, multiplied, best matches the reference, in the least-squares sense:

ming⁡∑c,i(bc,i−gpc,i)2⇒∂∂g=−2∑c,ipc,i(bc,i−gpc,i)=0⇒g=∑c,ibc,ipc,i∑c,ipc,i2\min_g \sum_{c,i} \left(b_{c,i} - g\, p_{c,i}\right)^2 \quad\Rightarrow\quad \frac{\partial}{\partial g} = -2 \sum_{c,i} p_{c,i}\left(b_{c,i} - g\, p_{c,i}\right) = 0 \quad\Rightarrow\quad g = \frac{\sum_{c,i} b_{c,i}\, p_{c,i}}{\sum_{c,i} p_{c,i}^2}

The sum runs over all channels and only over the valid range – otherwise the inserted zeros would pull the factor down. If the denominator is zero (silent test signal), g=1g = 1 remains. The measurement chain also reports the factor in dB, 20log10⁡|g|20\log_{10}|g|.

Pseudocode – Ausrichtung.richteAus(bezug, pruef, maxVersatz, mitPegel)

check same sample rate and same channel count   otherwise IllegalArgumentException
v ← schaetzeVersatz(alsMono(ref), alsMono(test), maxOffset)
p ← test.verschoben(−v).aufLaenge(length(ref))
von ← (v < 0) ? −v : 0
bis ← min(length(ref), length(test) − v)
if bis < von + 1:  bis ← min(length(ref), von + 1)
g ← 1
if withLevel:
    g ← schaetzeVerstaerkung(ref[von, bis), p[von, bis))
    p ← p · g
return (v, g, p, von, bis)

schaetzeVerstaerkung(b, p):
    z ← Σ_c Σ_i b[c][i]·p[c][i];   q ← Σ_c Σ_i p[c][i]²
    return (q ≤ 0) ? 1 : z / q

Source: envisionz-framework-audiometrik/src/envisionz/audiometrik/Ausrichtung.java. The code contains two branches for v>0v > 0 and v≤0v \le 0 with the same statement; the result is the single formula above.

Convention in the framework: the offset is positive when the test signal lags, and always an integer number of samples. It applies to all channels together. By default the measurement chain searches up to vmax⁡=8192v_{\max} = 8192 samples (about 171 ms at 48 kHz) in both directions, always aligns and does not adjust the level; both can be switched. With different sample rate or channel count there is no guessing; the call fails with an exception.

Worked examples

The probe case

Masseprobe delays 8192 values of uniformly distributed noise (amplitude 0.3) by 137 values and searches up to vmax⁡=1024v_{\max} = 1024:

  • Transform length: needed=8192+1024+1=9217\text{needed} = 8192 + 1024 + 1 = 9217, 2⋅9217=18,4342 \cdot 9217 = 18{,}434, next power of two n=32,768n = 32{,}768.
  • Found: v=137v = 137, exactly.
  • Valid range: [0,8192−137)=[0,8055)[0,\ 8192 - 137) = [0, 8055).
  • SNR without alignment rounded −3 dB, infinite in the valid range after alignment – the shifted signal is identical value for value there.

The measured range of the measurement chain

In the chord example above (48,000 values, v=500v = 500, frame R=1024R = 1024): the valid range is [0,47,500)[0, 47{,}500). The measurement chain removes one frame on both sides and measures in [1024,46,476)[1024,\ 46{,}476) – 45,452 values, just as it reports as “Messbereich”. Why the extra margin: a spectral measure with a frame reaching beyond the edge of the valid range would see the transition to the zeros as an error.

Level

The same chord with noise, but multiplied by 0.5 and without delay, with level matching switched on: the measurement chain reports the factor 1.9990 (6.016 dB) and then an SNR of 33.79 dB – as without the level change. The factor is not exactly 2 because the noise power NN counts in the denominator: for uncorrelated noise g=2S/(S+N)g = 2S/(S+N), at 33.8 dB about 1.9992; the rest of the deviation comes from the random correlation between noise and signal. In the probe case without noise (factor 0.75), 1/0.75=1.33331/0.75 = 1.3333 is hit to 10−910^{-9}.

Effort

The correlation runs over the whole signals in a single FFT. Spektren.kreuzkorrelation allocates four double arrays of length nn for this. For one second at 48 kHz and vmax⁡=8192v_{\max} = 8192, n=131,072n = 131{,}072 – negligible. For ten minutes (28.8 million values) n=226=67,108,864n = 2^{26} = 67{,}108{,}864, and the four arrays together occupy 2 GiB. For long recordings this is the limiting factor, not the computing time.

How it is tested

All anchors can be computed in closed form (Masseprobe, plus one anchor in Fftprobe):

  • A known offset of 137 values is found again exactly (bound 0).
  • After richteAus the valid range is exactly [0,n−137)[0, n - 137).
  • In the valid range the SNR after alignment is infinite.
  • The measurement chain compensates the same offset by itself: SNR above 100 dB (at frame 256).
  • A known level error (factor 0.75) is estimated as 1/0.751/0.75, bound 10−910^{-9}.
  • Randfallprobe: an inverted test signal (noise, delayed by 37 values, multiplied by −1) is found with the correct offset 37, and level matching returns the factor −1 (bound 10−910^{-9}).
  • Fftprobe: the autocorrelation of a noise signal has its maximum at offset 0.

Limits

  • Whole samples only. An offset of half a sample (for instance after a sample-rate conversion) remains as an error and mainly lowers the high frequencies.
  • One offset for everything. Drifting delay (two clocks slowly running apart) or an offset changing in the middle is not captured.
  • Mono sum. If the channels cancel (left = −right), the mono sum is zero and the correlation is zero everywhere. Then the first candidate, −vmax⁡-v_{\max}, wins: such a noise signal, delayed by 200 values, is “aligned” with v=−8192v = -8192 (recomputed).
  • Periodic signals. With a strictly periodic signal the correlation has secondary maxima one period apart that are almost as high as the main maximum; then the error decides which one wins.
  • Search range. An offset beyond vmax⁡v_{\max} is not found; the best value inside the range is reported, without a warning.
  • Memory. See above: several gigabytes for long recordings.
