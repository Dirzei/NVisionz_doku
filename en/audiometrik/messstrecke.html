Measurement chain and report – procedure, measured range, bit rate and CSV

How Messstrecke.vergleiche combines alignment, trimming and the six measures into one call, what comes out in which order, how bit rate and compression ratio are computed and how Bericht builds a CSV for rate-distortion curves from it line by line. With pseudocode following the source, a complete measurement run as an example, the probes and the limits.

What this is about

An encoder is not judged at a single point but on a curve: how good is the result at 64, 96, 128, 192 kbit/s? This rate-distortion curve – data rate against distortion – arises from many single measurements, each a pair of original and decoded version. The measurement chain turns such a pair into a complete series of values in one call, and the report appends it as a line to a CSV file. Several calls thus produce the curve point by point.

The measurement chain deliberately lives in a framework module and not in the command-line tool: according to the module documentation, in stage 5 the same distortion measure is to enter the objective function of the encoder, which then decides by itself where to save bits.

Convention in the framework: rahmenlaenge always resets the hop to half the frame length. Anyone wanting a different hop must call vorschub afterwards: rahmenlaenge(2048).vorschub(256) gives hop 256, vorschub(256).rahmenlaenge(2048) gives 1024. The procedure of vergleiche

With alignment switched on, the signals are first aligned. The valid range [gV,gB)[\text{gV}, \text{gB}) is then reduced by one frame RR on both sides:

von=min⁡(gV+R,Lb−1),bis=max⁡(gB−R,von+1)\text{von} = \min(\text{gV} + R,\ L_b - 1), \qquad \text{bis} = \max(\text{gB} - R,\ \text{von} + 1)

The reason: a frame extending beyond the edge of the valid range would see the transition to the inserted zeros as an error. With alignment switched off, the test signal is only brought to the length of the reference, and the whole length is measured. Both signals are trimmed to [von,bis)[\text{von}, \text{bis}), then the measures run.

Pseudocode – Messstrecke.vergleiche(bezug, pruef)

v ← 0;  g ← 1;  von ← 0;  bis ← length(ref)
if align:
    a ← Ausrichtung.richteAus(ref, test, maxOffset, levelMatching)
    p ← a.ausgerichtet();  v ← a.versatz();  g ← a.verstaerkung()
    von ← min(a.gueltigVon() + R, length(ref) − 1)
    bis ← max(a.gueltigBis() − R, von + 1)
else:
    p ← test.aufLaenge(length(ref))
B ← ref[von, bis);  P ← p[von, bis)
output: Versatz v                    (remark: v in ms)
        Messbereich bis − von         (remark: “von … bis … von L”)
        if levelMatching: Pegelfaktor g   (remark: 20·log10|g| dB)
        Bitgenau = istBitgenau(B, P, 10⁻⁹) ? 1 : 0
        largest deviation, SNR, segmental SNR(R), spectral distance(R, H)
        (NMR mean, NMR peak) = nmrDb(B, P, R, H, offset)

Source: envisionz-framework-audiometrik/src/envisionz/audiometrik/Messstrecke.java.

The measured values

Each value is a Messwert with name, number, unit, sense of direction and an optional remark. The sense of direction is not a detail: in a series of signal-to-noise ratios and distance measures it tells which number should be large and which small. alsZeile() formats a measured value for the command line in fixed columns: name left-aligned in 28 characters, number right-aligned with four decimals, unit in 8 characters, followed by the remark. NaN appears as “n.v.”, infinite values as “unendlich” or “-unendlich”.

Bit rate and compression ratio

Two plain computations, both static:

bit rate=8⋅bytest⋅1000kbit/s,q=L⋅C⋅w/8bytes\text{bit rate} = \frac{8 \cdot \text{bytes}}{t \cdot 1000} \ \text{kbit/s}, \qquad q = \frac{L \cdot C \cdot w/8}{\text{bytes}}

with tt the playing time in seconds, LL the length, CC the channel count and ww the word length of the uncompressed PCM. A kilobit is 1000 bits here. Examples: 16,000 bytes for one second give 128 kbit/s (the probe case); 1,000,000 bytes for 60 s give 133.33 kbit/s. One minute of stereo at 44.1 kHz with 16 bit has 2,646,000⋅2⋅2=10,584,0002{,}646{,}000 \cdot 2 \cdot 2 = 10{,}584{,}000 bytes raw size; packed to 1,000,000 bytes, q=10.584q = 10.584. With non-positive duration or non-positive stream size respectively, both return NaN.

The report as CSV

Bericht.ergaenze(datei, kennung, bitrate, werte) appends one line. If the file is missing or empty, a header line is written first:

Kennung;Bitrate_kbps;<name 1>;<name 2>;…
<label>;<bit rate>;<value 1>;<value 2>;…

Pseudocode – Bericht.ergaenze

new ← file missing or size = 0
if new:
    write "Kennung;Bitrate_kbps"
    for each measured value: write ";" + name (";" replaced by ",")
    write line end
write label (";" replaced by ",") + ";" + number(bitRate)
for each measured value: write ";" + number(value)
write line end;  append to the file (UTF-8)

number(x):  NaN → empty;  +∞ → "1e308";  −∞ → "-1e308";  otherwise "%.6f" with point

Source: envisionz-framework-audiometrik/src/envisionz/audiometrik/Bericht.java.

Convention in the framework: the separator is the semicolon, the decimal separator always the point (Locale.ROOT), also on a computer set to German. A semicolon in label or column name becomes a comma so that the column count is right. A missing number becomes an empty cell – not “NaN”, which a spreadsheet reads as text; an infinite value (such as the SNR of a lossless path) becomes ±1e308. The file is never overwritten, only extended.

Worked example: a complete measurement run

Reference: four-note chord (440, 554.37, 659.25, 880 Hz, amplitude 0.2 each), 1 s at 48 kHz. Test signal: the same chord plus uniformly distributed noise of amplitude 0.01, delayed by 500 values. new Messstrecke().vergleiche(bezug, pruef), each line with alsZeile():

  Versatz                            500.0000 Werte     10.417 ms
  Messbereich                      45452.0000 Werte     von 1024 bis 46476 von 48000
  Bitgenau                             0.0000 ja/nein
  Groesste Abweichung                  0.0100
  SNR                                 33.7869 dB
  Segment-SNR                         33.7788 dB
  Spektralabstand                     94.6066 dB
  NMR Mittel                         101.8191 dB        negativ = unter der Schwelle
  NMR Spitze                         113.7034 dB

How to read it: the offset has been found (500 values = 10.417 ms at 48 kHz). Measurement takes place in [1024,46,476)[1024, 46{,}476), i.e. [0,47,500)[0, 47{,}500) minus one frame on each side. The largest deviation corresponds to the noise amplitude. SNR and segmental SNR hit the closed-form value 33.80 dB. Spectral distance and NMR are high because the reference consists almost entirely of empty lines and bands (see The measures and NMR). The same test signal without alignment gives an SNR of −2.47 dB.

If the test signal is instead just the reference delayed by 500 values, without noise, the measurement chain returns Bitgenau 1 with the remark “verlustfrei bestaetigt” and SNR “unendlich”; the CSV contains 1e308 for it.

How it is tested

  • Masseprobe: the measurement chain compensates a known offset of 137 values by itself (SNR above 100 dB at frame 256); it delivers at least seven values, all named; the bit rate from 16,000 bytes and 1 s is 128 kbit/s (bound 10−910^{-9}).
  • Fensterprobe checks the report as a file: header only the first time and unchanged at the top; the values as lauf-1;128.000000;42.500000;-1.250000; no commas as decimal separators; a semicolon in column name and label becomes a comma, header and data line then have the same number of columns; NaN becomes empty, ±∞ becomes ±1e308; an empty file gets a header; without measured values the two fixed columns remain.

Without a probe of their own are kompressionsverhaeltnis, alsZeile and runs of the measurement chain with alignment switched off or level matching switched on.

Limits

  • CSV columns. The header line is created on the first call from its measured values. If level matching is switched between two calls, the new line has one column more or less than the header; the report does not check this, and the values slip into wrong columns.
  • Hop unchecked. vorschub accepts any value. At 0, spectral distance and NMR no longer get out of their frame loop; only the frame length is checked for being a power of two.
  • Short signals. If the signal is hardly longer than two frames plus offset, less than one frame remains after trimming; segmental SNR, spectral distance and NMR then return NaN, “n.v.” in the output, an empty cell in the CSV.
  • Without alignment there is no check for equal sample rate and channel count; a test signal with fewer channels leads to an index-out-of-bounds error.
  • Bit-exact with tolerance 10−910^{-9} does not distinguish deviations of one or two quantisation steps at 32-bit PCM (see The measures).
  • Memory. Both signals are held completely in memory, plus the arrays of the cross-correlation (see Alignment).
