Principles of the module

No dependencies. JDK only; matrices as double[][] or as an operator. The module therefore also runs as a GraalVM native image.
No silent failure. Every result carries konvergiert (converged) and a message with the reason. Error estimates are meant to lie above the true error.
Recomputed quality. Residuals, KKT measures and eigenpair residuals are recomputed independently at the end, not taken from the recursion.
Operator, not matrix class. Krylov and eigen solvers only see y = A x: dense, sparse, stencil or directional derivative all fit.
Verified against references. Closed-form solutions, literature values (QUADPACK, Hock/Schittkowski, Hairer/Wanner) and example collections under envisionz-examples/math.
One place per method. Formerly scattered copies (FFT, splines, LinAlg, Optimize, GSPAR) moved here, proven bit-identical.

Note: the API is German (loese = solve, integriere = integrate, minimiere = minimise, wert = value); names are kept as in the code.

Fourier and cosine transforms envisionz.math

Spectra of signals and images. The kernel comes from the digitizer and is the only FFT in the workspace. Background, formulas and pseudocode →

Fft – complex FFT, radix 2

Fast Fourier transform for powers of two, in place. The inverse transform deliberately does not scale; division by n happens with skaliere where the caller needs it.

API

  • transformiere(re, im, invers)
  • skaliere(re, im) – divides by n
  • naechsteZweierpotenz(n), istZweierpotenz(n)

Used in

audio: MFCC settingsaudiometrik: spectra, cross-correlation audiometrik: alignment, measurement chain

Useful for

Spectral analysis, fast convolution and correlation, frequency filters, time delay between two measured signals.

Example 1 – frequency of a measured signal

int n = 1024;                                 // power of two
double[] re = samples.clone(), im = new double[n];
Fft.transformiere(re, im, false);
int peak = 1;
for (int k = 2; k < n / 2; k++) if (Math.hypot(re[k], im[k]) > Math.hypot(re[peak], im[peak])) peak = k;
double frequency = peak * sampleRate / n;

Example 2 – cross-correlation of two microphones (as in Spektren)

Transform both signals, form X·conj(Y), transform back, skaliere. The position of the maximum is the time delay.

RealFft – FFT of real sequences at half the cost

Packs n real values into n/2 complex ones: one FFT of half length plus post-processing, same result as the complex FFT.

API

  • transformiere(x, re, im)
  • leistung(x, target) – squared magnitudes, target.length ≥ n/2+1

Used in

audio: Mfcc (power spectrum per frame)

Useful for

Audio, vibration measurements, pressure pulsations – wherever the input signal is real.

Example – power spectrum of a frame

double[] p = new double[frame.length / 2 + 1];
RealFft.leistung(frame, p);                 // p[k] = |X[k]|^2, then the mel filter bank

JacobiEquilibrator and ConditionEstimator – scaling and condition

JacobiEquilibrator computes row and column factors (Sinkhorn-Knopp) so that all rows and columns have norm ≈ 1 – essential with mixed units (Pa next to Mach number). ConditionEstimator estimates the condition number in three levels without SVD and classifies it (GOOD … CRITICAL).

API

  • compute(J, n), applyToJacobian(J), applyToRhs(f), unscaleStep(dx)
  • getRowScale(), getColScale()
  • estimateInfNorm(J, n) (fast heuristic), estimateInfNormHager(J, n), estimateFrobenius(J, Jinv, n), estimateDiagRatio(J, n)
  • classify(kappa) → ConditionLevel, isLmRecommended()

Used in

eqnparser: AbstractSolvereqnparser: static/dynamic normalisation (DYNAMIC_NORM) eqnparser: Broyden, LM, Newton-Armijoeqnparser: ModelDiagnostics

Useful for

Robust Newton solvers for engine and cycle models; automatic switch to Levenberg-Marquardt when conditioning is poor.

Example – scaled Newton step

JacobiEquilibrator eq = new JacobiEquilibrator();
eq.compute(j, n); eq.applyToJacobian(j); eq.applyToRhs(f);
double[] dx = eq.unscaleStep(j.solveLinear(f));
var level = ConditionEstimator.classify(ConditionEstimator.estimateInfNorm(j, n));

GSPAR, SparseMatrix, GSPARWorkspace

LU factorisation of sparse matrices in CSR format with pivoting strategy (MIN_FILL, MARKOWITZ, COLUMN, NONE). The structure is analysed once; each Newton iteration only refactorises the values.

API

  • SparseMatrix.buildFromTriplets(n, mp, rows, cols, vals), transferValues
  • GSPAR.allocate(A), factorize(A, ws, pivot, beta, apiv)
  • refactorize(ws, apiv), solve(ws, b) – overwrites b
  • estimateCondition(A, ws)

Used in

eqnparser: GSPARSolver, BroydenGSPARSolver (NEWTON_SPARSE)

Useful for

Large flowsheet equation systems (JT9D: 1184 equations), networks, discretised field problems.

Example – structure once, values each iteration

SparseMatrix a = SparseMatrix.buildFromTriplets(n, n, rows, cols, vals);
GSPARWorkspace ws = GSPAR.allocate(a);
GSPAR.factorize(a, ws, GSPAR.PivotStrategy.MIN_FILL, 0.1, 1e-12);
double[] x = GSPAR.solve(ws, b.clone());      // b is overwritten
Open (GS1): the pseudo-code path (GSPARPseudoCode, solveInPlace) does not compute; the test records the finding. The direct path via solve is verified.

Rodas – stiff and index-1 DAE (RODAS4)

Linearly implicit Rosenbrock method, six stages, coefficients from rodas.f (Hairer/Wanner). Without a Jacobian it is built by differences; the stage systems are solved by GMRES, replaceable via LinearerLoeser.

API

Used in

Useful for

Combustion and reaction kinetics, transient engine models with algebraic equations (mass and energy balances), control loops with fast components.

Example 1 – Robertson chemistry (classic stiff problem)

  dy[1] =  0.04 * y[0] - 1e4 * y[1] * y[2] - 3e7 * y[1] * y[1];
  dy[2] =  3e7 * y[1] * y[1];
};
Verlauf v = Rodas.loese(rob, 0, new double[] {1, 0, 0}, new double[] {40}, Einstellung.standard());

Example 2 – as a DAE

Make the third equation algebraic (y0 + y1 + y2 − 1 = 0) and pass the mass matrix {1, 1, 0}; the test hits the literature value to 1.7e-9.
