Linear, integer and multi-objective optimisation – background

The computation behind Simplex, InnerePunkte, Ganzzahlig, Nsga2 and Pareto: standard form, two-phase simplex with protection against cycling, primal-dual interior points after Mehrotra, branch and bound, non-dominated sorting and crowding distance – with derivations, worked examples, checks and limits.

What it is about

A linear program seeks min⁡cTx\min c^Tx under linear equations and inequalities; if some unknowns are integer, it becomes combinatorial. With several conflicting objectives the result is not one solution but the Pareto front – the set of compromises where no objective can improve without worsening another.

Two-phase simplex

The program is brought into standard form (min⁡cTz\min c^Tz, Az=b≥0Az = b \ge 0, z≥0z \ge 0): shift for lower bounds, reflection, free unknowns as the difference of two positive ones, upper bounds as rows. Phase 1 seeks a feasible vertex with artificial variables (redundant equations drop out), phase 2 optimises. The entering variable is chosen after Dantzig (largest reduced cost); after 20 degenerate steps in a row after Bland (smallest index), which excludes cycling. Shadow prices follow from BTy=cBB^Ty = c_B.

Vertices, reduced costs, ratio test

The feasible set {z≥0:Az=b}\{z \ge 0 : Az = b\} is a polyhedron; if the program is bounded, cTzc^Tz attains its minimum at a vertex. A vertex is a basic solution: mm linearly independent columns BB of AA, zB=B−1b≥0z_B = B^{-1} b \ge 0, all others zN=0z_N = 0. With yy from BTy=cBB^T y = c_B the reduced costs are

dj=cj−ajTy,d_j = c_j - a_j^T y,

the change of the objective when zjz_j is raised from zero by one and the basic variables follow Az=bAz = b. If d≥0d \ge 0, no edge leads downwards – the vertex is optimal, and yy is then also a feasible solution of the dual program max⁡bTy\max b^T y subject to ATy≤cA^T y \le c with bTy=cTzb^T y = c^T z (strong duality). Otherwise some qq with dq<0d_q < 0 enters; how far is decided by the ratio test

θ=mini:(B−1aq)i>0⁡(B−1b)i(B−1aq)i,\theta = \min_{i:\ (B^{-1} a_q)_i > 0} \frac{(B^{-1} b)_i}{(B^{-1} a_q)_i},

and the row attaining the minimum leaves the basis. If no denominator is positive, zqz_q grows without bound: the program is unbounded. In the code B−1B^{-1} never appears explicitly – the tableau B−1[A∣b]B^{-1}[A \mid b] is updated by one pivot per exchange.

Degeneracy and cycling. If some (B−1b)i=0(B^{-1} b)_i = 0, then θ=0\theta = 0: the basis changes, the vertex does not. In unfavourable cases a sequence of such exchanges returns to the initial basis and the method cycles (examples by Beale and Chvátal, both in the probe). Bland's rule (1977) – enter with the smallest index with dj<0d_j < 0, leave with the smallest index on ties – excludes this. Since it is slower, the code switches to it only after 20 degenerate steps.

Worked example (Chvátal): max⁡5x1+4x2+3x3\max 5x_1 + 4x_2 + 3x_3 subject to 2x1+3x2+x3≤52x_1 + 3x_2 + x_3 \le 5, 4x1+x2+2x3≤114x_1 + x_2 + 2x_3 \le 11, 3x1+4x2+2x3≤83x_1 + 4x_2 + 2x_3 \le 8. The optimal basis is {x1,x3,s2}\{x_1, x_3, s_2\} with zB=(2,1,1)z_B = (2, 1, 1), value 13, shadow prices y=(1,0,1)y = (1, 0, 1): bTy=5+8=13b^T y = 5 + 8 = 13. Complementarity is visible – the second row has slack 1 and price 0; x2=0x_2 = 0 and a2Ty=7>4=c2a_2^T y = 7 > 4 = c_2.

What follows. Each iteration is cheap, but the number of vertices can grow exponentially: on the Klee-Minty cube (1972) Dantzig's rule visits 2n2^n vertices. In practice it is usually between mm and 3m3m exchanges – which is why the simplex is the workhorse despite this bound, and why interior points with a polynomial bound exist alongside.

Interior points after Mehrotra

Primal-dual: Newton steps on the KKT conditions with the central path xisi=μx_i s_i = \mu; per step a predictor (μ=0\mu = 0), then corrector and centring with σ=(μaff/μ)3\sigma = (\mu_{aff}/\mu)^3; normal equations with Cholesky; starting point after Mehrotra. Infeasibility and unboundedness are only detected as “limit reached” with a hint – that is what the simplex is for.

The Newton step

The primal min⁡cTx\min c^T x, Ax=bAx = b, x≥0x \ge 0, and the dual max⁡bTy\max b^T y, ATy+s=cA^T y + s = c, s≥0s \ge 0, are jointly optimal when

Ax=b,ATy+s=c,xisi=0,x,s≥0.A x = b, \qquad A^T y + s = c, \qquad x_i s_i = 0, \qquad x, s \ge 0.

Complementarity xisi=0x_i s_i = 0 is combinatorially hard; the central path replaces it by xisi=μx_i s_i = \mu and lets μ→0\mu \to 0. Under feasibility the duality gap is cTx−bTy=xTs=nμc^T x - b^T y = x^T s = n\mu – μ\mu directly measures the distance from the optimum. Linearising with the residuals rp=b−Axr_p = b - Ax, rd=c−ATy−sr_d = c - A^T y - s, rxs=−XSe+σμer_{xs} = -XSe + \sigma\mu e gives the system

AΔx=rp,ATΔy+Δs=rd,SΔx+XΔs=rxs,A\,\Delta x = r_p, \qquad A^T \Delta y + \Delta s = r_d, \qquad S\,\Delta x + X\,\Delta s = r_{xs},

and after eliminating Δs\Delta s and Δx\Delta x, with D=XS−1D = X S^{-1}, a symmetric positive definite system of size mm remains:

ADATΔy=rp−AS−1rxs+ADrd,Δs=rd−ATΔy,Δx=S−1(rxs−XΔs).A D A^T\,\Delta y = r_p - A S^{-1} r_{xs} + A D\, r_d, \qquad \Delta s = r_d - A^T \Delta y, \qquad \Delta x = S^{-1}(r_{xs} - X\,\Delta s).

Predictor and corrector. Mehrotra solves the same system twice with the same Cholesky factorisation: first with σ=0\sigma = 0 (affine step, “where would it go without centring”), giving μaff\mu_{aff}, then with σ=(μaff/μ)3\sigma = (\mu_{aff}/\mu)^3 and the correction term −Δxaff∘Δsaff-\Delta x^{aff} \circ \Delta s^{aff}, which compensates the quadratic error of the linearisation. If the affine step is good, σ\sigma becomes small and the step aggressive. The step lengths keep a distance from the boundary with the factor 0.995. The third power is an empirical rule from Mehrotra (1992), not a derived quantity.

What follows. The number of steps hardly depends on the size (at most 40 in the probe), but each step is a factorisation of ADATA D A^T. Towards the end DD becomes extremely skewed (xi/si→0x_i/s_i \to 0 or ∞\infty) and the normal equations ill-conditioned; the code therefore adds a small regularisation to the diagonal.

Branch and bound

The relaxation (without integrality) gives a bound. If an integer unknown is fractional, branching is on the largest fractional part (xj≤⌊v⌋x_j \le \lfloor v\rfloor and xj≥⌈v⌉x_j \ge \lceil v\rceil), depth first with the nearer branch first; nodes whose bound is not better than the best integer solution are pruned.

Why this is correct. Every integer solution lies in exactly one of the two branches – there is no integer between ⌊v⌋\lfloor v \rfloor and ⌈v⌉\lceil v \rceil – so nothing is lost. And the relaxation is a program with fewer constraints, so for minimisation its optimum is a lower bound of every integer solution in this node. If it is not better than the best known integer solution, the whole subtree cannot contain anything better (Land and Doig 1960).

Example (probe LV4-12): max⁡x+y\max x + y subject to −x+y≤1-x + y \le 1, 3x+2y≤123x + 2y \le 12, 2x+3y≤122x + 3y \le 12. The relaxation sits at the vertex (2.4,2.4)(2.4,\ 2.4) with 4.8; the integer optimum is 4 (e.g. (2,2)(2, 2)) – the gap of 0.8 is typical: the integer optimum does not lie near a rounded relaxation, which here would be infeasible as (2,3)(2, 3) or (3,2)(3, 2).

NSGA-II

Parents and children are sorted together into fronts (fast non-dominated sorting; with constraints after Deb's rule: feasible before infeasible, among infeasible the smaller violation); fronts are filled one by one, the last by crowding distance (distance to the neighbours in each objective). Selection by binary tournament, SBX crossover and polynomial mutation (η=20\eta = 20). Quality measures: hypervolume (2D exact), GD and IGD against a known front.

Dominance. aa dominates bb if fk(a)≤fk(b)f_k(a) \le f_k(b) for all objectives and << for at least one. The first front are the points nobody dominates; remove them, and the non-dominated rest is the second front, and so on. The fast sorting counts for each point by how many it is dominated and records whom it dominates – O(MN2)O(M N^2) for NN points and MM objectives.

Crowding distance. Within a front the points are sorted per objective; the two boundary points get ∞\infty, an inner point the sum of the normalised side lengths of the box spanned by its neighbours:

di=∑k=1Mfk(i+)−fk(i−)fkmax⁡−fkmin⁡.d_i = \sum_{k=1}^{M} \frac{f_k(i^+) - f_k(i^-)}{f_k^{\max} - f_k^{\min}}.

Points with a large distance are preferred – so the front spreads out instead of clustering in one place. Example from the probe: front (1,5)(1, 5), (2,3)(2, 3), (4,1)(4, 1); the middle point has 3/3+4/4=23/3 + 4/4 = 2.

SBX. Simulated binary crossover (Deb and Agrawal 1995) places the children symmetrically around the parents' mean, k1,2=12((y1+y2)∓β(y2−y1))k_{1,2} = \tfrac12\big((y_1 + y_2) \mp \beta\,(y_2 - y_1)\big), with a random spread factor β\beta of density 12(η+1)βη\tfrac12(\eta + 1)\beta^\eta for β≤1\beta \le 1 and 12(η+1)β−(η+2)\tfrac12(\eta + 1)\beta^{-(\eta + 2)} above. A large η\eta keeps the children close to the parents. With bounds the distribution is truncated so that no child lands outside (version of the original code).

Hypervolume. The area the front dominates with respect to a reference point rr; in two objectives, sorted by f1f_1, a sum of rectangles (r1−f1(i))(f2(i−1)−f2(i))(r_1 - f_1^{(i)})(f_2^{(i-1)} - f_2^{(i)}). For the true front of ZDT1, f2=1−f1f_2 = 1 - \sqrt{f_1}, against (1,1)(1, 1) it is ∫01f1df1=2/3\int_0^1 \sqrt{f_1}\,df_1 = 2/3, for ZDT2 (f2=1−f12f_2 = 1 - f_1^2) 1/31/3 – the maxima against which the probe measures.

How it is checked

  • Textbook example after Chvátal (optimum 13, duals (1, 0, 1)) with both methods; Klee-Minty n=8n = 8 with 585^8; cycling examples after Beale and Chvátal; unbounded, infeasible, redundant; 20 random programs with strong duality, interior points = simplex to 1e-8.
  • Interior points on unbounded and infeasible programs: GRENZE with a pointer to the simplex; an artificial variable left in the basis at value 0 after phase 1 and pivoted out (TD3-LP-01, 02).
  • Assignment 7 × 7 equal to the best of 5040 permutations, knapsack equal to the enumeration of 65 536 subsets, mixed-integer equal to enumeration.
  • NSGA-II: ZDT1 hypervolume above 0.655 (optimum 2/3), IGD below 0.01, bitwise repeatable; ZDT2, ZDT3 in all five pieces, CONSTR with kink at 2/3, DTLZ2 on the unit sphere.

Limits

Dense tableau (a few hundred rows); branch and bound without cutting planes; NSGA-II for few objectives (two, three).
