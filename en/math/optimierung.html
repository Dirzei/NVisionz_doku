Optimisation and root finding – L-BFGS, L-BFGS-B and SQP

The computation behind Lbfgs, LbfgsB, Sqp and the package-internal building blocks Liniensuche and QpDual: optimality conditions, Wolfe line search, limited-memory quasi-Newton, bounds via the generalised Cauchy point, sequential quadratic programming with a dual subproblem – with pseudocode following the source, recomputed examples, checks and limits. The derivative-free and one-dimensional methods are on the page Brent, Nelder-Mead, Levenberg-Marquardt.

What this is about

We seek an xx with nn components that minimises a smooth objective f(x)f(x) – the sum of squared deviations of a model from measured points, the fuel consumption of a cycle, the weight of a structure –, possibly subject to constraints:

minx⁡f(x)subjecttohj(x)=0,ci(x)≥0,l≤x≤u.\min_x f(x) \quad \text{subject}\;\text{to} \quad h_j(x) = 0,\quad c_i(x) \ge 0,\quad l \le x \le u.

ClassConstraintsMethodSize
Lbfgsnonelimited-memory quasi-Newton, Wolfe line searchalso many thousands of variables
LbfgsBbounds l≤x≤ul \le x \le uL-BFGS-B: Cauchy point, subspace, line search up to the boundalso many thousands of variables
Sqpequalities, inequalities, boundsSQP after Han and Powell, dual QP, L1 merit function, damped BFGSup to a few hundred variables and constraints

All three need the gradient ∇f\nabla f (and for SQP the gradients of the constraints). A Zielfunktion (objective) returns value and gradient in one call; anyone without a hand-coded gradient uses Zielfunktion.numerisch(f) (central differences, section gradient). All find local minima.

Optimality conditions

Without constraints, ∇f(x*)=0\nabla f(x_*) = 0 at a local minimum. With constraints this no longer holds – the minimum often lies on the boundary, and there the gradient points against the binding constraints. The Karush-Kuhn-Tucker conditions say how: there are multipliers λ\lambda with

∇f(x*)=∑jλj∇hj(x*)+∑iλi∇ci(x*),λi≥0,λici(x*)=0.\nabla f(x_*) = \sum_j \lambda_j \nabla h_j(x_*) + \sum_i \lambda_i \nabla c_i(x_*), \qquad \lambda_i \ge 0, \qquad \lambda_i\, c_i(x_*) = 0.

Each inequality is either inactive (ci>0c_i > 0, then λi=0\lambda_i = 0) or binding (ci=0c_i = 0); the multiplier of a binding constraint is the sensitivity of the optimum: relaxing ci≥0c_i \ge 0 to ci≥−δc_i \ge -\delta lowers f*f_* by about λiδ\lambda_i \delta. That is why the multipliers in the result are more than a by-product – in the example “consumption at a T4 limit” they tell what one more degree of turbine inlet temperature is worth.

The result Optimum carries a measure of how well the conditions are satisfied (kkt): for Lbfgs ‖∇f‖∞\|\nabla f\|_\infty, for LbfgsB the projected gradient ‖P(x−∇f)−x‖∞\|P(x - \nabla f) - x\|_\infty, for Sqp ‖∇f−∑λ∇c‖∞\|\nabla f - \sum \lambda \nabla c\|_\infty, plus the largest constraint violation.

Wolfe line search

All three methods determine a direction dd per iteration and then a step length α\alpha along dd. With ϕ(α)=f(x+αd)\phi(\alpha) = f(x + \alpha d) the strong Wolfe conditions require

ϕ(α)≤ϕ(0)+c1αϕ'(0),|ϕ'(α)|≤c2|ϕ'(0)|,c1=10−4,c2=0.9.\phi(\alpha) \le \phi(0) + c_1\,\alpha\,\phi'(0), \qquad |\phi'(\alpha)| \le c_2\,|\phi'(0)|, \qquad c_1 = 10^{-4},\ c_2 = 0.9.

The first (Armijo) requires sufficient decrease, the second that the slope has become clearly flatter. The second ensures sTy>0s^T y > 0 for s=xnew−xs = x_{\text{new}} - x, y=∇fnew−∇fy = \nabla f_{\text{new}} - \nabla f – the condition under which the BFGS approximation stays positive definite.

The search (Nocedal and Wright, algorithms 3.5 and 3.6) first brackets: the trial α\alpha is quadrupled until an interval surely contains an acceptable point. Then it zooms in: the next trial is the minimum of the cubic interpolant from values and derivatives at both ends, restricted to the inner interval [lo+0.1w,hi−0.1w][lo + 0.1\,w,\ hi - 0.1\,w]; if it falls outside, the midpoint. At most 40 evaluations per search. If no Wolfe point is found, the search takes the best point with sufficient decrease; if there is none, it reports “no decrease”.

L-BFGS

Newton's method takes the direction d=−H∇fd = -H\,\nabla f with the inverse Hessian H=(∇2f)−1H = (\nabla^2 f)^{-1} and converges quadratically, but needs second derivatives and O(n2)O(n^2) memory. Quasi-Newton methods build an approximation of HH from the observed pairs sk=xk+1−xks_k = x_{k+1} - x_k, yk=∇fk+1−∇fky_k = \nabla f_{k+1} - \nabla f_k. BFGS updates

Hk+1=(I−ρkskykT)Hk(I−ρkykskT)+ρkskskT,ρk=1ykTsk.H_{k+1} = \big(I - \rho_k s_k y_k^T\big) H_k \big(I - \rho_k y_k s_k^T\big) + \rho_k s_k s_k^T, \qquad \rho_k = \frac{1}{y_k^T s_k}.

L-BFGS (Nocedal 1980, Liu and Nocedal 1989) never stores HH but only the last mm pairs, and computes H∇fH\nabla f with the two-loop recursion in 4mn4mn operations. The initial matrix is H0=γIH_0 = \gamma I with γ=sTy/yTy\gamma = s^T y / y^T y from the most recent pair – this gives the direction a sensible length even before the line search, so that α=1\alpha = 1 is usually accepted.

Pseudocode – Lbfgs.minimiere(f, x0, e) and zweiSchleifen

x ← x0;  (fx, g) ← f(x);  not finite → end with message
repeat:
    if ‖g‖∞ ≤ gradTol:  converged “gradient below tolerance”
    if it ≥ maxIt or evaluations ≥ maxEval:  end with message
    d ← zweiSchleifen(g)
    if not g·d < 0:  clear memory, d ← −g                            steepest descent
    α0 ← (memory empty) ? min(1, 1/‖d‖∞) : 1
    line search along d from α0
    if no decrease:  with filled memory clear it and retry, otherwise end
    s ← xNew − x;  y ← gNew − g;  x ← xNew;  g ← gNew
    if s·y > ε · y·y:  append pair (s, y, 1/s·y), drop the oldest beyond m
    if fOld − fx ≤ fTol · max(|fOld|, |fx|, 1):  converged “relative decrease”

zweiSchleifen(g):  q ← g
    for i ← newest to oldest:  α_i ← ρ_i s_i·q;  q ← q − α_i y_i
    q ← (s·y / y·y)_newest · q
    for i ← oldest to newest:  β ← ρ_i y_i·q;  q ← q + (α_i − β) s_i
    return −q

Source: envisionz-framework-math/src/envisionz/math/optimierung/Lbfgs.java, line search in Liniensuche.java.

Worked example. Rosenbrock f=(1−x1)2+100(x2−x12)2f = (1 - x_1)^2 + 100(x_2 - x_1^2)^2 from (−1.2,1)(-1.2,\ 1) with analytic gradient and the defaults: 38 iterations, 47 evaluations, x=(1.0000000004,1.0000000008)x = (1.0000000004,\ 1.0000000008), stop via the relative decrease of ff. With difference gradients the same 38 iterations, xx accurate to 1.4⋅10−81.4 \cdot 10^{-8}.

L-BFGS-B: bounds

Bounds l≤x≤ul \le x \le u are the most common constraint – map scaling factors between 0.8 and 1.2, efficiencies below 1. L-BFGS-B (Byrd, Lu, Nocedal and Zhu 1995) combines L-BFGS with a projection onto the box. The Hessian approximation is kept in compact representation

B=θI−WMWT,W=[Y,θS](n×2m),M−1=(−DLTLθSTS),B = \theta I - W M W^T, \qquad W = [\,Y,\ \theta S\,] \ (n \times 2m), \qquad M^{-1} = \left(\begin{matrix} -D & L^T \\ L & \theta S^T S \end{matrix}\right),

with D=diag(siTyi)D = \operatorname{diag}(s_i^T y_i), Lab=saTybL_{ab} = s_a^T y_b for a>ba > b and θ=yTy/sTy\theta = y^T y / s^T y from the most recent pair (Byrd, Nocedal and Schnabel 1994). All computations with BB thus cost only systems of size 2m2m. An iteration has three parts:

  1. Generalised Cauchy point. Along the projected gradient path x(t)=P(x−t∇f)x(t) = P(x - t\nabla f) the path bends each time a variable hits its bound (at ti=(xi−ui)/git_i = (x_i - u_i)/g_i or (xi−li)/gi(x_i - l_i)/g_i). The quadratic model is followed piece by piece along the path, the breakpoints in ascending order; the first local minimum is the Cauchy point xcx^c. It determines which variables stay at their bounds.
  2. Subspace. Over the remaining free variables the model is minimised exactly (direct primal method; Sherman-Morrison-Woodbury, only 2m×2m2m \times 2m systems), then the step is cut back to the bounds: x\bar x.
  3. Line search along d=x−xd = \bar x - x with the Wolfe search, at most up to the next bound. Initial trial in the first step min⁡(1/‖d‖2,αmax⁡)\min(1/\|d\|_2, \alpha_{\max}), afterwards min⁡(1,αmax⁡)\min(1, \alpha_{\max}). Points that land just outside because of rounding are clamped to the bounds and re-evaluated.

The method has converged when the projected gradient ‖P(x−∇f)−x‖∞≤\|P(x - \nabla f) - x\|_\infty \le gradTol – for a variable at its bound only the part that would point inwards counts – or when ff hardly decreases any more relatively. The start value is projected onto the bounds.

Worked example. f=(x1−1)2+(x2−2)2f = (x_1 - 1)^2 + (x_2 - 2)^2 with x≤(0.5,1)x \le (0.5,\ 1) from (0,0)(0, 0): the free minimum (1,2)(1, 2) lies outside; LbfgsB finds (0.5,1)(0.5,\ 1), f=1.25f = 1.25, in 2 iterations and 3 evaluations; the projected gradient there is 0 although ∇f=(−1,−2)≠0\nabla f = (-1, -2) \ne 0.

SQP: equalities and inequalities

Sequential quadratic programming (Han 1977, Powell 1978) solves a quadratic subproblem in each iteration: the quadratic model of the Lagrangian with linearised constraints,

mind⁡12dTBd+∇fTdsubjectto∇hjTd+hj=0,∇ciTd+ci≥0,\min_d\ \tfrac12 d^T B d + \nabla f^T d \quad \text{subject}\;\text{to} \quad \nabla h_j^T d + h_j = 0,\quad \nabla c_i^T d + c_i \ge 0,

with a BFGS approximation BB of the Hessian of the Lagrangian. The solution gives the step dd and the multipliers λ\lambda. In Sqp bounds are treated as ordinary inequalities xi−li≥0x_i - l_i \ge 0 and ui−xi≥0u_i - x_i \ge 0.

The subproblem via its dual

QpDual solves the convex QP min⁡12dTGd+aTd\min \tfrac12 d^T G d + a^T d subject to Ajd=bjA_j d = b_j or Ajd≥bjA_j d \ge b_j via the dual problem. With d=G−1(ATλ−a)d = G^{-1}(A^T \lambda - a) it becomes

minλ⁡12λTHλ+qTλ,H=AG−1AT,q=−(AG−1a+b).\min_\lambda\ \tfrac12 \lambda^T H \lambda + q^T \lambda, \qquad H = A G^{-1} A^T, \quad q = -(A G^{-1} a + b).

For the inequalities λi≥0\lambda_i \ge 0. Instead of general constraints only sign bounds remain – an active-set method with the feasible start λ=0\lambda = 0 solves this in finitely many steps. GG is factored once by Cholesky; a regularisation 10−14⋅trace(H)/p10^{-14} \cdot \operatorname{trace}(H)/p on the diagonal catches dependent rows. Contradictory constraints show up as an unbounded dual: λ\lambda grows beyond any limit, and QpDual reports it. Sqp then weakens the constraints in the subproblem (right-hand sides halved, up to ten times, i.e. down to 1/1024) and only gives up after that.

Step length: L1 merit function

A full step dd can violate the constraints or increase ff. It is therefore assessed with the exact L1 merit function

Φ(x)=f(x)+∑jμj|hj(x)|+∑iμimax⁡(0,−ci(x)),\Phi(x) = f(x) + \sum_j \mu_j |h_j(x)| + \sum_i \mu_i \max(0, -c_i(x)),

with weights after Powell: μ=2|λ|\mu = 2|\lambda| in the first iteration, afterwards μ←max⁡(|λ|,12(μ+|λ|))\mu \leftarrow \max\big(|\lambda|,\ \tfrac12(\mu + |\lambda|)\big), at least 10−1010^{-10}. The step length is backtracked from α=1\alpha = 1 until Φ(x+αd)≤Φ(x)+0.1αΦ'\Phi(x + \alpha d) \le \Phi(x) + 0.1\,\alpha\,\Phi' (at most 40 trials, quadratic interpolation, restricted to [0.1α,0.5α][0.1\alpha,\ 0.5\alpha]).

Second-order correction: if already the full step is rejected, this is often due to the curvature of the constraints, not to dd (Maratos effect). Once per iteration x+d−AT(AAT)−1c(x+d)x + d - A^T (A A^T)^{-1} c(x + d) over the equalities and the active inequalities is therefore tried; if the merit function decreases sufficiently with it, this point is taken.

Hessian approximation: BFGS with Powell's damping

The Hessian of the Lagrangian is often not positive definite, but the subproblem needs a positive definite BB. Powell's damping replaces yy by r=τy+(1−τ)Bsr = \tau y + (1 - \tau) B s if sTy<0.2sTBss^T y < 0.2\, s^T B s, with τ=0.8sTBs/(sTBs−sTy)\tau = 0.8\, s^T B s / (s^T B s - s^T y); then sTr=0.2sTBs>0s^T r = 0.2\,s^T B s > 0, and the update

B←B+rrTsTr−BssTBsTBsB \leftarrow B + \frac{r r^T}{s^T r} - \frac{B s s^T B}{s^T B s}

stays positive definite. According to the module description none of the reference problems needs this damping (the counter-probe on it stayed green); it remains as a safeguard.

Pseudocode – Sqp.minimiere(f, gleich, ungleich, unten, oben, x0, e)

x ← x0 projected onto the bounds;  evaluate state (f, ∇f, c, A = ∇c);  B ← I
repeat:
    check maxima
    for factor ← 1, ½, ¼, … (up to 10 halvings):
        (d, λ) ← QpDual(B, ∇f, A, −factor · c, me);  if solved: break
    if unsolved: end “subproblem unsolvable”
    kkt ← ‖∇f − Σ λ_j ∇c_j‖∞;  viol ← largest violation
    if viol ≤ nbTol and kkt ≤ gradTol · max(1, ‖∇f‖∞):           converged “KKT”
    if viol ≤ nbTol and |∇f·d| + Σ|λ_j c_j| ≤ gradTol (1 + |f|):    converged “expected decrease”
    if viol ≤ nbTol and ‖d‖∞ ≤ gradTol (1 + ‖x‖∞):                 converged “step vanishes”
    μ after Powell;  Φ0 ← Φ(x);  Φ' ← ∇f·d − penalty part
    α ← 1;  up to 40 times:
        x_α ← P(x + α d);  if Φ(x_α) ≤ Φ0 + 0.1 α Φ': accepted
        if first trial: try the second-order correction
        α ← interpolation, in [0.1 α, 0.5 α]
    if nothing accepted:
        if viol ≤ nbTol and kkt ≤ √gradTol · max(1, ‖∇f‖∞): converged “accuracy exhausted”
        else end “merit function does not decrease”
    s ← x_new − x;  y ← ∇L(x_new, λ) − ∇L(x, λ);  bfgsGedaempft(B, s, y)

Gradient from differences

Zielfunktion.numerisch(f) forms the gradient with central differences,

∂f∂xi≈f(x+hiei)−f(x−hiei)2hi,hi=ε1/3max⁡(1,|xi|),\frac{\partial f}{\partial x_i} \approx \frac{f(x + h_i e_i) - f(x - h_i e_i)}{2 h_i}, \qquad h_i = \varepsilon^{1/3} \max(1, |x_i|),

2n2n evaluations per gradient. The step ε1/3≈6⋅10−6\varepsilon^{1/3} \approx 6 \cdot 10^{-6} balances the truncation error (∝h2\propto h^2) against the rounding error (∝ε/h\propto \varepsilon/h). Probe NM9-XX-05 hits the gradient of x3+eyx^3 + e^y at (2,1)(2, 1) to 6⋅10−116 \cdot 10^{-11}. For tight tolerances an analytic gradient remains better; with differences the gradient tolerance cannot sensibly be below about 10−810^{-8}.

Convention in the framework: Einstellung.standard(): gradTol 10−810^{-8}, fTol 10−1210^{-12} (relative to max⁡(|fold|,|f|,1)\max(|f_{\text{old}}|, |f|, 1)), nbTol 10−810^{-8}, memory 10 pairs, 2000 iterations, 50 000 evaluations. For Lbfgs and LbfgsB gradTol is absolute, for Sqp relative to max⁡(1,‖∇f‖∞)\max(1, \|\nabla f\|_\infty). Inequalities are always in the form c(x)≥0c(x) \ge 0. The start value is not modified.

Limits

  • Only local minima; with several valleys the start value decides.
  • The objective must be smooth (continuous first derivatives); kinks, jumps or noisy function values disturb the line search and BFGS. For such cases: Nelder-Mead.
  • Sqp computes densely (BB is n×nn \times n, the dual p×pp \times p) – up to a few hundred variables and constraints.
  • In flat valleys xx is only accurate to about tolerance\sqrt{\text{tolerance}}, even if ff is very accurate (HS39, recorded during construction).
  • Difference gradients limit the achievable accuracy (see above).
