Iterative solvers (Krylov) – background

The computation behind KonjugierteGradienten, Gmres and BiCgStab: Krylov spaces, the conjugate gradient method, GMRES with restart and Givens rotations, BiCGStab, preconditioning and the stopping rules – with pseudocode following the source, a worked example by hand, checks and limits.

What this is about

The direct methods (LU, sparse LU) need the matrix entry by entry and pay with fill-in. For a heat conduction problem on a fine grid, or for a Newton method whose Jacobian is only available as a directional derivative Jv≈(F(x+εv)−F(x))/εJ v \approx (F(x + \varepsilon v) - F(x))/\varepsilon, the matrix does not exist at all – only the rule v→Avv \to A v. Iterative methods make do with that: they improve an approximation step by step and need one or two applications of AA per step.

In the package the matrix is therefore a LinearerOperator with a single method anwenden(x, y): y=Axy = A x. Whether a dense matrix (LinearerOperator.dicht), a finite-difference stencil or a function evaluation is behind it, the method does not see.

The Krylov space

From the initial residual r0=b−Ax0r_0 = b - A x_0 and repeated application of AA arises the Krylov space

Kk(A,r0)=span⁡{r0,Ar0,A2r0,…,Ak−1r0}.\mathcal{K}_k(A, r_0) = \operatorname{span}\{r_0,\ A r_0,\ A^2 r_0,\ \dots,\ A^{k-1} r_0\}.

All methods implemented here seek the kk-th approximation in x0+Kkx_0 + \mathcal{K}_k. The residual is then a polynomial in AA applied to r0r_0:

rk=pk(A)r0,pk(0)=1,r_k = p_k(A)\, r_0, \qquad p_k(0) = 1,

with a polynomial pkp_k of degree kk.

This gives the most important property: if AA has only mm distinct eigenvalues λ1,…,λm\lambda_1, \dots, \lambda_m (and is diagonalisable), the polynomial p(z)=∏j(1−z/λj)p(z) = \prod_j (1 - z/\lambda_j) vanishes on the whole spectrum, and a method that finds the best polynomial is exactly done after at most mm steps. The probes use this as a sharp anchor: five distinct eigenvalues → CG in at most 5 steps, four → GMRES without restart in at most 4. More generally a Krylov method converges fast if the eigenvalues gather in a few clusters far away from 0 – which is the aim of preconditioning.

The methods differ in which polynomial they choose and what they require for it:

Conjugate gradients (CG)

For symmetric positive definite AA, Ax=bA x = b is equivalent to minimising ϕ(x)=12xTAx−bTx\phi(x) = \tfrac12 x^T A x - b^T x; the residual r=b−Axr = b - A x is the negative gradient. Steepest descent runs along rr and zigzags in an elongated valley. CG (Hestenes and Stiefel 1952) instead chooses search directions that are A-conjugate to each other, piTApj=0p_i^T A p_j = 0 for i≠ji \ne j. Then each direction is finished for good after one step, and xkx_k minimises ϕ\phi – equivalently the error in the A-norm – over all of x0+Kkx_0 + \mathcal{K}_k. The directions come from a short recurrence without storing old vectors:

αk=rkTzkpkTApk,xk+1=xk+αkpk,rk+1=rk−αkApk,βk=rk+1Tzk+1rkTzk,pk+1=zk+1+βkpk\alpha_k = \frac{r_k^T z_k}{p_k^T A p_k}, \quad x_{k+1} = x_k + \alpha_k p_k, \quad r_{k+1} = r_k - \alpha_k A p_k, \quad \beta_k = \frac{r_{k+1}^T z_{k+1}}{r_k^T z_k}, \quad p_{k+1} = z_{k+1} + \beta_k p_k

with z=M−1rz = M^{-1} r (without preconditioner z=rz = r). For convergence the well-known bound holds

‖xk−x*‖A≤2(κ−1κ+1)k‖x0−x*‖A,\|x_k - x_*\|_A \le 2\left(\frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}\right)^k \|x_0 - x_*\|_A,

so the number of steps grows with κ\sqrt{\kappa}, not with κ\kappa. For the five-point stencil on 30×3030 \times 30 points (n=900n = 900) CG needs 108 steps to 10−1010^{-10} in the probe.

Pseudocode – KonjugierteGradienten.loese(a, b, x0, m, absTol, relTol, maxIt)

target ← max(absTol, relTol · ‖b‖)
x ← x0 (copy) or 0;  r ← b − A x                                  1st operator call
if ‖r‖ ≤ target: done
z ← M⁻¹ r;  p ← z;  rz ← r·z
if not rz > 0: stop “preconditioner not positive definite”
for it ← 1 to maxIt:
    ap ← A p;  pap ← p·ap
    if not pap > 0: stop “matrix not positive definite (p·Ap = …)”
    α ← rz / pap;   x ← x + α p;   r ← r − α ap
    if x not finite: stop
    if ‖r‖ ≤ target:                                           recursive residual
        r ← b − A x                                               recompute the true residual
        if ‖r‖ ≤ target: done
        z ← M⁻¹ r;  p ← z;  rz ← r·z;  continue                      restart
    z ← M⁻¹ r;  rzNew ← r·z
    if not rzNew > 0: stop
    β ← rzNew / rz;  rz ← rzNew;  p ← z + β p
end “maximum number of iterations reached”

Source: envisionz-framework-math/src/envisionz/math/krylov/KonjugierteGradienten.java; input checks, counting and final computation in Ablauf.java.

GMRES with restart

For non-symmetric matrices there is no short recurrence that is optimal at the same time. GMRES (Saad and Schultz 1986) therefore builds an orthonormal basis Vk=[v1,…,vk]V_k = [v_1, \dots, v_k] of the Krylov space explicitly (Arnoldi process) and chooses in it the xx with the smallest residual. The Arnoldi recurrence gives

AVk=Vk+1Hk,A V_k = V_{k+1} \bar H_k,

with an upper Hessenberg matrix Hk\bar H_k of size (k+1)×k(k+1) \times k, and with x=x0+Vkyx = x_0 + V_k y the large least-squares problem becomes a small one:

‖b−Ax‖2=‖βe1−Hky‖2,β=‖r0‖2.\|b - A x\|_2 = \|\beta e_1 - \bar H_k y\|_2, \qquad \beta = \|r_0\|_2.

It is solved progressively with Givens rotations: every new column of H\bar H first receives all previous rotations, then a new one that annihilates the subdiagonal element hj+1,jh_{j+1,j}. The right-hand side g=βe1g = \beta e_1 is rotated along, and its last entry |gj+1||g_{j+1}| is the norm of the residual – without another application of AA.

The basis grows by one vector of length nn per step, and orthogonalisation costs O(kn)O(k n) per step. After mm steps (default NEUSTART = 30) the approximation is therefore formed and the method restarts with the true residual: GMRES(m). The restart forgets the Krylov space; for difficult matrices this can slow convergence down considerably (in the probe GMRES(2) on the convection problem still has a relative residual of 0.4 after 20 steps).

Orthogonalisation: modified Gram-Schmidt, and if the norm of the new vector drops below 1/21/\sqrt 2 of its initial value – a sign of cancellation – a second pass (criterion after Daniel, Gragg, Kaufman and Stewart). The corrections of the second pass are added into H\bar H.

Right preconditioning: the method solves AM−1u=bA M^{-1} u = b, x=M−1ux = M^{-1} u. The minimised residual is then the unpreconditioned b−Axb - A x; the tolerance means the same with and without preconditioner.

Pseudocode – Gmres.loese(a, b, x0, m, absTol, relTol, neustart, maxIt)

k ← min(neustart, n);  x ← x0 or 0;  r ← b − A x;  it ← 0
repeat:
    β ← ‖r‖
    if β ≤ target: done;   if it ≥ maxIt: end “maximum reached”
    v₀ ← r / β;   g ← (β, 0, …, 0)
    for j ← 0 to k−1, while it < maxIt:
        it ← it + 1
        w ← A (M⁻¹ v_j);   before ← ‖w‖
        for i ← 0 to j:  h[i][j] ← w·v_i;  w ← w − h[i][j] v_i              MGS
        if ‖w‖ < 0.7071 · before:                                          second pass
            for i ← 0 to j:  c ← w·v_i;  h[i][j] ← h[i][j] + c;  w ← w − c v_i
        h[j+1][j] ← ‖w‖
        apply old Givens rotations 0..j−1 to column j
        d ← hypot(h[j][j], h[j+1][j])
        if d = 0 or not finite: stop “Arnoldi breakdown”
        cs[j] ← h[j][j]/d;  sn[j] ← h[j+1][j]/d;  h[j][j] ← d;  h[j+1][j] ← 0
        g[j+1] ← −sn[j] g[j];   g[j] ← cs[j] g[j]
        lucky ← ‖w‖ ≤ 1e−14 · before                                        Krylov space invariant
        if not lucky: v_{j+1} ← w / ‖w‖
        if lucky or |g[j+1]| ≤ target: break
    solve H y = g (upper triangle) backwards
    x ← x + M⁻¹ (Σ y_i v_i);   r ← b − A x                                     true residual

Source: envisionz-framework-math/src/envisionz/math/krylov/Gmres.java. The factor 0.7071 is 1/21/\sqrt 2: reorthogonalisation happens when more than half of the squared norm is lost (until 2026-09-28 the class description said “half of the norm”, corrected, WT5).

BiCGStab

BiCGStab (van der Vorst 1992) combines the biconjugate gradient method – a short recurrence for non-symmetric matrices whose residuals are orthogonal to a second, “shadow” Krylov space built from r^0\hat r_0 – with a smoothing step that minimises the residual along t=As^t = A \hat s in every iteration. Memory is fixed, AA and M−1M^{-1} are applied twice per iteration. In exchange the method minimises nothing global; the residual history can jump, and the recurrence can break down when a denominator becomes zero.

Pseudocode – BiCgStab.loese(a, b, x0, m, absTol, relTol, maxIt)

r ← b − A x;  if ‖r‖ ≤ target: done
r̂₀ ← r;  ρ ← α ← ω ← 1;  v ← p ← 0
for it ← 1 to maxIt:
    ρ_new ← r̂₀·r;         if ρ_new = 0 or not finite: breakdown
    β ← (ρ_new/ρ)(α/ω)
    p ← r + β (p − ω v);   p̂ ← M⁻¹ p;   v ← A p̂
    r̂₀v ← r̂₀·v;           if r̂₀v = 0 or not finite: breakdown
    α ← ρ_new / r̂₀v;   s ← r − α v
    if ‖s‖ ≤ target:  x ← x + α p̂;  check the true residual, otherwise restart with it
    ŝ ← M⁻¹ s;   t ← A ŝ;   if t·t = 0: breakdown
    ω ← (t·s)/(t·t);   x ← x + α p̂ + ω ŝ;   r ← s − ω t
    if ω = 0: breakdown
    if ‖r‖ ≤ target: check the true residual, otherwise restart
    ρ ← ρ_new

Source: envisionz-framework-math/src/envisionz/math/krylov/BiCgStab.java. On restart r^0\hat r_0, pp, vv and ρ,α,ω\rho, \alpha, \omega are reset.

A breakdown is not rare for small unfavourable matrices: for A=(0110)A = \left(\begin{matrix} 0 & 1 \\ 1 & 0 \end{matrix}\right) with x*=(0,1)x_* = (0, 1) we have b=(1,0)b = (1, 0), v=Ar=(0,1)v = A r = (0, 1) and r^0⋅v=0\hat r_0 \cdot v = 0 in the very first step. BiCGStab reports “Zusammenbruch: r0 . v = 0.0”; GMRES solves the same problem in 2 steps (case NM5-BS-03 of the probe).

Preconditioning

A preconditioner M≈AM \approx A is a cheap approximation with which, instead of Ax=bA x = b, one solves the equivalent system M−1Ax=M−1bM^{-1} A x = M^{-1} b (left) or AM−1u=bA M^{-1} u = b (right). If M−1AM^{-1} A is closer to the identity, the eigenvalues are more clustered and the Krylov method needs fewer steps. Only the application z=M−1rz = M^{-1} r is required – the interface Vorkonditionierer has exactly this one method.

  • Vorkonditionierer.keiner(): z=rz = r.
  • Vorkonditionierer.jacobi(d): zi=ri/diz_i = r_i / d_i with the diagonal dd of AA. Helps with rows or columns that differ by orders of magnitude. Zero or non-finite diagonal entries are rejected on creation.

For CG, MM must be symmetric positive definite; the class checks this indirectly via rTz>0r^T z > 0. Effect in the probe: on the two-sided scaled 1D Poisson matrix DADD A D, D=diag⁡(103i/99)D = \operatorname{diag}(10^{3i/99}), CG needs 1502 steps without preconditioner, with Jacobi 100; GMRES(30) on the column-scaled convection problem uses up the allowed 3000 steps without preconditioner, with Jacobi from the right 571 suffice; BiCGStab needs 245 instead of the full 5000.

Convention in the framework: ILU(0) and SSOR are deliberately missing; they need the sparsity structure. Any existing solver can however be plugged in as a preconditioner – for instance an LU factorisation of an approximate matrix. Jacobi from the right compensates column scaling, not row scaling; the first version of probe problem NM5-P10 was designed wrongly because of this (finding during construction).

Stopping and the true residual

All three methods carry the residual along by a recurrence, not via b−Axb - A x. In floating point the two drift apart; the recursive one may keep falling while the true one stagnates. Therefore:

  • The target is ‖b−Ax‖2≤max⁡(absTol,relTol‖b‖2)\|b - A x\|_2 \le \max(\text{absTol},\ \text{relTol}\,\|b\|_2); both tolerances 0 are rejected.
  • When the recursive residual reaches the target, the true one is recomputed. If it misses the target, the method restarts with the true residual (CG: new search direction p=M−1rp = M^{-1} r; BiCGStab: new shadow vector) until the maximum is reached.
  • The result Loesung always carries the residual freshly computed at the end, the relative residual, the iterations, the counted operator calls, konvergiert and a message. Converged means: no breakdown and true residual below the target – even if the maximum was reached on the way.
  • The Euclidean norm is computed scaled by the largest entry and therefore does not overflow even for entries around 1020010^{200}.
Convention in the framework: defaults: start at 0, no preconditioner, GMRES restart after 30 steps. For GMRES maxIt counts Arnoldi steps over all restarts. Operator calls are counted exactly; for CG they are start + one per step + final computation, so that five steps give 7 calls (check NM5-CG-04).

Limits

  • CG assumes symmetry without checking it; for non-symmetric AA it does not converge or converges to something wrong. Only lack of definiteness is detected (pTAp≤0p^T A p \le 0).
  • GMRES(m) can stagnate if mm is too small; without restart (m≥nm \ge n) memory grows to n2n^2.
  • BiCGStab can break down; this is reported, not worked around. If in doubt, use GMRES.
  • Only Jacobi as built-in preconditioner; for difficult field problems (fine grids, strong convection) that is not enough – plug in your own Vorkonditionierer there.
  • The speed of convergence depends on the problem, not on the code: κ\sqrt\kappa for CG, the eigenvalue distribution for GMRES.
