Eigenvalues and singular value decomposition – large operators: Lanczos and Arnoldi

The computation behind Lanczos, Arnoldi, Einstellung and the package-internal building blocks Basis and Nachbereitung: Arnoldi decomposition, Ritz values, residual estimate, thick restart and restart on the invariant subspace – with pseudocode following the source, a recomputed example, checks and limits. The dense methods are on the page QR and SVD.

What this is about

A finite-element model of a compressor blade has tens of thousands of degrees of freedom, but only the five lowest natural frequencies are needed. A Markov chain with thousands of states has exactly one interesting eigenvalue, 1, and with it the stationary distribution. Computing all eigenvalues densely (O(n3)O(n^3), memory n2n^2) would be wasteful and often impossible, because the matrix is only available as a rule v→Avv \to A v – as a LinearerOperator like for the Krylov solvers.

Lanczos (symmetric) and Arnoldi (general) compute some eigenvalues at the edge of the spectrum – the largest, the smallest or those of largest magnitude – and need only applications of the operator and memory for a few dozen vectors. They correspond to eigs in MATLAB and the ARPACK routines dsaupd and dnaupd, but are written independently in Java.

Arnoldi decomposition and Ritz values

From a start vector v0v_0, as in GMRES, an orthonormal basis of the Krylov space Km(A,v0)\mathcal{K}_m(A, v_0) is built. Writing the orthogonalisation coefficients into an m×mm \times m matrix HH, the Arnoldi relation holds

AVm=VmHm+βvmemT,VmTVm=I,VmTvm=0.A V_m = V_m H_m + \beta\, v_m e_m^T, \qquad V_m^T V_m = I, \qquad V_m^T v_m = 0.

Hm=VmTAVmH_m = V_m^T A V_m is the projection of AA onto the Krylov space, a small matrix. Its eigenvalues θi\theta_i are called Ritz values, the corresponding vectors xi=Vmyix_i = V_m y_i Ritz vectors. The Ritz values approximate the edges of the spectrum particularly fast – the Krylov space contains polynomials in AA, and polynomials emphasise the outer eigenvalues. For the residual of a Ritz pair the Arnoldi relation gives, without another operator application,

‖Axi−θixi‖=|β|⋅|emTyi|(‖yi‖=1),\|A x_i - \theta_i x_i\| = |\beta| \cdot |e_m^T y_i| \qquad (\|y_i\| = 1),

i.e. the magnitude of the last component of yiy_i times β\beta. This residual estimate decides convergence. If AA is symmetric, HH is symmetric too and even tridiagonal – that is the Lanczos method.

The basis in the code

Both methods use the same class Basis. It orthogonalises fully – every new vector against all previous ones, with classical Gram-Schmidt in two passes. This is more expensive than the three-term recurrence of the classical Lanczos method but avoids its well-known weakness: without reorthogonalisation the Lanczos vectors lose their orthogonality in floating point, and copies of already converged eigenvalues appear (“ghost values”).

// Basis.erweitere(von): columns von..m−1
for j ← von to m−1:
    w ← A v_j;  before ← ‖w‖
    twice: for i ← 0 to j:  c ← v_i·w;  h[i][j] ← h[i][j] + c;  w ← w − c v_i
    b ← ‖w‖
    if b ≤ 1e−12 · max(before, max_i |h[i][j]|) or b = 0:              invariant subspace
        if j+1 < m:  v_{j+1} ← random vector ⟂ v_0..v_j;  h[j+1][j] ← 0      replacement
        else:        β ← 0;  invariant ← true
        continue
    v_{j+1} ← w / b
    if j+1 < m: h[j+1][j] ← b  else: β ← b

Source: envisionz-framework-math/src/envisionz/math/eigen/Basis.java. Start vector and replacement vectors come from java.util.Random with the fixed seed 4711 (entries uniform in [−0.5,0.5][-0.5,\ 0.5]); if no independent replacement is found after ten attempts, an ArithmeticException is thrown.

Restart

The search space mm is limited because memory (n⋅mn \cdot m) and orthogonalisation (nm2n m^2 per pass) grow with it. If it does not suffice, the method restarts – not from scratch, but with the best part of the space so far.

Lanczos: thick restart

For the symmetric problem (Wu and Simon 2000) the ll best Ritz vectors are kept, qc=yord(c)q_c = y_{\text{ord}(c)}. In the new basis v˜c=Vmqc\tilde v_c = V_m q_c the projected matrix is diagonal with the Ritz values, and the last row couples them to the rest vector:

AV˜l=V˜ldiag⁡(θ1,…,θl)+vm(βemTQ),v˜l:=vm.A \tilde V_l = \tilde V_l \operatorname{diag}(\theta_1, \dots, \theta_l) + v_m\,(\beta\, e_m^T Q), \qquad \tilde v_l := v_m.

The code puts this coupling into row ll of HH (hl,c=βqm−1,ch_{l,c} = \beta\, q_{m-1,c}), and erweitere(l) rebuilds the space from there. Because HH is then no longer tridiagonal, T=(H+HT)/2T = (H + H^T)/2 is formed before each decomposition and factored with the package-internal Symmetrisch (EISPACK tred2/tql2, Householder tridiagonalisation and implicit QL).

Arnoldi: restart on the invariant subspace

For the non-symmetric problem the Ritz vectors are not orthogonal, and complex pairs must stay together. Arnoldi therefore keeps (in the sense of Stewart's Krylov-Schur method) an orthonormal basis of the subspace spanned by the Ritz vectors of the ll best values – for a pair real and imaginary part as two columns; a pair is never split. The columns are orthonormalised with Gram-Schmidt (twice), dependent ones are dropped, and HH is projected onto the new basis: Hnew=QTHQH_{\text{new}} = Q^T H Q. The Ritz values of HH are computed by EigenQr with balancing.

Pseudocode – Lanczos.loese(a, n, k, wahl, e)

m ← suchraum(e, k, n);  basis with start vector;  von ← 0;  restarts ← 0
repeat:
    erweitere(von)
    T ← (H + Hᵀ)/2;  (θ, Y) ← Symmetrisch.zerlege(T)
    ord ← indices by selection (GROESSTE, KLEINSTE: algebraic; BETRAG_GROESSTE)
    limit ← tolerance · max(max|θ|, MIN_NORMAL)
    good ← number of i < k with |β · Y[m−1][ord[i]]| ≤ limit
    done ← (good = k) or (m = n and β = 0)
    if done or restarts ≥ maxRestarts:
        x_i ← V · Y[·][ord[i]] for i < k
        return Nachbereitung.fertig(θ_ord, x, …)                recompute residuals
    restarts ← restarts + 1
    l ← min(m−1, k + max(1, (m−k)/2))
    Q ← Y[·][ord[0..l−1]];  H ← diag(θ_ord);  coupling h[l][c] ← β·Q[m−1][c]
    Basis.neustart(Q, l, H);  von ← l

Source: envisionz-framework-math/src/envisionz/math/eigen/Lanczos.java; Arnoldi.java follows the same flow with EigenQr instead of Symmetrisch, pairs as units, residual estimate |β||ym|2/‖y‖2|\beta| \sqrt{|y_m|^2/\|y\|^2} and orthonormalisation of the kept columns.

The result is an Eigenpaare as for the dense methods: values in the order of the selection, pairs side by side (+i+i first), vectors normalised, recomputed residuals ‖Ax−λx‖\|A x - \lambda x\|, number of restarts and operator calls, konvergiert and a message. If for Arnoldi the kk-th wanted value cuts a complex pair, the partner is added – the result then has k+1k + 1 values.

Limits

  • Lanczos does not check symmetry; for a non-symmetric operator the result is wrong – then use Arnoldi.
  • Multiple eigenvalues are found only once in exact arithmetic (the Krylov space contains only one direction from each eigenspace); rounding and reorthogonalisation usually bring further copies along, but this cannot be relied on.
  • Interior eigenvalues (near a value σ\sigma in the middle of the spectrum) converge slowly. There compute with (A−σI)−1(A - \sigma I)^{-1} as the operator – for instance via an LU factorisation – and choose BETRAG_GROESSTE; the eigenvalues follow as σ+1/μ\sigma + 1/\mu.
  • The speed depends on the gap between wanted and remaining values. If many values lie close together at the edge (for instance on a spiral), hundreds of restarts are normal – then enlarge the search space (observed during construction; a property of the method).
  • Full reorthogonalisation costs O(nm2)O(n m^2) per pass; for very large mm this becomes the most expensive part.
  • For strongly non-normal matrices the residual can be small and the eigenvalue still inaccurate (see QR and SVD).
