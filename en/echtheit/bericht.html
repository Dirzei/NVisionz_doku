Maps, time axis and report – background

What the traces have in common: the map with threshold 1, the rule for connected regions, the mapping from frame pairs to frames, the combination with weights and why there is no overall verdict – with derivation, pseudocode following the source, a worked example, testing and limits.

What this is about

The image-based traces deliver what they found as maps. So that these can be compared they share a scale, and so that no false impression arises there is no computation that turns the maps into genuine or fake. Each trace judges only for itself.

The scale

Each map has one value per tile, with a fixed meaning:

ValueMeaning
v≥1v \ge 1above the trace's threshold
0≤v<10 \le v < 1measured, below the threshold
NaNnothing measured
0.99explicitly taken back: single tile, rigid object or cap

So the number is neither a percentage nor a probability; it only means "multiple of this trace's threshold". The thresholds are settings from test material.

Regions

Regions are sets of tiles with v≥1v \ge 1, connected through the eight neighbours. They count from a minimum of 2 tiles; single tiles stay visible as 0.99. For output the enclosing rectangle is determined, the strongest region first.

The rule embodies the experience that single tiles fire at any scale without anything being there.

From frame pair to frame

Many traces measure between frame ii and frame i+ai + a. A change in frame ff then hits two pairs, f−af - a and ff. If every frame of a firing pair were "conspicuous", the display would be aa frames too wide. Hence:

vf=min⁡(pf−a,pf),a≤f<n−a.v_f = \min(p_{f-a},\ p_f), \qquad a \le f < n - a.

Why the minimum (derived). Let BB be the set of affected frames. Pair ii fires exactly if i∈Bi \in B or i+a∈Bi + a \in B. So a frame f∈Bf \in B makes both pairs f−af - a and ff fire. A frame f∉Bf \notin B whose two pairs both fire must have f−a∈Bf - a \in B and f+a∈Bf + a \in B: a false marking arises only when regions lie exactly 2a2a frames apart.

At the border one pair is missing. There the frame inherits from its inner neighbour: working outward, vf=min⁡(pf,vf+1)v_f = \min(p_f, v_{f+1}) and vf=min⁡(pf−a,vf−1)v_f = \min(p_{f-a}, v_{f-1}). For n≤2an \le 2a there are no inner frames, and the maximum of the existing pairs applies. For display, connected sections with vf≥1v_f \ge 1 are formed.

Combination

The combination samples all maps with a valid verdict at the tile centres of the finest map and weights by evidential value:

TraceWeightTraceWeight
geometry1.0groups of pictures0.7
camera pattern1.0spectrum0.6
time0.8motion0.4
double quantisation0.7others0.5

With gj=vjγjg_j = v_j \gamma_j the value is:

w=h+12max⁡(0,S−max⁡(h,0)),h=maxj⁡gj,S=∑j:vj≥1gj.w = h + \tfrac12 \max(0,\ S - \max(h, 0)), \qquad h = \max_j g_j, \qquad S = \sum_{j : v_j \ge 1} g_j.

The strongest trace counts in full; whatever else lies above the threshold counts half. A single trace thus stays at hh; a second, independent trace at the same location raises the value visibly without letting the sum grow linearly, because the traces need not be independent. Traces that could not be evaluated do not enter (EC-44), and without maps there is no combination (EC-45). The weights are settings (caveat).

The timeline counts per frame the traces with a "conspicuous" verdict and a course value of at least 1.

Why there is no overall verdict

A probability of "genuine" from the traces would need the joint distribution of all traces for genuine and edited material: per camera, per encoder and per kind of edit. That does not exist; all thresholds come from generated material. A number pretending to such a statement would be the most dangerous kind of result. So the report says "indications, not proof" and gives for each trace the reasons and settings. What the traces cannot settle among themselves stays open.

VerdictMeansDoes not mean
conspicuousthe measurement lies above the threshold, at a named locationedited
unremarkablenothing reached the thresholdgenuine
cannot be evaluatednothing to measure, with a reasona finding

Pseudocode – Bericht.zusammen()

ref ← finest map among the traces with a valid verdict
if none: nothing
for each tile (s, z) of ref:
    highest ← NaN;  sum ← 0
    for each trace:  v ← Karte.bei(tile centre);  if NaN: continue
        g ← v · weight(id)
        highest ← max(highest, g)
        if v ≥ 1: sum ← sum + g
    w[z][s] ← highest + 0.5 · max(0, sum − max(highest, 0))

Source: envisionz-framework-echtheit/src/envisionz/echtheit/bericht/Bericht.java, Karte.java, Zeitachse.java.

How it is tested

  • Building blocks (Echtheitsprobe): regions and minimum (EC-01, EC-02), sampling (EC-03), time axis in the middle and at the border (EC-06, EC-07), continuous (EC-08), sections (EC-09).
  • Report: no overall verdict (EC-39), frames are named (EC-40), a trace that cannot be evaluated stays out (EC-44), no maps no combination (EC-45), nine traces (EV-111), weights of the new traces (EV-113).
  • On the object: the combination carries the object (EC-25), the timeline shows the frames (EC-24).

The weights and the combination formula are covered in the tests only through the result on the object, not with fixed numbers.

Limits

  • The combined view is a display: a higher value does not mean the location was edited with more certainty.
  • The traces are not independent; the same object can count twice through geometry and time.
  • The time axis assumes that affected frames are contiguous. With changes lying exactly 2a2a frames apart, the frame in between is marked as well.
  • Maps of different resolution are only sampled, not converted; a coarse map counts for all tiles it covers.
