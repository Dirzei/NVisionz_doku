envisionz-framework-chiffre

Fifty historical ciphers – encrypt, recognise, break

Function overview for the presentation of the envisionz framework, as of 28 Sep 2026. A catalogue from Atbash to Kryptos, six cipher machines from the Enigma to Purple, analysis with profile and periodicity, automatic breaking against a language model, a collection of historical ciphertexts, plus command line (envisionz-commandline-chiffre) and GUI (envisionz-app-chiffre). For each method: purpose, API, use in the framework, applications, examples. The examples are shortened. Most API names are German (e.g. Verfahren = method, Schluessel = key, verschluessele = encrypt, Brecher = breaker); they are shown unchanged.

50methods in the catalogue, from 6 epochs and 6 regions
6machines: Enigma I/M3/M4, M-209, Typex, SIGABA, Lorenz, Purple
14breakers for 29 methods, without the key
0dependencies, pure JDK, no Swing
9probe classes, 10 test files
7counter-probes

Principles of the module

A method exists only once it is in the catalogue. Katalog is the one hand-maintained list, without reflection. GUI, command line and probes see only the catalogue.
Published test values rather than round trips. Every method is held against an example from a textbook or original source, the Enigma against real radio messages (Barbarossa 1941, Scharnhorst 1943, M4).
Checked against the original. The codebook of the Wujing Zongyao was corrected against the scan of the Siku Quanshu edition: message no. 18 was missing in the secondary source, and every code after it was shifted by one.
Language tables generated, not maintained. Quadgrams and single-letter frequencies are built from a corpus (German from Europarl, English from a Gutenberg extract), format QG01 in GZIP.
Compute core without GUI. Pure JDK, no dependency, no Swing. The same classes carry command line and app.
Locale-proof and ordered. Locale.ROOT for every case conversion; ordered collections are never copied with Map.copyOf.

Catalogue, key, alphabets envisionz.chiffre

Verfahren, Katalog, Schluessel, Parameter

Each method carries id, name, epoch, region, date, description and its key parts. A key part is text, number, choice or block and has a default; from these the GUI builds its input fields and the command line its switches.

Methods

  • Katalog.alle() (all), Katalog.nach(kennung) (by id)
  • Verfahren: kennung(), name(), epoche(), region(), zeit(), parameter(), verschluessele(klar, s), entschluessele(geheim, s), reziprok(), alphabet(s)
  • Schluessel.vorgabe(v), von(v, name, wert, …), von(v, map), mit(name, wert), text(name), zahl(name)
  • Parameter.text, zahl, wahl, block; Epoche, Region; Texte.name(v), beschreibung(v) (DE/EN)

Used in

app-chiffre: method card, chronicle, key fieldscommandline-chiffre: -op:liste, -op:info, -op:ver, -op:ent

What for

Teaching and talks on the history of encryption; generating exercise texts.

Example – Vigenère with the textbook key

Verfahren v = Katalog.nach("vigenere");
Schluessel s = Schluessel.von(v, "schluesselwort", "LEMON");
String geheim = v.verschluessele("attack at dawn", s);
String gruppen = Aufbereitung.inGruppen(geheim, 5);

Alphabet and Aufbereitung

Alphabets by code point: Latin with 26, 25 (without J or without Q) and 36 characters, Hebrew, Iroha (kana). The preparation (Aufbereitung) reduces text to an alphabet, sets groups of five and can lay the original form (spaces, punctuation, case) over the result.

Methods

  • Alphabet.LATEIN, LATEIN25, LATEIN25_OHNE_Q, LATEIN36, HEBRAEISCH, IROHA; stellen(text), text(stellen), index(cp)
  • Aufbereitung.buchstaben(text, alphabet), inGruppen(text, groesse), formErhalten(original, ergebnis, alphabet)

Used in

app-chiffre: keep form, groups of fivecommandline-chiffre: -gruppen, -form

What for

Hebrew ciphers (Atbash) and Japanese ones (Uesugi) in their own script; readable output with punctuation.

Hand ciphers envisionz.chiffre.verfahren

From antiquity to Kryptos – 44 methods without a machine

Shared genera: Grundlage (base), on top of it Buchstabenweise (letter-by-letter substitution) and Transposition. Helpers: Quadrat, Mischalphabet, Zahlen, Digraphen. Plus special cases with their own logic: Vic with the key derivation after Hayhanen, Codebuch with the 40 messages of the Wujing Zongyao verbatim, Zodiac with the Z340 transposition found in 2020, Kryptos K1 to K3.

Cipher machines envisionz.chiffre.maschine

Enigma and M209

Enigma I, M3 and M4 with rotors I to VIII, β and γ, reflectors A, B, C and the thin B and C, double stepping of the middle rotor, rings and plugboard. Hagelin M-209 with six pin wheels (26, 25, 23, 21, 19, 17 pins) and a drum of 27 bars, encryption after Beaufort; checked against Mark J. Blair's test keys.

Methods

  • Enigma key parts: modell, ukw, walzen, ringe, grundstellung, stecker (model, reflector, rotors, rings, start position, plugs)
  • Enigma.maschine(s) → Maschine, Enigma.WALZEN, Enigma.UKW
  • M-209 key parts: stangen, stifte, grundstellung (bars, pins, start position)

Used in

ready, no callers outside the probes yetinternal: via Katalog; EnigmaBrecher, M209Brecher

What for

Retracing real radio messages; showing why double stepping and the plugboard made the Enigma strong and the reflector made it weak.

Example – decrypting an Enigma message

Verfahren enigma = Katalog.nach("enigma");
Schluessel s = Schluessel.von(enigma, "walzen", "II IV V", "ringe", "BUL",
        "grundstellung", "BLA", "stecker", "AV BS CG");              // key illustrative
String klar = enigma.entschluessele(spruch, s);

Typex, Sigaba, Lorenz, Purple

Typex: five rotors, the right two as stators, rotors with five, seven or nine notches, insertable reversed. SIGABA: five cipher rotors whose stepping is set irregularly by five control and five index rotors. Lorenz SZ40/42: twelve cam wheels generate a 5-bit key for teleprinters (ITA2). Purple: plugboard split into sixes and twenties, stepping switches instead of rotors.

Methods

  • via Katalog.nach("typex" | "sigaba" | "lorenz" | "purple") and Schluessel
  • Purple.stellungen(s, n), Sigaba.schritte(s, n) – stepping sequences for checking the mechanics
  • Lorenz.ITA2 – teleprinter alphabet

Used in

ready, no callers outside the probes yetinternal: via Katalog

What for

The machines of the Second World War side by side: SIGABA, never broken during the war, next to the broken Enigma, Lorenz and Purple.

Purple's stepping rule is checked over a full cycle with Purple.stellungen: an earlier counter-probe stayed green because its anchor never reached a position of the slow twenty.

Analysis envisionz.chiffre.analyse

Steckbrief, Haeufigkeit, Periodik

The first look at a ciphertext (Steckbrief = profile): character set, frequencies, index of coincidence, chi-squared against German and English, Friedman estimate, Kasiski distances, likely period lengths. From these a reasoned guess at the cipher family; each guess carries its reasoning, and for short texts the uncertainty is stated.

Methods

  • Steckbrief.von(geheim): art(), koinzidenzindex(), chiDeutsch(), wieDeutsch(), friedman(), laengen(), kasiski(), befunde(), vermutungen(), alsText()
  • new Haeufigkeit(text, alphabet): zaehlung(), anteile(), koinzidenzindex()
  • Periodik.kasiski(text, max), wiederholungen(text, mindestens), spaltenIndex(x, periode), friedman(ic, n, sprachIc), laengen(x, max, sprachIc)

Used in

app-chiffre: analysis card, frequency chartcommandline-chiffre: -op:analyse, -op:brich without method

What for

Classifying an unknown ciphertext before a breaker runs.

Example – profile of a ciphertext

Steckbrief sb = Steckbrief.von(geheim);
System.out.println(sb.alsText());                 // findings and reasoned guesses
List<String> kennungen = sb.vermutungen();        // e.g. method ids for the breaker

Sprachmodell and Tafelbau

The score of a text is the sum of the logarithms of its quadgrams: the measure all breakers work against. Plus a language similarity from 0 (random) to 1 (average language). The tables hold one byte per quadgram (264), quantised log10 frequency, GZIP-compressed.

Methods

  • Sprachmodell.DEUTSCH, ENGLISCH, nach("de" | "en")
  • bewerte(text | stellen), aehnlichkeit(text), chiQuadrat(zaehlung), koinzidenzindex()
  • Tafelbau.baue(dateien, quadgramme, einzeln) → Ergebnis(buchstaben, verschiedene, untergrenze, obergrenze)

Used in

app-chiffre: language when breakingcommandline-chiffre: -sprache, -op:tafel

What for

Deciding whether a decryption attempt looks like language; building tables for further languages.

Breaking without the key envisionz.chiffre.brecher

Brecher, Brecherliste, Kandidat, Fortschritt, Gluehen

For each method the breaker list finds the responsible breaker. It returns candidates with key, plaintext, score and language similarity; the plaintext is produced by the method itself and is therefore guaranteed to match. Breakers over arrangements (grids, tables, mappings) share the same annealing loop (Gluehen). A known plaintext start can be passed as a Vorgabe (prior).

app-chiffre: breaking card, cancellable, adoptcommandline-chiffre: -op:brich

What for

Demonstrating how classical ciphers fall; solving the exercises of the collection.

Example 1 – guess and break

Verfahren v = Katalog.nach(Steckbrief.von(geheim).vermutungen().get(0));
Brecher b = Brecherliste.fuer(v);                          // null if not breakable
List<Kandidat> k = b.brich(v, geheim, Sprachmodell.DEUTSCH, Fortschritt.STILL);
String klar = k.get(0).klartext();                         // k.get(0).schluessel(), aehnlichkeit()

Example 2 – M-209 with a known start

Verfahren m209 = Katalog.nach("m209");
List<Kandidat> k = Brecherliste.fuer(m209).brich(m209, geheim, Sprachmodell.ENGLISCH,
        Fortschritt.STILL, new Brecher.Vorgabe(null, bekannterAnfang));
Without known plaintext the M-209 is not broken here; measured, 80 known characters sufficed with the default key.

Collection of historical ciphertexts envisionz.chiffre.sammlung

Sammlung and Stueck

Solved, unsolved and exercise pieces from resources/sammlung.txt, each with title, date, region, status, method, key, description, source and ciphertext. Solved pieces yield their plaintext with their key; exercises can be broken.

Methods

  • Sammlung.alle(), nach(kennung), lade(name)
  • Stueck: kennung(), titel(), status() (GELOEST, UNGELOEST, UEBUNG = solved, unsolved, exercise), geheimtext(), verfahrenObjekt(), schluesselObjekt()

Used in

app-chiffre: collection card, with or without solutioncommandline-chiffre: -op:sammlung

What for

Holding Beale, Zodiac, Kryptos and the other famous texts in one's own hands.

Example – decrypting a solved piece

Stueck s = Sammlung.nach("beale-b2");
String klar = s.verfahrenObjekt().entschluessele(s.geheimtext(), s.schluesselObjekt());

Command line cmd.chiffre · envisionz-commandline-chiffre

Chiffre – eight tasks in the house format -name:wert

List, info, encrypt and decrypt, analysis, breaking, collection, table building. Key parts are passed with the parameter's name (-op:info lists them); a value @datei is read from the file. main only calls lauf(args, aus, err), so the probe checks without System.exit. Return codes: 0 OK, 1 no switches or help, 2 wrong switch or key, 3 other error, 10 no convincing plaintext when breaking (language similarity below 0.6).

Examples

Chiffre -op:liste
Chiffre -op:info -verfahren:vigenere
Chiffre -op:ver -verfahren:vigenere -schluesselwort:LEMON -text:"attack at dawn"
Chiffre -op:ent -verfahren:enigma -walzen:"II IV V" -ringe:BUL -grundstellung:BLA -ein:spruch.txt
Chiffre -op:analyse -ein:geheim.txt
Chiffre -op:brich -sprache:de -ein:geheim.txt
Chiffre -op:sammlung -stueck:beale-b2 -loesung:ja
Chiffre -op:tafel -de:<korpusordner> -en:<korpusordner> -ziel:<ordner>
