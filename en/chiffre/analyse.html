Analysing a ciphertext – background

The computation behind Haeufigkeit, Periodik, Sprachmodell and Steckbrief: index of coincidence, Friedman's estimate of the key length, Kasiski, chi-squared and the scoring of a text by four-letter groups.

Index of coincidence

The first look at a ciphertext is counting the letters, al-Kindī's tool from the 9th century. A single figure derived from it already says much about the kind of encryption: the index of coincidence (Friedman 1922), the probability that two randomly drawn letters are equal. If a text has NN characters and letter ii occurs nin_i times, then

κ=∑ini(ni−1)N(N−1)\kappa = \frac{\sum_{i} n_i (n_i - 1)}{N\,(N-1)}

For a language with single-letter frequencies pip_i one expects κ=∑pi2\kappa = \sum p_i^2. From the frequency tables of the module this gives 0.07770.0777 for German and 0.06620.0662 for English; uniformly distributed random letters give 1/26≈0.03851/26 \approx 0.0385. A substitution of the letters (Caesar, simple substitution) and a transposition leave the frequency distribution unchanged except for the names of the letters; the index stays high. A polyalphabetic encryption mixes several distributions and pushes it towards random.

Pseudocode – Haeufigkeit and Steckbrief.buchstaben

koinzidenzindex():
    if total < 2: return 0
    s ← sum over all characters of z·(z − 1)
    return s / (total·(total − 1))

buchstaben(t):
    ic ← index of coincidence;  chiPer ← min(chi²(German), chi²(English)) / length
    if length < 60: finding "all measures fluctuate strongly"
    if similarity(German or English) > 0.6: finding "already reads like language"
    if ic > 0.058:
        if chiPer < 0.15: guess transposition (column, rail fence, scytale, spiral)
        else:               guess substitution (Caesar, affine, Atbash, simple; Playfair for even length without J)
    else if ic > 0.045: guess Vigenère, Beaufort, variant, autokey (Playfair) with Friedman estimate
    else:                 guess Vigenère, autokey, Enigma
    if no J and length ≥ 100: finding "typical for 5×5 squares"

Source: envisionz-framework-chiffre/src/envisionz/chiffre/analyse/Haeufigkeit.java and …/Steckbrief.java. Before the letter computation Steckbrief.von detects special cases by the character set: only A and B (Bacon), only ADFGX/ADFGVX, kana (Uesugi), Hebrew letters (Atbash, Albam, Atbah) and number sequences (Polybius, Uesugi square, homophonic table, book cipher).

Convention in the framework: Every guess carries its reason. The thresholds 0.045 and 0.058, the limit 0.15 for chi-squared per character and the minimum length 60 are rules of thumb; for short texts the uncertainty is stated alongside. The profile names method identifiers that the breaker can use as input; it decides nothing.

Key length: Friedman, Kasiski, column index

In a periodic cipher with a key word of length LL, every LL-th position of the text is encrypted with the same alphabet. Splitting the text into LL columns, each column is a simple shift, and the index of each column jumps to that of the language. With a wrong length the columns stay mixed and the index close to random. Periodik.spaltenIndex forms the mean of the column indices (columns with fewer than two characters are skipped).

Friedman's estimate needs no splitting. With κr=1/26\kappa_r = 1/26, the index of the language κp\kappa_p (in the module the mean of German and English, about 0.0720.072) and the measured κ\kappa for NN characters:

L≈(κp−κr)N(N−1)κ−κrN+κpL \approx \frac{(\kappa_p - \kappa_r)\,N}{(N-1)\,\kappa - \kappa_r N + \kappa_p}

If the denominator is not positive, the method returns infinity. Example: N=100N = 100 and κ=0.05\kappa = 0.05 give L≈2.85L \approx 2.85 – a key of about three letters. For a text of this length the estimate fluctuates strongly; it is a hint, not a finding.

Kasiski (1863) uses the fact that equal plaintext pieces at a distance of a multiple of LL are encrypted equally. Periodik.wiederholungen searches all sequences of minimum length 3 that occur more than once; kasiski counts, for every number k=2,…,maxk = 2,\dots,\text{max}, how often it divides the distance between two consecutive occurrences. The number with the largest count is a candidate for LL or a divisor of it.

Pseudocode – Periodik

spaltenIndex(x, p):
    s ← 0;  count ← 0
    for c ← 0 to p−1:
        column ← x[c], x[c+p], x[c+2p], …
        if length(column) ≥ 2: s ← s + index(column);  count ← count + 1
    return s / count

laengen(x, max, κp):
    for p ← 1 to min(max, max(1, length(x) div 4)):  pair (p, spaltenIndex(x, p))
    sort by  |index − κp| / (κp − 1/26) + 0.01·p        smaller length wins ties
    return the lengths in this order

kasiski(text, max):
    for each sequence of length 3 with occurrences s₀ < s₁ < …:
        for i ← 1 to …:  d ← sᵢ − sᵢ₋₁
            for k ← 2 to max:  if d mod k = 0: count[k] ← count[k] + 1

Source: envisionz-framework-chiffre/src/envisionz/chiffre/analyse/Periodik.java. Steckbrief asks for lengths up to 20 and shows the first five.

Convention in the framework: Multiples of a good length are also good; the surcharge 0.01p0.01\,p prefers the smaller length at nearly equal index. Lengths are considered only up to N/4N/4 so that each column keeps enough characters. The lengths of the column analysis and Friedman's number are separate findings; they need not agree.

Language scoring: chi-squared and four-letter groups

Chi-squared compares the letter count ziz_i with the expected eiNe_i N of the language; small means language-like:

χ2=∑i=025(zi−eiN)2eiN\chi^2 = \sum_{i=0}^{25} \frac{(z_i - e_i N)^2}{e_i N}

Single-letter frequencies do not tell whether the letters stand in a sensible order. For that the scoring by four-letter groups serves, the measure all breakers work against: the table holds, for each of the 264=45697626^4 = 456\,976 four-letter groups, the decimal logarithm of its frequency in a corpus. The score of a text x0…xn−1x_0 \ldots x_{n-1} is the sum

S=∑i=0n−4log10⁡P(xixi+1xi+2xi+3)S = \sum_{i=0}^{n-4} \log_{10} P(x_i x_{i+1} x_{i+2} x_{i+3})

the closer to the language, the higher (less negative). The table is stored as one byte per group: 0 means “not seen” and carries the lower limit, a byte q≥1q \ge 1 stands for log10⁡P=lower+q−1254(upper−lower)\log_{10}P = \text{lower} + \frac{q-1}{254}\,(\text{upper}-\text{lower}). Two reference values are obtained from the table: the mean Slanguage\bar S_{\text{language}} of the logarithms weighted with the frequencies themselves, and the mean Srandom\bar S_{\text{random}} over all entries. The language similarity of a text with nn letters is

a=S/(n−3)−SrandomSlanguage−Srandom,a∈[0;1.2]a = \frac{S/(n-3) - \bar S_{\text{random}}}{\bar S_{\text{language}} - \bar S_{\text{random}}}, \qquad a \in [0;\,1.2]

0 means like random, 1 like the language on average; the value is limited to 0 to 1.2. Summing uses a running index: h←(hmod263)⋅26+xih \leftarrow (h \bmod 26^3)\cdot 26 + x_i.

Pseudocode – Sprachmodell.bewerte and aehnlichkeit

bewerte(x, n):
    if n < 4: return 0
    h ← x[0]·17576 + x[1]·676 + x[2]·26 + x[3];  s ← table[h]
    for i ← 4 to n−1:
        h ← (h mod 17576)·26 + x[i];  s ← s + table[h]
    return s

aehnlichkeit(text):
    n ← number of letters A–Z;  if n < 4: return 0
    mean ← bewerte(text) / (n − 3)
    a ← (mean − randomMean) / (languageMean − randomMean)
    return max(0, min(1.2, a))

Source: envisionz-framework-chiffre/src/envisionz/chiffre/analyse/Sprachmodell.java. The tables (format QG01, GZIP) are generated by Tafelbau from a corpus: German from Europarl, English from a Gutenberg excerpt.

Convention in the framework: The language tables are generated, not maintained; there are German and English, and the selection nach("de" | "en") throws an exception for other languages. When breaking, the command line reports “no convincing plaintext” (return value 10) if the language similarity stays below 0.6.

How it is checked

The Brecherprobe checks the profile on generated texts: a Caesar text has an index above 0.06 and triggers the guess caesar; Vigenère with the key KEY guesses vigenere with length 3 among the first; a columnar transposition is recognised as transposition; numbers above 99 lead to the book cipher; only A and B to Bacon. A counter-test holds 300 random letters (a random sequence with a fixed seed) against it: even the best Caesar candidate stays below a language similarity of 0.5. The Katalogprobe checks the table construction.

Limits

  • All measures fluctuate strongly for short texts; below 60 letters the profile warns explicitly.
  • The thresholds separate families, not methods. A medium index fits Vigenère as well as Playfair; the length does not separate methods of the same family.
  • Friedman's formula presupposes a plaintext with the frequencies of the language; the estimate takes the mean of German and English because the language is unknown.
  • The four-letter tables exist only for German and English, and only for the 26 Latin letters.
